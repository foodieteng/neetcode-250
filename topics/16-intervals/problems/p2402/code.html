完整實作// FREE ROOMS BY ID · USED ROOMS BY END

p2402.cpp C++17 
class Solution {
public:
    int mostBooked(int n, vector<vector<int>>& meetings) {
        sort(meetings.begin(), meetings.end());
        priority_queue<int, vector<int>, greater<int>> freeRoom;
        priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> usedRoom;  // {結束時間, 編號}
        vector<int> freq(n, 0);

        for (int i = 0; i < n; i++) freeRoom.push(i);

        for (auto& v : meetings) {
            long long s = v[0], e = v[1];

            while (!usedRoom.empty() && usedRoom.top().first <= s) {
                auto [_, idx] = usedRoom.top(); usedRoom.pop();
                freeRoom.push(idx);
            }

            if (freeRoom.empty()) {
                auto [end, idx] = usedRoom.top(); usedRoom.pop();
                e = end + (e - s);
                freeRoom.push(idx);
            }

            int idx = freeRoom.top(); freeRoom.pop();
            freq[idx]++;
            usedRoom.push({e, idx});
        }

        return max_element(freq.begin(), freq.end()) - freq.begin();
    }
};

兩個官方範例 → 0、1,都正確。 和「每場掃一遍 n 間房」的模擬比對:n = 1–3、最多 5 場會議(起點 0–5 互不相同、長度 1–3)的所有組合共 10,098 組,加上隨機 50,000 組(n ≤ 6、最多 30 場),0 筆不一致。ASan + UBSan 0 警告。

每一行各自的意思:

  • sort(meetings.begin(), meetings.end()):按起點。題目保證起點都不同,所以不用管平手。
  • freeRoom:greater<int> 讓 top 是最小的編號(規則 ①)。
  • usedRoom:pair 先比結束時間、再比編號,greater<> 讓「最早空、同時空取編號小」的在 top(規則 ②)。
  • long long s, e:延後的結束時間會累加,最大實測到 45,000,050,000(概念頁 LEMMA 2)。
  • e = end + (e - s):會議從 end 開始,長度 e − s 不變。先把房間放回 freeRoom 再統一從 freeRoom 拿,寫法就和有空房的情況共用。
  • max_element(…) - freq.begin():回傳的是位置(房間編號),不是次數;平手時 max_element 回傳第一個。

n = 3, [[1,20],[2,10],[3,5],[4,9],[6,8]],每一行都是實際印出來的。

// 前三場:都有空房 [1,20) free {0,1,2} → 房 0 used {20,0} freq [1,0,0] [2,10) free {1,2} → 房 1 used {10,1} {20,0} freq [1,1,0] [3,5) free {2} → 房 2 used {5,2} {10,1} {20,0} freq [1,1,1]
// 後兩場:沒空房,延後 [4,9) 沒有 ≤ 4 的結束 → free 空 → 等 {5,2}:e = 5 + (9 − 4) = 10 → 房 2 freq [1,1,2] [6,8) 沒有 ≤ 6 的結束 → free 空 → 等 {10,1}:e = 10 + (8 − 6) = 12 → 房 1 freq [1,2,2] // OUTPUT: 1(freq [1,2,2],房 1、房 2 平手,取 1)

[6,8) 那一行:usedRoom 裡有 {10,1} 和 {10,2} 兩間同時在 10 空,pair 比完結束時間再比編號,選房 1。如果 comparator 只比結束時間,就可能選到房 2。
