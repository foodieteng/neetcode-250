完整實作// OFFLINE SWEEP · HEAP BY SIZE

p1851.cpp C++17 
class Solution {
public:
    vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
        int m = (int)queries.size(), n = (int)intervals.size();

        vector<int> order(m);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return queries[a] < queries[b];
        });
        sort(intervals.begin(), intervals.end());

        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;  // {size, right}
        vector<int> ans(m, -1);
        int i = 0;

        for (int qi : order) {
            int q = queries[qi];

            while (i < n && intervals[i][0] <= q) {
                int left = intervals[i][0], right = intervals[i][1];
                pq.push({right - left + 1, right});
                i++;
            }

            while (!pq.empty() && pq.top().second < q) pq.pop();

            if (!pq.empty()) ans[qi] = pq.top().first;
        }

        return ans;
    }
};

兩個官方範例 → [3,3,1,4]、[2,-1,4,6],都正確。 和「每個 query 掃一遍所有區間」的暴力解比對:1–3 個區間(1 ≤ left ≤ right ≤ 4,順序不同算不同組)× 1–3 個 query(值 1–5)共 172,050 組,加上隨機 50,000 組(n、q ≤ 30,值 ≤ 75),0 筆不一致。n = q = 10⁵ 的大測資和並查集解法一致。ASan + UBSan 0 警告。

每一行各自的意思:

  • order + sort(..., queries[a] < queries[b]):排的是下標,queries 本身不動,答案才能寫回 ans[qi](概念頁 LEMMA 2)。
  • sort(intervals.begin(), intervals.end()):預設字典序,先比 left —— 讓指標 i 可以一路往右推,每個區間只進場一次。
  • {right - left + 1, right}:第一個鍵是長度,greater<> 讓最短的在 top;兩端都包含,所以要 +1。第二個鍵 right 用來判斷過期。
  • intervals[i][0] <= q:左端點剛好等於 q 也包含 q,要推進去。
  • pq.top().second < q:右端點剛好等於 q 還算包含,不能 pop。只看 top、而且用 while(概念頁 LEMMA 1)。
  • ans(m, -1):預設 -1,heap 空了就不用寫。長度最大 10⁷,int 放得下。

細節走讀// WALKTHROUGH · 官方範例 2

intervals = [[2,3],[2,5],[1,8],[20,25]], queries = [2,19,5,22],heap 裡是 (size, right),每一行都是實際印出來的。

// 排序 order(按值排的下標) = 0 (q=2), 2 (q=5), 1 (q=19), 3 (q=22) intervals(按 left) = [1,8] [2,3] [2,5] [20,25]
// q = 2, 5:進場與第一次退場 q=2 push [1,8] → (8,8) push [2,3] → (2,3) push [2,5] → (4,5) heap {(2,3), (4,5), (8,8)} top (2,3) 的 right 3 ≥ 2 → ans[0] = 2 q=5 [20,25] 的 left 20 > 5,不推 pop (2,3):right 3 < 5 top (4,5) 有效 → ans[2] = 4
// q = 19, 22:全部過期,再進場 q=19 pop (4,5) pop (8,8) heap {} → ans[1] = -1 q=22 push [20,25] → (6,25) top 有效 → ans[3] = 6 // OUTPUT: [2,-1,4,6]

q = 2 時 (8,8) 一直埋在 heap 底下,q = 5 時也沒被檢查(它的 right 8 ≥ 5,本來就還有效);到 q = 19 它浮上 top 才被 pop。這就是延遲刪除:不急著清,浮上來再說。
