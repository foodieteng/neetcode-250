完整實作// SORT · TRACK LATEST END

p252.cpp C++17 
class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        if (intervals.empty()) return true;

        sort(intervals.begin(), intervals.end(), [&](auto& a, auto& b) {
            return a[1] < b[1];
        });

        int n = intervals.size(), e = intervals[0][1];

        for (int i = 1; i < n; i++) {
            if (intervals[i][0] < e) return false;
            e = max(intervals[i][1], e);
        }

        return true;
    }
};

🎧 面試模擬 · UMPIRE mock · 逐句點播有聲版 ↗

兩個官方範例 → false、true,都正確。 和「每一對都比」比對:座標 0–5 上長度 0–4 的所有會議序列共 54,241 組,加上隨機 50,000 組(n < 30),0 筆不一致。ASan + UBSan 0 警告。

每一行各自的意思:

  • if (intervals.empty()) return true;:不能省。這題 n 可以是 0,下面的 intervals[0][1] 會讀空陣列。拿掉這行實測:ASan 直接 SEGV;-O2 不開 ASan 剛好印出 true —— 這是未定義行為,換個環境就可能崩潰。
  • sort(…, a[1] < b[1]):按終點排。cmp 的寫法細節在 435 程式碼頁第 2 節。
  • e = intervals[0][1]:e 是「前面所有會議裡最晚的結束時間」。名字短,面試時可以說成 latestEnd。
  • intervals[i][0] < e:嚴格小於。剛好等於代表上一場結束的那一刻開始,來得及。
  • max(intervals[i][1], e):按終點排時一定是 intervals[i][1],max 是多餘但無害的保險(概念頁 LEMMA 2)。

細節走讀// WALKTHROUGH · 兩組動畫範例

每一行都是實際印出來的。

// 官方範例 1:[[0,30],[5,10],[15,20]] sort by end → [5,10] [15,20] [0,30] e = 10 i=1 [15,20] 15 < 10 ? no → e = max(20, 10) = 20 i=2 [0,30] 0 < 20 ? yes → return false [0,30] 在 [15,20] 結束前就開始了 // OUTPUT: false
// 剛好碰到:[[7,10],[2,4],[4,7]] sort by end → [2,4] [4,7] [7,10] e = 4 i=1 [4,7] 4 < 4 ? no → e = max(7, 4) = 7 剛好碰到,不算衝突 i=2 [7,10] 7 < 7 ? no → e = max(10, 7) = 10 // OUTPUT: true
