題目簡介// THE QUESTION

QUESTION

給一堆區間 [start, end],最少要刪掉幾個,剩下的才會兩兩不重疊?這題只碰到一點不算重疊:[1,2] 和 [2,3] 可以同時留著。
1 ≤ intervals.length ≤ 10⁵,-5 × 10⁴ ≤ start < end ≤ 5 × 10⁴。

範例:[[1,2],[2,3],[3,4],[1,3]] → 1(刪 [1,3]);[[1,2],[1,2],[1,2]] → 2;[[1,2],[2,3]] → 0。

反過來問:最多能留幾個互不重疊的區間?刪掉的數量就是 n − 留下的數量。 要留最多,就每次留「最早結束」的那一個 —— 它把右邊的空間讓出最多。所以按終點排序,能留就留。

核心策略 · 三步驟// THE LOOP

  1. 按終點排序 —— sort(…, [&](auto& a, auto& b) { return a[1] < b[1]; })。cmp 怎麼寫見程式碼頁第 2 節。
  2. 能留就留 —— res.empty() || res.back()[1] <= v[0]:和最後留下的那個不重疊(碰到也行),就留下。
  3. 回傳刪掉的數量 —— n − res.size()。

和 56 Merge Intervals 長得很像:都是排序後只看 res.back()。差別在排序的鍵(56 按起點、這題按終點)和碰到時的處理(56 合併、這題保留)。兩者的差別在第 5 節的圖裡。

按起點 vs 按終點 · 整理圖// SORT KEY: START OR END

同一組 [[1,10],[2,3],[4,5]],三種寫法。紅點標的是排序用的那一端;綠 = 留下,紅虛線 = 刪掉。正確答案是刪 1 個(留 [2,3]、[4,5])。

怎麼讀這張圖:

  • ① 錯在哪:按起點排,[1,10] 第一個出場就被留下,之後的 [2,3]、[4,5] 都撞到它。起點早不代表結束早 —— 貪心要比的是「誰先把空間讓出來」,那是終點。
  • ② 為什麼對:按終點排,每次留下的都是剩下的區間裡最早結束的。換成任何別的區間,結束得只會更晚,後面能放的只會更少(第 7 節證明)。
  • ③ 也對:按起點排也行,但重疊時要「刪掉終點比較大的那個」,也就是 prevEnd = min(prevEnd, end)。它其實還是在留終點小的,只是決定得比較晚。
① 這個錯法三個官方範例全部都會過(實跑:1、2、0),但窮舉的 111,110 組裡錯 11,592 組。 官方範例裡沒有「起點早、結束晚、把別人整個蓋住」的長區間。自己測一定要加一組,例如 [[1,10],[2,3],[4,5]]。
要做的事排序鍵碰到 / 重疊時本站題目
留最多個不重疊的(= 刪最少)終點 a[1] < b[1]重疊就丟,只留最早結束的435(本題)
把重疊的接成一段起點(預設 sort)終點取 max,接起來56 Merge Intervals
插入一個到已排好的序列不用排(已按起點)重疊的全併進新區間57 Insert Interval

口訣:要「合併」從左邊接,按起點;要「挑最多」看誰先結束,按終點。另一個常見的錯直覺是「先留最短的」:[[0,4],[3,6],[5,9]] 會先留 [3,6],結果刪 2 個,正解只要刪 [3,6] 這 1 個(實跑)。

6

兩個關鍵// TWO LEMMAS

LEMMA 1 · 碰到不算重疊:留下的條件是 <=

[1,2] 和 [2,3] 可以同時留,所以條件是 res.back()[1] <= v[0]。這裡和 56 / 57 相反 —— 那兩題「碰到就合併」。 寫成 <:官方範例 1 回傳 2(應為 1)、範例 3 回傳 1(應為 0),會被抓到;窮舉錯 62,128 / 111,110 組。

LEMMA 2 · 終點相同時,誰先誰後都一樣

兩個區間終點相同,留哪一個,對後面的影響完全一樣(後面只看 res.back()[1])。所以 cmp 只比終點就夠,不用 tie-break。 實測加上「終點相同再比起點(由小到大 / 由大到小)」,200,000 組隨機都 0 差異。

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

按終點排序、能留就留,留下的個數是所有「兩兩不重疊的子集」裡最多的,所以 n − 留下 就是最少刪除數。

PROOF · 手法:交換論證
  1. 第一個可以換成貪心的。拿任何一個最佳解 OPT,把它最早結束的區間 o₁ 換成全體最早結束的 g₁。g₁ 結束得不比 o₁ 晚,所以不會撞到 OPT 後面的區間 —— 換完還是合法、個數不變。
  2. 一路換下去。前 k 個都一樣之後,OPT 的第 k + 1 個一定在 g_k 結束後才開始;貪心挑的是這些區間裡最早結束的,同樣可以換過去而不撞到後面。
  3. 貪心不會比較少。如果 OPT 還有第 m + 1 個,它在 g_m 結束後開始,貪心掃到它時就會留下 —— 矛盾。所以貪心留下的個數 = OPT。
面試這樣說 · 30 秒

我把題目反過來想:最多能留幾個不重疊的區間,刪掉的就是剩下的。要留最多,每次就留最早結束的那個,因為它讓出最多空間給後面。所以我按終點排序,往後掃,跟最後留下的不重疊就留,碰到也算不重疊。最後回傳總數減掉留下的。用交換論證可以證明這樣是最優的。
