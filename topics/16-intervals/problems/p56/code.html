完整實作// SORT · EXTEND res.back() · OR PUSH

p56.cpp C++17 
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        int n = intervals.size();
        sort(intervals.begin(), intervals.end());

        vector<vector<int>> res;
        res.push_back(intervals[0]);

        for (int i = 1; i < n; i++) {
            if (res.back()[1] >= intervals[i][0]) {
                res.back()[1] = max(res.back()[1], intervals[i][1]);
            } else {
                res.push_back(intervals[i]);
            }
        }

        return res;
    }
};

🎧 面試模擬 · UMPIRE mock · 逐句點播有聲版 ↗

兩個官方範例 → [[1,6],[8,10],[15,18]]、[[1,5]],都正確。 和「數線標記」暴力解比對:座標 0–5 上長度 1–4 的所有區間序列共 204,204 組,加上隨機 20,000 組(n ≤ 300、座標 ≤ 10⁴),0 筆不一致。ASan + UBSan 0 警告。

每一行各自的意思:

  • sort(…):vector 的預設比較是字典序,先比起點、起點一樣再比終點。只按起點排(自己寫 comparator)也對,實測 0 錯。
  • res.push_back(intervals[0]):題目保證 n ≥ 1。如果 n 可能是 0,這行會讀越界,要先 if (n == 0) return {};。
  • res.back()[1] >= intervals[i][0]:和「目前合併出來的最後一段」比,含等號,碰到也算重疊。
  • max(…):新的區間可能整個被包住,終點不能往回縮。
  • sort 會直接改掉呼叫端的 intervals(傳參考)。LeetCode 不在意;如果呼叫端還要原來的順序,要先複製。

細節走讀// WALKTHROUGH · 亂序 + 被包住

走概念頁動畫的第二組 [[8,10],[1,9],[3,4],[12,13],[2,6]],每一行都是實際印出來的。

// sort [[1,9],[2,6],[3,4],[8,10],[12,13]] res = [[1,9]]
// for i = 1 … 4 i=1 [2,6] back[1] 9 >= 2 ? yes → back[1] = max(9, 6) = 9 [2,6] 整個被包住 i=2 [3,4] back[1] 9 >= 3 ? yes → back[1] = max(9, 4) = 9 [3,4] 也被包住 i=3 [8,10] back[1] 9 >= 8 ? yes → back[1] = max(9, 10) = 10 i=4 [12,13] back[1] 10 >= 12 ? no → push [12,13] // OUTPUT: [[1,10],[12,13]]

i = 1、2 就是「拿掉 max」會出錯的地方:終點會先變 6、再變 4,到 i = 3 時 4 < 8,[8,10] 被切成另一段。i = 3 則是「和 intervals[i−1] 比」會出錯的地方:前一個是 [3,4],4 < 8,同樣會切開。

// ONE-LINE TAKEAWAY
sort → res 放第一個 → res.back()[1] ≥ intervals[i][0] 就 max 終點,否則 push。四種錯法(不取 max、比 intervals[i−1]、不排序、按終點排)官方範例都抓不到 —— 一定要測 [[1,10],[2,3],[4,5]] 和 [[4,7],[1,4]]。O(n log n) / O(n)。
