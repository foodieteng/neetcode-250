題目簡介// THE QUESTION

QUESTION

給一串會議時間 [start, end],一間會議室同時只能開一場會,最少需要幾間會議室?一場在 5 點結束、另一場 5 點開始,可以用同一間。
1 ≤ intervals.length ≤ 10⁴,0 ≤ start < end ≤ 10⁶。(LeetCode 上是會員題;NeetCode 上可以免費寫。)

範例:[[0,30],[5,10],[15,20]] → 2;[[7,10],[2,4]] → 1。

最少要幾間 = 同一時刻最多有幾場會在開。 照開始時間一場一場排進去:heap 存每間使用中房間的結束時間,最早空出來的在 top。新會議開始前,先把已經結束的房間釋放,剩下的就是「此刻正在開的會」。
注意 · 原版按終點排序會算錯

你貼的程式 cmp 是 a[1] < b[1](按終點)。兩個官方範例都會過,但 [[0,3],[1,4],[2,7],[5,6]] 回傳 2,正解 3;小測資窮舉 813,615 組裡錯 106,236 組。 只要把 cmp 改成 a[0] < b[0](按起點),同樣 813,615 組全部正確。為什麼在第 5 節的圖。這份筆記用的是修正後的版本。

核心策略 · 三步驟// THE LOOP

  1. 按起點排序 —— a[0] < b[0],或直接 sort(begin, end)。
  2. 每場會議開始前,先釋放房間 —— while (top <= v[0]) pop:結束時間不晚於現在的,房間都空出來了(碰到可以接著用)。
  3. 佔一間,記錄最大值 —— push(v[1]),heap 大小就是此刻在開的會議數,room = max(room, size)。

為什麼一定要按起點// TIME MUST MOVE FORWARD

同一組 [[0,3],[1,4],[2,7],[5,6]],兩種排序的處理順序和每一步之後的 heap(都是實跑結果):

怎麼讀這張圖:

  • pop 的意思是「到了這個時間,這間房已經空了」。它把 v[0] 當成「現在」。這只在現在只會往前走的時候成立 —— 也就是按開始時間處理。
  • ② 按終點排序,時間會倒退。[5,6] 比 [2,7] 早結束,所以先處理;它把現在推到 5,pop 掉 3、4。下一場 [2,7] 其實 2 就開始了,那時 [0,3]、[1,4] 都還在開,可是已經被 pop,算不進去 —— 回傳 2。
  • ③ 按起點排序,時間只往前。處理 [2,7] 時現在是 2,heap 裡 3、4 都還在,大小到 3。之後 [5,6] 開始才 pop 3、4,那時它們真的結束了。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 碰到可以接著用:pop 的條件是 <=

一場 1 點結束,下一場 1 點開始,同一間房就夠。所以釋放條件是 pq.top() <= v[0]。 寫成 <:[[0,1],[1,2]] 回傳 2(正解 1)。兩個官方範例都會過;窮舉錯 468,908 / 813,615 組。

LEMMA 2 · 按起點排序時,while 換成 if 也對

每一步 push 一個、最多 pop 一個,heap 永遠不會變小 —— 它的大小剛好等於「到目前為止用過最多幾間」。所以 if 只 pop 一個、最後直接回傳 pq.size(),實測 813,615 組也 0 錯。 但這樣 heap 就不再代表「此刻正在開的會」,只是個計數器。原版的 while + max 意思比較清楚,面試建議寫 while 版,再補一句這個觀察(複習頁第 5 題)。

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

回傳的 room 等於「同一時刻最多有幾場會在開」,而這就是最少需要的會議室數。

PROOF · 手法:不變量 + 下界
  1. 不變量。處理第 i 場(按起點排)之後,heap 裡剛好是「已處理、而且在時刻 start_i 還沒結束」的會議。因為已處理的都在 start_i 或更早開始,所以 heap 大小 = 時刻 start_i 正在開的場數。這一步需要 start 不遞減 —— 按終點排就不成立。
  2. 最大值一定在某場的開始時刻出現。在開的場數只會在有會議開始時變多,所以取遍所有 start_i,就拿到全時段的最大值。room 就是這個最大值。
  3. 不能更少,也不用更多。同時在開的 k 場一定要 k 間,所以至少 room 間;反過來,每次都把新會議放進剛空出來的房間(複習頁第 9 題),最多只會用到 room 間。
面試這樣說 · 30 秒

最少需要幾間,等於同一時刻最多有幾場會在開。我按開始時間排序,用一個 min-heap 存每間使用中房間的結束時間。每場會議開始前,先把結束時間不晚於現在的房間釋放,再把這場的結束時間放進去;heap 的大小就是此刻在開的場數,取最大值。一定要按開始時間,因為「釋放」假設時間只往前走。
