if edges.size() != n-1: return false  // a tree has exactly n-1 edges

return add == n-1  // n-1 successful merges ⇒ connected & acyclic

One: if the edge count isn't n-1, return false right away.
Two: start every node as its own root, and union the endpoints of each edge, counting the merges that succeed.
Three: return true only if there were exactly n-1 successful merges.

One thing worth flagging — I pack the size into the same parent array using a negative value, so a root stores -size and no separate array is needed. And on the union — I attach the smaller tree under the larger and add the sizes, which keeps the trees shallow. Together with path compression in Find, that's the near-constant amortized cost.

class Solution {
    vector<int> parent;                        // <0: root, -value = size; >=0: parent

    int Find(int x) {
        return parent[x] < 0 ? x : parent[x] = Find(parent[x]);  // path compression
    }

    bool Union(int x, int y) {
        int rootX = Find(x), rootY = Find(y);
        if (rootX == rootY) return false;        // same root → this edge makes a cycle

        if (-parent[rootX] < -parent[rootY])   // make rootX the bigger tree
            swap(rootX, rootY);
        parent[rootX] += parent[rootY];        // add sizes (two negatives)
        parent[rootY] = rootX;              // hang smaller under bigger
        return true;
    }

public:
    bool validTree(int n, vector<vector<int>>& edges) {
        if (edges.size() != n - 1) return false;   // a tree has exactly n-1 edges

        parent.assign(n, -1);                   // n singletons, each a root of size 1
        int add = 0;

        for (auto e : edges) {
            int u = e[0], v = e[1];
            if (Union(u, v)) add++;             // count real merges
        }
        return add == n - 1;                    // n-1 merges = acyclic and connected
    }
};

Find returns x if its parent value is negative, otherwise it recurses to the root. Union finds both roots; if they match, it returns false, because this edge would close a cycle. Otherwise it makes rootX the bigger tree, adds the two negative sizes, and hangs rootY under rootX. The main function guards the edge count, fills parent with -1, and counts successful unions.

One thing worth flagging — the Find line does path compression inline: parent[x] = Find(parent[x]) reassigns every node on the path to point straight at the root.
