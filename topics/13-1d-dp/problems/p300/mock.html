Hmm, let me think about this for a second.

This problem reminds me of two patterns. The classic one is a 1-D DP: dp[i] is the longest increasing subsequence ending at i, and I look back at every smaller predecessor — that's O(n²).

For the follow-up, a patience-sorting, or tails, method: keep tails[k] as the smallest tail of an increasing subsequence of length k+1, and binary-search it — that's O(n log n).

CANDIDATE

Here's the plan for the fast one.

// tails[k] = min tail of an increasing subseq of length k+1
for num in nums:
  it = lower_bound(tails, num)  // first element >= num
  if it == end: tails.push_back(num)  // extend
  else: *it = num  // overwrite with a smaller tail
return tails.size()

One: start with an empty tails array.
Two: for each number, find the first tail that's ≥ num, with lower_bound.
Three: if there's none, push the number to extend; otherwise overwrite that slot with the smaller tail. The answer is tails.size().

One thing worth flagging — lower_bound gives strictly increasing; switching to upper_bound, the first element > num, would allow equals, which is the longest non-decreasing subsequence. And tails is not a real increasing subsequence — only its length is meaningful. Does this approach sound good, or would you rather I think of another way?

The O(n log n) tails version:

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;              // tails[k] = smallest tail of length k+1

        for (int num : nums) {
            auto it = lower_bound(tails.begin(), tails.end(), num);
            if (it == tails.end()) tails.push_back(num);  // num is largest → extend
            else *it = num;                          // overwrite: smaller tail
        }

        return tails.size();
    }
};

For each number, lower_bound into tails; at the end, push to extend, otherwise overwrite with the smaller tail. Return the size.

And the O(n²) DP, which I'd write first in an interview:

int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);              // dp[i]: LIS ending at i, at least 1

    for (int i = 0; i < n; i++) {
        for (int j = i - 1; j >= 0; j--) {
            if (nums[i] > nums[j])       // can follow j
                dp[i] = max(dp[i], dp[j] + 1);
        }
    }

    return *max_element(dp.begin(), dp.end());   // LIS can end at any i
}

Every dp[i] starts at 1, and for each earlier j with a smaller value, dp[i] can be dp[j] + 1.

One thing worth flagging — the DP returns max(dp), not dp[n-1], because the longest subsequence can end anywhere.
