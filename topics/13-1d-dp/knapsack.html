固定模板· Templates
0/10/1 背包 · 每物品一次O(nW)
WHEN 物品不可重複取 · 求最大價值
// dp[j] = 容量 j 的最大價值
vector<int> dp(W + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)   // 容量逆序 ↓
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
return dp[W];
// 逆序 → 每個物品這輪只被用一次(不會拿到本輪剛更新的 dp[j-w])
COMPLETE完全背包 · 無限次O(nW)
WHEN 物品可重複取 · 求最大價值
// dp[j] = 容量 j 的最大價值(可重複拿)
vector<int> dp(W + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= W; j++)   // 容量正序 ↑
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
return dp[W];
// 正序 → dp[j-w] 可能已含同一物品 → 允許重複使用
COMBO組合數 · 順序不算Coin Change 2
WHEN 幾種組合湊出金額 · {1,2}={2,1}
// dp[j] = 湊出金額 j 的組合數
vector<long long> dp(amount + 1, 0);
dp[0] = 1;
for (int c : coins)              // ← 外圈:硬幣
    for (int j = c; j <= amount; j++) // 內圈:金額
        dp[j] += dp[j - c];
return dp[amount];
// 硬幣在外 → 每種硬幣只當一層 → 不重複數順序
PERM排列數 · 順序要算Combination Sum IV
WHEN 幾種排列湊出金額 · {1,2}≠{2,1}
// dp[j] = 湊出金額 j 的排列數
vector<unsigned long long> dp(target + 1, 0);
dp[0] = 1;
for (int j = 1; j <= target; j++)  // ← 外圈:金額
    for (int c : nums)            // 內圈:硬幣
        if (c <= j) dp[j] += dp[j - c];
return dp[target];
// 金額在外 → 對每個金額試「最後一枚是誰」→ 順序算
MIN最少硬幣數 · Coin Change 322O(n·amount)
WHEN 湊出金額所需最少硬幣 · 順序無關 → 用完全背包 min
const int INF = 1e9;
vector<int> dp(amount + 1, INF);
dp[0] = 0;                                // 湊 0 元用 0 枚
for (int c : coins)
    for (int j = c; j <= amount; j++)         // 正序(可重複)
        if (dp[j - c] != INF)
            dp[j] = min(dp[j], dp[j - c] + 1);
return dp[amount] == INF ? -1 : dp[amount];  // 湊不出 → -1
排列 vs 組合 · 內外圈怎麼放· THE KEY
組合 Combination順序不算 · {1,2} = {2,1}
for 硬幣 c(外圈)
  for 金額 j = c..target(內圈)
    dp[j] += dp[j − c];
物品(硬幣)在外圈。每種硬幣只被當成「一層」處理一次。當你處理到硬幣 2 時,dp[j] 早已算好「只用硬幣 1」的所有湊法,你只是在其上疊加硬幣 2。

因此湊法永遠以「先 1 再 2」的固定順序長出來,不會再產生「先 2 再 1」。所以 {1,2} 只被算一次 → 得到組合數。

代表題:Coin Change 2 (518)。
排列 Permutation順序要算 · {1,2} ≠ {2,1}
for 金額 j = 1..target(外圈)
  for 硬幣 c(內圈)
    if (c ≤ j) dp[j] += dp[j − c];
目標(金額)在外圈。對每個金額 j,你都問「最後一枚硬幣是哪種」,把所有硬幣都試一遍。

於是 {1,2}(最後放 2)由 dp[3] += dp[2] 算到,{2,1}(最後放 1)由 dp[3] += dp[1] 又算一次 —— 同一組硬幣的不同順序各算一次 → 得到排列數。

代表題:Combination Sum IV (377)。

🔎 具體看差別:coins = {1, 2},target = 3

組合 = 2{1,1,1}、{1,2}　——「1,2」和「2,1」視為同一種
排列 = 3{1,1,1}、{1,2}、{2,1}　——「2,1」多算一種
口訣:「物品在外 → 組合;目標在外 → 排列」。 更根本的理由 —— 外層那一維只會被「單向走一次」:外層是物品,就保證每個物品照固定次序加入(不計順序=組合);外層是容量,就讓每個容量對所有物品開放(計順序=排列)。
MEMORIZE
背誦口訣
  • 0/1 背包 → 物品外、容量逆序(每物品一次);完全背包 → 物品外、容量正序(可重複)。
  • 逆序 vs 正序:逆序時 dp[j−w] 還是「上一輪(沒放本物品)」→ 一次;正序時已含本物品 → 無限次。
  • 組合數(順序不算)→ 硬幣在外、金額在內(Coin Change 2)。
  • 排列數(順序要算)→ 金額在外、硬幣在內(Combination Sum IV)。
  • 計數版初值 dp[0]=1(空集合一種湊法);最值版初值 0 或 INF。
  • 易錯:計數用 +=、最值用 max/min;帶大數用 long long 防溢位。
