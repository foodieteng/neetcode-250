CANDIDATE

Alright, let me code this up. One while loop, as long as l < r.

class Solution {
public:
    int maxArea(vector<int>& height) {
        int maxArea = 0, l = 0, r = height.size() - 1;

        while (l < r) {
            int curArea = min(height[l], height[r]) * (r - l);  // shorter × width
            maxArea = max(maxArea, curArea);

            if (height[l] < height[r]) {
                l++;                                   // left wall shorter → move l
            } else {
                r--;                                   // right shorter or tie → move r
            }
        }

        return maxArea;
    }
};

Inside, the current area is the min of the two heights times r - l, and I fold it into maxArea. Then I move whichever wall is shorter.

One thing worth flagging — the comparison is strictly <, so on a tie the else branch moves r. That's fine: with equal walls, neither end can do better with anything in between. And the area is computed before the move, so the pair I'm standing on always gets counted.
