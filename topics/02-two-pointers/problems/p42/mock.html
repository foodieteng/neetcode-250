Here's the plan.

// A · O(n) space
l[i] = max of height[0..i]    // L→R
r[i] = max of height[i..n-1]  // R→L
water = Σ min(l[i], r[i]) - height[i]
// B · O(1) space
while l < r: take the shorter side
  sideMax = max(sideMax, height)  // update first
  water += sideMax - height; move inward

One, version A: build the l[] (L→R max) and r[] (R→L max) arrays, then sum min(l[i], r[i]) - height[i].
Two, version B: two pointers; each step, update the shorter side's running max, add sideMax - height, and move inward.
Three: return the total.

One thing worth flagging — update the max before adding water, so the amount added is never negative.

Alright, let me code this up. Version A is three scans: left maxes going right, right maxes going left, then add the minimum of the two minus the height.

class Solution {
public:
    int trap(vector<int>& height) {
        int n = height.size();
        vector<int> l(n, 0), r(n, 0);
        l[0] = height[0]; r[n - 1] = height[n - 1];

        for (int i = 1; i < n; i++)          // leftMax: max going L→R
            l[i] = max(l[i - 1], height[i]);

        for (int i = n - 2; i >= 0; i--)       // rightMax: max going R→L
            r[i] = max(r[i + 1], height[i]);

        int water = 0;
        for (int i = 0; i < n; i++)
            water += min(l[i], r[i]) - height[i];   // water level − height

        return water;
    }
};

Version B keeps two scalars instead of the arrays. While l < r, whichever side is shorter updates its max, adds max minus height, and moves inward; a tie goes to the right side, which is fine.

class Solution {
public:
    int trap(vector<int>& height) {
        int l = 0, r = height.size() - 1;
        int leftMax = 0, rightMax = 0, water = 0;

        while (l < r) {
            if (height[l] < height[r]) {          // left is shorter → a taller wall on the right caps it
                leftMax = max(leftMax, height[l]);
                water += leftMax - height[l];    // settle with the left max
                l++;
            } else {                             // right is shorter (or tie)
                rightMax = max(rightMax, height[r]);
                water += rightMax - height[r];  // settle with the right max
                r--;
            }
        }

        return water;
    }
};

One thing worth flagging — the max is updated before the water is added. If the current bar is a new max, it adds 0 instead of going negative.
