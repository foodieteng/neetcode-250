完整實作(修正版)// MAX-HEAP PAIRING

p767.cpp C++17 
class Solution {
public:
    string reorganizeString(string s) {
        using P = pair<int, char>;                        // (次數, 字元)
        vector<int> freq(26, 0);

        for (char c : s) {
            freq[c - 'a']++;
        }

        priority_queue<P> pq;                                // 最大堆:次數多的先
        for (int i = 0; i < 26; i++) {
            if (freq[i]) pq.push({freq[i], i + 'a'});
        }

        string ans = "";
        while (!pq.empty()) {
            auto [cnt1, ch1] = pq.top(); pq.pop();
            ans += ch1;
            // 接縫檢查:ch1 和上一輪最後一個字元;長度 2 就要開始檢查
            if (ans.size() >= 2 && ans[ans.size() - 1] == ans[ans.size() - 2]) return "";
            if (!pq.empty()) {
                auto [cnt2, ch2] = pq.top(); pq.pop();   // 一定 ≠ ch1
                ans += ch2;
                if (--cnt2) pq.push({cnt2, ch2});
            }
            if (--cnt1) pq.push({cnt1, ch1});             // 兩個都 pop 完才推回
        }

        return ans;
    }
};

為什麼偏偏只有 "aa" 會出事

接縫撞到,代表上一輪只剩一種字元、沒有 ch2 陪它,這一輪又拿到同一種。 實測窮舉集裡所有不可行的輸入,第一次撞到時 ans 的長度只有 2、4、6、8 四種(分別 41、360、1,308、1,344 次)。

長度 4、6、8 撞到時,> 2 照樣抓得到。長度 2 撞到的,都是「整串只有一種字母」: 長度 ≥ 3 的,迴圈還會跑下一輪,在長度 3 被抓到;只有 n = 2 的 "aa" 在長度 2 撞到後迴圈就結束了,直接回傳 "aa"。

教訓:邊界條件要用「最小的例子」測 —— 最小的不可行輸入就是 "aa",一跑就現形。 寫 size() > k 還是 >= k 時,直接問自己:「長度剛好 k 的時候要不要檢查?」
