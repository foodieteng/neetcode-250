範例 Trace// 範例 2 · "aaab" 不可行

n = 4,maxFreq 3 > (4+1)/2 = 2,不可行。看接縫檢查在哪一輪抓到。以修正版實跑。

// STEP 1: 第 1 輪 pq [(3,a),(1,b)] ch1 = a → "a" ch2 = b → "ab" 推回 (2,a)(b 用完)
// STEP 2: 第 2 輪 —— a 落單 pq [(2,a)] ch1 = a → "aba"(接縫 a ≠ b ✓) pq 空,沒有 ch2 推回 (1,a)
// STEP 3: 第 3 輪 —— 撞上自己 pq [(1,a)] ch1 = a → "abaa" 接縫 a == a → return "" // OUTPUT: ""
第 2 輪 a 已經落單了(沒有 ch2 陪它),下一輪的 ch1 一定又是 a。 這就是不可行時必然發生的事:其他字元先用完,最多的那種只能自己撞自己。 同樣的過程在 "aa" 只有兩輪,撞到時長度是 2 —— 我原本的 > 2 就在這裡漏掉。

應用題// APPLY IT

App 1. 改成「相同字元之間至少隔 k 個位置」(LeetCode 358 Rearrange String k Distance Apart)。怎麼推廣?
App 2. 不用堆,能不能 O(n) 直接排?(提示:偶數位、奇數位)
App 3. Distant Barcodes(LeetCode 1054):把條碼重排成相鄰都不同,題目保證有解。這題的程式碼能直接用嗎?
// ANSWERS
A1. 最多的字元要彼此隔開,最密的放法是放在位置 0、2、4…,共 ⌈n/2⌉ = (n+1)/2 個位置。

超過這個數,依鴿籠原理一定有兩個相鄰。不超過的話,把它放偶數位、其他字元依序填剩下的位置就排得出來。
寫成 n/2(無條件捨去)在 n 為奇數時少算一格:"a"(1 > 0)、"aab"(2 > 1)都會被誤判成不可行。實測窮舉錯 1,381 組。
A2. 每個字元在堆裡只有一筆,而且這一輪兩個都 pop 完才推回,所以 ch1、ch2 是兩筆不同的資料 = 兩個不同的字元。

同一輪內不可能相鄰相同,唯一的風險在「上一輪最後一個」和「這一輪的 ch1」之間。ch1 接上後它在最後一格、上一輪的最後一個在倒數第二格 —— 比 ans[size−1] 和 ans[size−2] 就是在比接縫。
A3. 只有「單一字母剛好 2 個」會錯("aa"、"bb"…),回傳 "aa" 而不是 ""。

"aa":第 1 輪接上 a,堆空沒有 ch2,推回 (1,a);第 2 輪接上 a → "aa",長度 2,2 > 2 為假,檢查被跳過,迴圈結束。
更長的單一字母("aaa"…)在長度 3 會被抓到;其他不可行的輸入第一次撞到的長度是 4、6、8,> 2 都抓得到。 所以窮舉 15,300 組只錯 7 組、隨機 200,000 組只錯 1,701 組,全是這一族。
兩個官方範例:"aab" 可行、"aaab" 在長度 4 撞到 —— 都不是長度 2,所以抓不到。
A4. ch1 推回去之後,pop ch2 可能又拿到 ch1 自己,同一輪就接了兩個一樣的字元。

例:"aaab" → 回 "aaba"(不合法,而且這組本來該回 "")。實測窮舉錯 5,308 組, 包括把可行的誤判成 ""、可行卻排出相鄰相同的、以及不可行卻排出不合法字串的,三種都有。
A5. 最多的字元最難安排,要趁還有其他字元可以夾在中間時先排掉。

最小堆先用掉少的字元,最後只剩最多的那種,只能連著放 → 明明可行也被判成 ""。 最小反例 "aab":先排 b,再來只剩 a、a → ""(正解 "aba")。實測窮舉錯 10,644 組。
A-App 1. 一輪從 2 個改成 k 個:每輪 pop 最多 k 個不同字元,全部接完才推回。

和 621 一模一樣的「一輪 n+1 格 + buff」結構(那題的 n+1 就是這裡的 k)。 差別是 358 不准 idle:如果某一輪堆空了、但還有字元在等(buff 非空),就代表做不到,回 ""。 767 就是 k = 2 的特例。
A-App 2. 可以:把最多的字元先填偶數位 0、2、4…,其他字元接著填剩下的偶數位,再從 1、3、5… 繼續填。

先檢查 maxFreq ≤ (n+1)/2。最多的那種先放,保證它不會自己相鄰; 其他每種字元的個數都不超過最多的那種,依序填「偶數位用完接奇數位」時,同一種字元也不會相鄰。 只要數次數和填一次,O(n),不需要堆。
A-App 3. 可以,邏輯完全一樣,只是元素從字母換成整數條碼。

次數表改成 unordered_map<int, int>(條碼值不只 26 種),堆存 (次數, 條碼),一輪拿兩個不同的。 題目保證有解,所以接縫檢查一定不會觸發 —— 可以留著當安全網。堆的大小變成「不同條碼數」,複雜度 O(n log d)。
