題目簡介// THE QUESTION

QUESTION

最多可以用 a 個 'a'、b 個 'b'、c 個 'c', 組出最長的字串,而且不能有連續三個相同的字(不能出現 aaa、bbb、ccc)。不用全部用完,答案有多個時回傳任一個。
0 ≤ a, b, c ≤ 100,a + b + c > 0。

範例:(1,1,7) → 長度 8,例如 "ccaccbcc"(我的程式輸出 "ccbccacc",也對); (7,1,0) → "aabaa"。c 有 7 個但只用得了 6 個 —— 因為能拿來隔開 c 的字只有 2 個。

剩最多的那個字最難放完,所以要盡量先用它;但連兩個之後就得插一個別的字隔開。 別的字是「隔板」,越省著用,最多的那個字就能放越多。

為什麼是「最大堆貪心」// WHY THIS

A 暴力 DFS:每一格試三種字 指數級
能保證最長,但不記憶化會爆;記憶化要記 (a,b,c,上一個字,連了幾個),a、b、c 各 101 種,狀態上百萬,寫起來也比貪心長很多。 我拿它當對拍的參考解。
× REJECT · 太慢太重
B 輪流放 a、b、c O(a+b+c)
永遠不會連三個,但少的字很快用完,剩下的那個字只能放 2 個就停。 (1,1,7):a b c 之後只剩 c,停在 abcc,長度 4,正解 8。
△ REJECT · 浪費了隔板
BOTH FAIL · ADOPT
C 最大堆:每次拿剩最多的,會連三個就先插第二多的 O(a+b+c)
堆裡最多三個元素,每次 push / pop 是常數。剩最多的盡量用、第二多的只在被擋時用一個,隔板用得最省。 題目範圍 0~100 全部 1,030,300 組輸入實測 0 錯(和暴力解、長度公式都對過)。
● ADOPT · 每輪最多放兩個字
和 767 Reorganize String 是同一個骨架:最大堆拿最多的,不能放就拿第二多的。 767 是「不能連兩個」而且要全部用完(做不到回空字串);這題是「不能連三個」、用不完就停在最長的地方。
3

核心策略 · 三步驟// THE SHAPE

  1. 建堆:把 > 0 的 (個數, 字) 放進最大堆(0 個的不放)。
  2. 每輪拿堆頂 ch1:如果 res 結尾已經是 ch1 ch1,先拿第二多的 ch2 放一個;沒有第二多的就結束。
  3. 放 ch1,個數減一,還有剩才放回堆。堆空就結束,回傳 res。
我的寫法在被擋時一輪放兩個字(ch2 再 ch1);常見的另一種寫法是只放 ch2、把 ch1 原封不動放回堆。 兩種實測都 0 錯 —— ch2 放下去之後結尾不是 ch1 了,緊接著放 ch1 一定合法。

動畫演示// (1,1,7) → "ccbccacc"

a=1, b=1, c=7。c 一直是堆頂,每放兩個 c 就被擋一次,只好插 b 或 a。 兩個隔板用完之後,最後一個 c 放不下 —— 堆空了就停。

▶ 最大堆貪心 · 結尾兩個都是 ch1 就先插第二多的

載入中…
7 次 while:5 次直接放 c,2 次被擋(插 b、插 a),最後 1 次被擋而堆空 → return。 長度 8 = 2 × (1 + 1 + 1) + 2:兩個隔板把 c 切成三段,每段最多 2 個。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 最長能多長

把三個數排序成 x ≥ y ≥ z。另外兩種字共 y + z 個,最多把最多的那種字切成 y + z + 1 段,每段最多 2 個, 所以最多的字最多放 2(y + z + 1) 個。答案長度 = min(x + y + z, 2(y + z + 1) + y + z)。 另外兩種字彼此之間不會卡住(它們都不比 x 多)。這個公式和暴力解在 0~12 全部輸入一致,我拿它驗證 0~100 的全部輸入。

LEMMA 2 · 為什麼被擋時拿「第二多」,而且只拿一個

被擋時一定要插別的字,插一個就夠讓 ch1 繼續放。插第二多的,是因為它最不怕被用掉:之後它自己也可能變成最多、需要被隔開。 只插一個,是因為隔板很珍貴 —— 多插一個,就少一個機會隔開最多的字。 實測:被擋時用了第二多的卻把 ch1 丟掉(沒放、也沒放回堆),全範圍錯 970,004 組,(0,1,3) 只得到 "ccb"(正解長度 4)。

一句洞察// INSIGHT

最多的字盡量放,連兩個就插一個第二多的當隔板;沒有隔板可插就停。 長度上限 min(總數, 2(y + z + 1) + y + z),貪心剛好達到。
