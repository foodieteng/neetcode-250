被擋結尾已經是兩個它 → 先插一個第二多的;沒有就結束

觀念題// CONCEPT Q&A

Q1. (1,1,7) 為什麼最長只有 8,不能把 7 個 c 全部用上?
Q2. 被擋的時候,為什麼插的是「第二多」的字,而且只插一個?
Q3. 被擋時我先放 ch2 再立刻放 ch1。放 ch1 會不會又造成連三個?
Q4. 被擋、而且堆是空的時候直接 return,會不會太早?
Q5. 開頭的 if (a) pq.push(...) 拿掉會怎樣?
3

範例 Trace// (7,1,0) · 只有一個隔板

a=7, b=1, c=0(c 是 0,不進堆)。以實跑程式逐圈記錄。

// ROUND 1–2 拿 a7 → "a" 拿 a6 → "aa" 堆 [a5, b1]
// ROUND 3 · 被擋 拿 a5,結尾 aa → 拿 b1 放 b → "aab",再放 a → "aaba" 堆 [a4]
// ROUND 4–5 拿 a4 → "aabaa" 堆 [a3] 拿 a3,結尾 aa,被擋,堆空 → return // OUTPUT: "aabaa" (長度 5 = 2 × (1 + 0 + 1) + 1)
一個 b 把 a 切成兩段,每段最多 2 個 → a 最多 4 個,加上 b 共 5。 剩下 3 個 a 怎麼排都放不進去,所以停下來不是程式的問題。
4

應用題// APPLY IT

App 1. 不用真的建字串,只要回傳最長長度,可以 O(1) 算出來嗎?
App 2. 改成「不能連 k 個相同」(k 是參數),程式要改哪裡?
App 3. 改成有 26 種字母,每種有個數上限,還能用同一個堆嗎?複雜度會變嗎?
// ANSWERS
A1. 能拿來隔開 c 的字只有 a、b 共 2 個,最多把 c 切成 3 段,每段最多 2 個 → c 最多 6 個。

所以最長是 6 + 2 = 8 = 2 × (1 + 1 + 1) + 2。一般式:排成 x ≥ y ≥ z,長度 = min(x + y + z, 2(y + z + 1) + y + z)。
A2. 插一個就足夠讓最多的字繼續放;插越多,越少隔板留給之後。第二多的最不怕用掉。

如果插的是最少的字,第二多的之後可能自己也要被隔開,卻沒隔板可用。被擋時只放 ch2、把 ch1 丟掉(沒放回堆)的寫法,全範圍錯 970,004 組:(0,1,3) 只得到 "ccb",正解長度 4("ccbc")。
A3. 不會。放完 ch2 之後結尾是 ch2,不是 ch1;接著放一個 ch1,結尾最多是 ch2 ch1。

而且 ch2 也不會連三個:它是剛從堆裡拿的第二多,在被擋的這個時刻結尾是 ch1 ch1,前面跟它不相連。全範圍 1,030,300 組沒有任何一個輸出出現連三個。
A4. 不會。堆空代表只剩 ch1 這一種字,而結尾已經是兩個 ch1,再放就連三個。

不管怎麼排都放不進去了,這時的 res 就是最長。拿掉這行的話是對空堆 top(),全範圍 124,950 組會踩到((0,0,3) 就是)。
A5. 個數 0 的字會進堆,被當成「還能放」。

實測錯 30,300 組,(0,0,1) 就變成無窮迴圈:放完 c 後堆裡剩 a0、b0,拿出來 --cnt 變成 -1,if (-1) 是 true 又放回去…… 同理兩個 if (--cnt) 都不能省(省了會多放字,(0,0,1) → "cc")。
A-App 1. 可以:排序成 x ≥ y ≥ z,回傳 min(x + y + z, 2(y + z + 1) + y + z)。

這就是我拿來驗證全範圍的公式,和暴力 DFS 在 0~12 全部一致。題目要的是字串,所以還是得跑貪心;但面試時先講出上限,可以證明貪心沒浪費。
A-App 2. 把「結尾兩個都是 ch1」改成「結尾 k−1 個都是 ch1」。

最簡單是多記一個變數:目前結尾連續了幾個、是哪個字,每次放字時更新。不用每次往回掃。上限也跟著變:最多的字最多放 (k − 1)(y + z + 1) 個。
A-App 3. 可以,同一個骨架;堆最多 26 個元素,每次 push / pop 變成 O(log 26)。

總時間 O(總個數 × log 26),仍然是線性。767 Reorganize String 就是 26 種字母、不能連兩個的版本。
