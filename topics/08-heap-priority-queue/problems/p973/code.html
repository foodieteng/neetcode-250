完整實作// MAX-HEAP BY SQUARED DISTANCE

p973.cpp C++17 
class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        // cmp(p1, p2) 為真 = p1 比 p2 近 → 優先權低 → 最遠的站在 top(最大堆)
        auto cmp = [&](const auto& p1, const auto& p2) {
            return (p1[0] * p1[0] + p1[1] * p1[1]) < (p2[0] * p2[0] + p2[1] * p2[1]);
        };
        priority_queue<vector<int>, vector<vector<int>>, decltype(cmp)> pq(cmp);

        for (const auto& p : points) {
            pq.push(p);
            if (pq.size() > k) pq.pop();   // 踢掉 k+1 個裡最遠的
        }

        vector<vector<int>> ans;
        while (!pq.empty()) {
            ans.push_back(pq.top()); pq.pop();   // 最遠的先出;題目接受任意順序
        }
        return ans;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

pq(cmp) 這個建構參數是必要的。 lambda 的型別沒有預設建構子(C++17),所以只寫 pq; 會編譯失敗。 C++20 放寬了:沒有捕獲的 lambda 可以預設建構 —— 但實測 [&] 即使什麼都沒捕獲,在 C++20 仍然失敗, 只有 [] 才過。這個 lambda 沒用到任何外部變數,寫 [] 比較乾淨。
