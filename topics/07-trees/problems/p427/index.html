題目簡介// THE QUESTION

QUESTION

給一個 n × n 的 0/1 矩陣(n = 2x,0 ≤ x ≤ 6,所以 n ≤ 64),用四元樹表示它。
一塊區域全部同值 → 葉子(isLeaf = true,val 就是那個值); 否則 → 內部節點,切成左上、右上、左下、右下四塊分別遞迴。
內部節點的 val 填什麼都接受。

這是本章少見的「樹不是給你的,而是你要蓋出來」的題目。 樹的形狀完全由矩陣決定:哪裡同色就停,哪裡不同色就往下切。

一句話:先問「這一整塊是不是同一個值?」—— 是就收成一片葉子,不是就切四塊、各自再問一次。 邊長每層減半,最多切到 1×1(一格一定同值),所以遞迴一定會停。
2

為什麼「先檢查再切」// WHY THIS

A 不檢查,一律切到 1×1 樹不對
每一格都變成一片葉子,同色的大區域沒有被收起來。 題目要的是「整塊同值就是一片葉子」,這樣蓋出來的樹答案就是錯的(64×64 全 0 應該只有 1 個節點)。
× REJECT · 沒有合併
B 由下往上合併(後序) O(n²) · 每格讀一次
先切到底蓋出四個小孩,若四個都是同值的葉子,就合併成一片葉子。 每格只讀一次,複雜度更好;驗證時我就拿它當對拍的參考解。 代價是合併邏輯比較多,也要處理「丟掉四個小孩」。
△ 也正確 · 較難寫
ADOPT
C 由上往下:先 isSame,不同才切四塊 O(n² log n) · 最直接
直接照題目的定義寫:同值 → 葉子;不同 → 內部節點 + 四個遞迴。 因為是「檢查過才切」,只要一塊同值就一定會在那一層停下,所以蓋出來的樹自動是最精簡的。 代價是每一層都要重新掃一次自己那塊。
● ADOPT · 照定義寫
和 1325 剛好相反:1325 必須先處理小孩才能判斷自己(後序); 這題判斷自己只需要看矩陣,不需要小孩的答案,所以可以在往下遞迴之前就決定。 B 方案才是這題的「後序版」。
3

核心策略 · 三步驟// THE SHAPE

  1. 用 (length, r, c) 描述一塊區域:左上角 (r, c),邊長 length。不複製子矩陣。
  2. isSame:拿 grid[r][c] 當基準,逐格比,遇到第一個不同就立刻回 false。
  3. 同值 → 葉子;不同 → 內部節點,四個小孩的左上角是 (r, c)、(r, c+h)、(r+h, c)、(r+h, c+h),其中 h = length/2。
四個座標記法:r 是列(上下),c 是行(左右)。 「右」是 c + h,「下」是 r + h —— 右上 = 同一列、往右;左下 = 同一行、往下。這兩個寫反是最容易犯的錯(實測錯 64520/65554)。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 「先檢查再切」蓋出來的樹一定最精簡

一個內部節點會出現,唯一的原因是它那塊 isSame 回了 false —— 也就是那塊真的有兩種值,本來就不可能用一片葉子表示。 反過來,只要一塊同值,在第一次碰到它的那一層就會停下。所以沒有多餘的切割,也沒有該切沒切的地方。
實測:和「由下往上合併」的參考解對拍 —— n=2 全部 16 張、n=4 全部 65536 張, n=8/16/32/64 各隨機 20000 張,結構不一致 0。

LEMMA 2 · 節點數永遠 = 4 × 內部節點 + 1

每個內部節點恰好有 4 個小孩,所以「小孩總數 = 4 × 內部」,再加上根:節點 = 4·內部 + 1, 葉子 = 3·內部 + 1。build 的呼叫次數就等於節點數(每次呼叫恰好 new 一個節點)。
實測:2000 張隨機矩陣(n = 1~64)全部滿足這三條。範例 2:2 個內部 → 9 個節點、7 片葉子。

複雜度// COMPLEXITY

同一層的所有區域互不重疊,加起來最多 n² 格;層數最多 log₂n + 1。 所以每一層最多重讀一次整張矩陣。

時間 O(n² log n),天花板 n²(log₂n + 1) 次讀格　·　空間 O(n²) 節點 + O(log n) 堆疊

節點最多的棋盤反而讀得不多 —— 每一塊在第 2 格就發現不同,提早結束幫了大忙。 最傷的是「幾乎同色、差異藏在最後才掃到」的矩陣:每一層都得掃到快底才停。
別把最壞情況背成「2.375n²」:那只是 n=4 窮舉 65536 張的最大值(38 格), n=8 就已經找得到讀 178 格(2.781n²)的矩陣。能證明的說法是 O(n² log n)。

一句洞察// INSIGHT

判斷一塊能不能收成葉子只需要看矩陣,不需要小孩的答案 —— 所以可以「先檢查、不同才切」。 檢查過才切,保證樹最精簡;代價是每一層都重掃,時間 O(n² log n)。 座標記住:右是 c+h,下是 r+h。
