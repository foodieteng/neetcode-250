題目簡介// THE QUESTION

QUESTION

想像你站在樹的右邊往左看,回傳你看得到的節點值(由上而下)。
節點數 0 ~ 100,節點值 −100 ~ 100。

這題是 102 層序走訪的直接延伸 —— 同一個 BFS 骨架,只多了一個 i == sz - 1 的條件。

⚡ 但題目的敘述會誤導你。 「站在右邊往左看」聽起來像「一路沿著右小孩往下走」—— 那是錯的。正確的定義是「每一層最右邊的那個節點」, 而那個節點完全可能是個左小孩。 實測「走右脊」的寫法錯 94.75% 的樹形。

「右視圖」不是「一路往右」// WHY THIS

A 一路沿著右小孩往下走 錯 94.75%

BFS 保證同一層是「由左到右」排列的, 所以「這一層的最後一個」就是「最右邊的那個」。 和 102 的骨架一字不差,只多一個條件。
● ADOPT · 每層取最後
實測「走右脊」的錯誤規模:窮舉 n ≤ 9 全部 6918 種樹形, 錯 6555 種(94.75%)。 而且巧合正確的那 363 種有一個精確的特徵 —— 「右脊的長度恰好等於樹高」(雙向驗證零例外)。 也就是說:只有當右脊本身就是一條最深路徑時,它才碰巧對。
3

核心策略 · 四步驟// THE SHAPE

  1. 凍結層寬:int sz = q.size(); —— 和 102 完全一樣,這一行是層界。
  2. 逐個彈出,把小孩先左後右推進佇列 —— 這個順序保證了同一層由左到右排列。
  3. 只在最後一個時記錄:if (i == sz - 1) ans.push_back(u->val);
  4. 佇列空了就結束。ans.size() 必定等於樹高(實測零違反)。
注意第 ② 步的推入順序才是關鍵 —— 「先左後右」讓佇列裡同一層永遠是左到右, 所以 i == sz - 1 取到的必定是該層最右。 如果反過來先推右,那 i == sz - 1 就會變成左視圖。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 「走右脊」什麼時候碰巧對 —— 一個精確的刻畫

右脊法正確 ⟺ 右脊的長度恰好等於樹高。 實測雙向驗證,零例外:
· 「碰巧對 且 右脊長==高」= 363
· 「碰巧對 但 右脊長≠高」= 0
· 「右脊長==高 但 答錯」= 0

直覺:只要右脊本身就是一條最深的路徑, 那麼每一層的最右節點剛好都落在右脊上。 只要有任何一層的最右不在右脊上(包含右脊提早斷掉),就錯。
而且巧合比例隨 n 快速衰減 —— n=9 時只剩 215/4862 ≈ 4.4%。 最小反例只要 2 個節點:[1,2]。

LEMMA 2 · i == sz - 1 改成 i == 0 會得到「左視圖」

因為 BFS 保證同一層由左到右,所以:
· i == sz - 1 → 該層最後一個 = 最右 = 右視圖
· i == 0 → 該層第一個 = 最左 = 左視圖

實測:把條件改成 i == 0, 與一個獨立的「左視圖」參考解比對 —— 6918/6918 完全相同。 官方範例會從 [1,3,4] 變成 [1,2,5]。
(它和正解「碰巧相同」的有 512 種 —— 就是那些每層只有一個節點的樹,左右視圖重合。)
另外 i == sz 則永遠不成立(迴圈條件是 i < sz)⇒ 永遠回傳 [],錯 6917/6918(唯一「對」的是空樹)。

// 變體實測(窮舉 n ≤ 9,共 6918 種樹形) 一路走右脊(while root->right) → 錯 6555/6918(94.75%),最小反例 [1,2] 巧合正確 363 種 ⟺ 「右脊長度 == 樹高」(零例外) i == sz - 1 改成 i == 0 → 錯 6406/6918,而且「恰好等於左視圖」(6918/6918) i == sz - 1 改成 i == sz → 錯 6917/6918,永遠回傳 [](條件永不成立) 每個節點都記、事後取該層最後 → 錯 0/6918 ← 等價,只是比較浪費 // 最後一列值得記:它證明了 i == sz-1 確實就是「該層最後一個」

兩個實測恆等式:
① 入隊 == 出隊 == n —— 每個節點恰好進出佇列一次。
② ans.size() == 樹高 —— 窮舉 6918 種樹形零違反, 因為每一層剛好貢獻一個答案。
而 n ≤ 100 讓這題完全沒有堆疊壓力 —— BFS 本來就不用遞迴,連 DFS 參考解也最多只到深度 100。

一句洞察// INSIGHT

「右視圖」是每一層的最右,不是一路往右走 —— 而那個節點完全可能是個左小孩。 決定入選的不是「自己是左是右」,而是「在佇列裡排第幾個」, 而佇列的順序是由「先左後右的推入順序」保證的。
走右脊的寫法錯 94.75%,而它碰巧對的那 363 種有精確的刻畫:右脊長度恰好等於樹高。
