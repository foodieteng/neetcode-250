題目簡介// THE QUESTION

QUESTION

給二元樹的根節點,回傳它的直徑 —— 樹中任意兩節點之間最長路徑的邊數。 這條路徑不一定要通過根節點。 節點數 1 ~ 10⁴,節點值 −100 ~ 100。

這題比 104 求深度難的地方只有一句話: 「不一定要通過根節點」。 題目自己把陷阱寫在敘述裡了 —— 但這句話非常容易被讀過去。

核心結構:一趟遞迴同時做兩件事。 path() 回報高度給父節點(這部分和 104 一模一樣), 同時在每一個節點上試算「穿過我的最長路徑 = 左高 + 右高」, 並更新一個全域最大值。 「回傳一個東西、順便更新另一個東西」是樹題非常常見的雙軌結構。
2

為什麼需要全域最大值// WHY THIS

A 只算根節點的「左高 + 右高」 錯 48/626
這就是題目那句話在防的錯誤。 實測窮舉 626 種樹形,有 48 種(7.67%)的直徑不通過根。 而且最小反例要 n = 6 才出現 —— n ≤ 5 的 65 種樹形它全部答對。
× REJECT · 手算測不出來
B 對每個節點各算一次左右高度 重複走訪
答案正確,但每個節點被重複走訪(深度 d 的節點被走 d+1 次)。 這正是本頁對拍用的暴力參考解。 能用一趟做完的事,不需要走 h 趟。
△ 對但浪費
ADOPT
C 一趟遞迴:回報高度 + 在每個節點更新全域最大 O(n) 時間 · O(h) 空間
任何一條路徑都有一個「最高點」(離根最近的那個節點)。 只要在每一個節點都試算一次「穿過我的最長路徑」,就必然涵蓋了所有可能的路徑 —— 因為每條路徑的最高點總會輪到。
● ADOPT · 一趟搞定
這個「每條路徑都有唯一的最高點」的論證,是本題正確性的全部。 它保證了「在每個節點試一次」不會漏掉任何路徑, 也保證了不會重複計算(每條路徑只在它的最高點被算到一次)。
3

核心策略 · 三步驟// THE SHAPE

  1. 拿到左右高度:int left = path(root->left), right = path(root->right); —— 和 104 完全一樣。
  2. 試算「穿過我」的路徑,更新全域最大: longestPath = max(longestPath, left + right); —— 這是本題唯一新增的一行。
  3. 回報高度給父節點:return 1 + max(left, right); —— 注意這裡是 max 不是 +: 往上回報時只能選一條路走,不能左右都要。
第 ② 行用 +、第 ③ 行用 max —— 這個差別是本題的核心。 「穿過我的路徑」可以左右各走一段(所以是 left + right); 但「從我往上延伸的路徑」只能挑一邊(所以是 max(left, right))—— 因為路徑不能在同一個節點分岔兩次。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 直徑真的可能不通過根(實測 48/626)

實測:窮舉 n = 0..7 全部 626 種樹形, 統計「直徑 > 根的左高 + 右高」的情形:
n ≤ 5 → 0 種(每一種都通過根!)
n = 6 → 8 / 132　　n = 7 → 40 / 429
合計 48 / 626 = 7.67%。

最關鍵的一點:n ≤ 5 的所有樹形,「只看根」都碰巧正確。 所以你在紙上手畫幾棵小樹,永遠不會發現這個 bug —— 你必須刻意造出「一邊很淺、另一邊掛著一條深的斜鏈」的形狀。 最小反例是 [1,null,2,3,4,null,5,null,6]: 「只看根」給 3,正解是 4 —— 那條最長路徑整條落在右子樹裡,根本沒碰到根。

LEMMA 2 · 為什麼「節點數高度」加起來剛好是「邊數」

path() 回傳的是「節點數」型的高度(葉節點回傳 1); 但 longestPath 累積的是 left + right,而題目要的是邊數。 兩個單位不同,為什麼相加剛好是對的?

因為 left 是「左子樹裡面最長的節點數」, 它已經等於「從我走到左邊最深處的邊數」 —— 從我到左小孩是 1 條邊,左小孩再往下 left−1 條,合計正好 left 條。 右邊同理。所以 left + right 本來就是邊數。
實測驗證:窮舉 n = 1..8 全部 2055 棵樹, 回傳值 == (最長路徑的節點數) − 1 命中 2055/2055; n = 1 的單節點樹回傳 0(不是 1)✓。 這個混用是對的,但值得在面試時主動說清楚 —— 因為它看起來很像 bug。

一句洞察// INSIGHT

每條路徑都有唯一的「最高點」,所以在每個節點各試一次就必然不漏。 而在同一個節點上,「穿過我」用 +(左右都要)、「往上延伸」用 max(只能挑一邊) —— 這個「回報一個值、順便更新一個全域值」的雙軌結構, 正是 124 二元樹最大路徑和(Hard)的完整骨架。學會這題,124 就只剩「負數要不要」一個新問題。
