p1863.cpp C++17 
class Solution {
public:
    int subsetXORSum(vector<int>& nums) {
        int total = 0;
        dfs(nums, 0, total, 0);
        return total;
    }

    void dfs(vector<int>& nums, int s, int& total, int cur) {
        total += cur;                                       // 每個節點都是一個子集

        for (int i = s; i < nums.size(); i++) {             // 下一個要加誰
            dfs(nums, i + 1, total, cur ^ nums[i]);         // 傳新值,不改 cur
        }
    }
};

完整實作 · 寫法 B(選 / 不選)// YES OR NO

p1863_binary.cpp C++17 
class Solution {
public:
    int subsetXORSum(vector<int>& nums) {
        return dfs(nums, 0, 0);
    }

    int dfs(vector<int>& nums, int i, int cur) {
        if (i == nums.size()) return cur;                   // 葉子才是一個子集

        return dfs(nums, i + 1, cur ^ nums[i])              // 選 nums[i]
             + dfs(nums, i + 1, cur);                       // 不選 nums[i]
    }
};
B 用回傳值把左右子樹的總和加起來,不需要 total 參考;A 因為每個節點都要加,用 int& total 一路累加比較直接。 兩版都過三個官方範例,窮舉 9,330 組 + 隨機 2 萬組 0 錯。-Wall 只有 i < nums.size() 的 signed/unsigned 警告,無害(n ≤ 12)。

我寫錯的地方// MY MISTAKES

第一版的 dfs(其他部分和上面一樣):

p1863_first_draft.cpp C++17 
    void dfs(vector<int>& nums, int s, int& total, int xor) {   // ✗① xor 是保留字
        total += xor;

        for (int i = s; i < nums.size(); i++) {
            dfs(nums, i + 1, total, xor ^= nums[i]);            // ✗② 改到了這一層的值
        }
    }
① xor 不能當變數名 —— 編譯錯誤

C++ 有一組「替代運算子」關鍵字:xor 就是 ^,另外還有 and、or、not、bitand、xor_eq…… 所以 int xor 等於寫 int ^。實際編譯:error: expected ',' or '...' before 'xor' token。 改名成 cur 就好。

② xor ^= nums[i] —— 兄弟分支吃到上一圈的結果

^= 會寫回變數。第一圈把 cur 改成 cur ^ nums[s],第二圈就從這個錯的值出發。
[1,3]:i = 0 時 cur 變成 1,算 {1} = 1、{1,3} = 2 都對; i = 1 時 cur 已經是 1,{3} 被算成 1 ^ 3 = 2(應該是 3)→ 總和 5,正解 6。 [5,1,6] → 21(正解 28)。窮舉錯 9,233 / 9,330,最小反例 [1,1] → 1(正解 2)。

② 是回溯最常見的錯:改了狀態卻沒有改回來。 兩種修法:傳新值 cur ^ nums[i](這題用這個);或像 path 一樣「改 → 遞迴 → 改回來」:cur ^= nums[i]; dfs(...); cur ^= nums[i];(XOR 兩次剛好還原,隨機 2 萬組實測 0 錯)。
