題目簡介// THE QUESTION

QUESTION

對 nums 的每一個子集(包含空集合),算出子集裡所有數的 XOR,再把這些 XOR 全部加起來。
1 ≤ n ≤ 12,1 ≤ nums[i] ≤ 20。

範例:[1,3] 的子集 {} {1} {3} {1,3},XOR 是 0, 1, 3, 2,總和 6。 [5,1,6] → 28,[3,4,5,6,7,8] → 480。

n ≤ 12,子集最多 2¹² = 4,096 個 —— 全部列出來就好。 這題真正要學的是「怎麼不重複、不遺漏地列出所有子集」,也就是回溯的骨架。09 分類後面的題目都長在這上面。

回溯的兩種寫法// TWO WAYS TO ASK

兩種寫法列出的子集一模一樣,差別在每一層遞迴問的問題不一樣,所以畫出來的樹形狀不一樣、答案記錄的位置也不一樣。

template_for.cpp 寫法 A · FOR 迴圈 
void dfs(int s, State& cur) {
    record(cur);                          // 每個節點都是一個答案
    for (int i = s; i < n; i++) {         // 問:下一個放誰?
        choose(i);
        dfs(i + 1, cur);                  // i + 1:不回頭,避免重複
        unchoose(i);
    }
}
template_binary.cpp 寫法 B · 選 / 不選 
void dfs(int i, State& cur) {
    if (i == n) { record(cur); return; }  // 只有葉子是答案
    choose(i);   dfs(i + 1, cur);         // 問:第 i 個要不要?要
    unchoose(i); dfs(i + 1, cur);         //                  不要
}
A · for 迴圈B · 二元(選 / 不選)
每層問的問題「下一個要放哪一個?」「第 i 個要不要?」
參數意思s:只能從 s 之後挑i:現在決定第幾個
一個節點幾個小孩0 ~ n 個(看 s 後面剩幾個)永遠 2 個
哪裡是答案每個節點都是一個子集只有葉子是子集
記錄答案函式一進來就記i == n 才記
呼叫次數2ⁿ(n=3 → 8)2ⁿ⁺¹ − 1(n=3 → 15)
樹的深度子集大小(最深 n)固定 n
寫法 A 的 i + 1 是「不回頭」:挑了 nums[i] 之後只能往後挑,所以 {5,1} 和 {1,5} 只會出現一次。 寫法 B 天生不會重複:每個數只被問一次「要不要」,葉子的路徑就是一串 0/1,剛好對到 bitmask。

什麼時候用哪一種// WHEN TO PICK WHICH

題型比較順手的寫法為什麼
子集、組合(78、77、39)兩種都行A 少一半呼叫;B 比較好想
有重複元素要去重(90、40)A排序後一行 if (i > s && nums[i] == nums[i-1]) continue;
排列(46、47)A(迴圈從 0 + used[])每一格要問「放誰」,不是「要不要」
每個東西二選一、或分到 k 組(473、698)B 的延伸每層決定一個東西放哪
答案只在「全部決定完」時才成立Bbase case 剛好就是記錄點
寫之前先問自己:「這一層在決定什麼?」 決定「下一個放誰」→ for 迴圈;決定「這一個要不要 / 放哪」→ 二元(或 k 元)分支。答案記錄的位置跟著決定:A 在每個節點,B 在葉子。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 寫法 A 為什麼剛好 2ⁿ 個節點、不重複

每個節點的路徑是一串嚴格遞增的 index(因為下一層從 i + 1 開始)。 每個子集排好 index 之後只有一種遞增寫法,所以每個子集恰好對應一個節點;子集共 2ⁿ 個,節點也就是 2ⁿ 個。 這也是為什麼 A 要「一進來就加」—— 不加的話,大部分子集根本不會被算到。

LEMMA 2 · 參數要傳新值,不要改自己

cur 代表「目前這個節點的 XOR」。寫成 dfs(..., cur ^= nums[i]) 會把這一層的 cur 也改掉, 下一圈 for 迴圈的兄弟就是從錯的值出發。我的第一版就是這樣:[1,3] 回 5({3} 被算成 1^3 = 2)。 傳 cur ^ nums[i],或用 path 時「push → 遞迴 → pop」成對出現 —— 這就是「回溯」的「回」。

一句洞察// INSIGHT
