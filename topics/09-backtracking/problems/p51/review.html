PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
為什麼檢查裡沒有「同一列」?row[] 有什麼用?
解答與說明 · ANSWER▾
每一層只在第 r 列放一個皇后,接著就去 r + 1,不可能有兩個皇后同列 —— 所以不用檢查。

row[] 只有被寫、沒有被讀;整個刪掉 n = 1~12 的輸出逐位元組相同。小心不要把它誤用在 if 裡:寫成 row[c] 時,每個 n 都只輸出 1 個錯的盤面。
第 2 題10 分
為什麼同一條「/」斜線上 r + c 相同、「\」斜線上 r − c 相同?為什麼要加 n − 1?
解答與說明 · ANSWER▾
沿著「/」走一步是 (r−1, c+1),和不變;沿著「\」走一步是 (r+1, c+1),差不變。

r − c 最小是 0 − (n−1) = −(n−1),加 n − 1 平移到 0 ~ 2n − 2。忘了平移:一般編譯 n = 1~9 全對(負索引讀到 vector<bool> 緩衝區前面的位元),ASan 會報 heap-buffer-overflow。 寫成 c - r + n - 1 也對,只是編號左右翻過來。
第 3 題10 分
diag 陣列只開 n 格,n = 1~9 全部答對、ASan 也沒報錯。那它算對嗎?
解答與說明 · ANSWER▾
不對,只是剛好沒被抓到。

索引最大到 2n − 2 = 16,超出 n 格。vector<bool> 把位元打包在 64 位元的 word 裡,索引 16 還在同一個 word,所以讀寫都「成功」,連 ASan 都看不到。這仍然是未定義行為,n 大到 2n − 1 > 64 就會壞。陣列大小照斜線條數開:2n − 1。
第 4 題10 分
忘了 board[r][c] = '.',但旗標有清。解數會錯嗎?盤面呢?
解答與說明 · ANSWER▾
解數全對(n = 1~9 都對),盤面全錯。

剪枝只看旗標,旗標有清,所以走的路完全一樣;但棋盤上之前放過的 Q 沒拿掉,收進答案的盤面會多出很多 Q,例如 n = 4 收到 QQ.. / ..QQ / QQ.. / ..Q.。只比對解數的測試會漏掉這個錯。
第 5 題10 分
輸出的盤面是什麼順序?
解答與說明 · ANSWER▾
照「每列皇后所在的欄」由小到大:先比第 0 列的欄,再比第 1 列 ……

因為每一列都是 c 從 0 試到 n − 1。n = 4 是 [1,3,0,2] 在 [2,0,3,1] 前面。題目說順序不限,所以不用管。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,照程式手走 n = 4 · 解 #1 是怎麼長出來的:逐步寫出關鍵變數的變化,最後回傳什麼?決定結果的是哪一步?
解答與說明 · ANSWER▾

插樁實跑,只看 (0,1) 開頭那一支。每一行寫出這一列被擋的欄和擋它的旗標。

// 放 (0,1):佔 col[1]、diag1[1]、diag2[2] #6 r1 c0:diag1[1] 已佔(r+c = 1)→ ／ c1:col[1] 已佔 → 欄 c2:diag2[2] 已佔(1−2+3 = 2)→ ＼ c3:放 (1,3),佔 col[3]、diag1[4]、diag2[1]
// 下兩列 #7 r2 c0:放 (2,0),佔 col[0]、diag1[2]、diag2[5] #8 r3 c0 欄、c1 欄 → c2:放 (3,2) #9 r4 = n → 收 .Q.. / ...Q / Q... / ..Q. // OUTPUT: 解 #1 = 每列的欄 [1,3,0,2]
#6 那一列 4 格有 3 格被擋,而且三種旗標各擋一格。 一個皇后最多讓下一列 3 格不能放:正下方(欄)和左下、右下(兩條斜線)。

PART C · 應用題// 3 題 × 13–14 分

第 7 題13 分
52 · N-Queens II ↗ 只要解的個數。程式可以拿掉什麼?
解答與說明 · ANSWER▾
拿掉整個 board 和 ans,base case 改成 count++。

旗標和回溯完全不動。少了每個解 O(n²) 的棋盤複製,也不用存答案。n = 1~9 的答案就是 1、0、0、2、10、4、40、92、352。
第 8 題13 分
把三個 bool 陣列換成三個整數的位元遮罩,要怎麼寫?
解答與說明 · ANSWER▾
cols、d1、d2 三個整數;這一列能放的位置 = ~(cols | d1 | d2) & ((1 << n) - 1)。

每次取最低位 p = avail & -avail 放下去,遞迴 (cols | p, (d1 | p) << 1, (d2 | p) >> 1):斜線遮罩每往下一列就左移 / 右移一格,剛好對應「左下、右下」。不用 continue 一格一格試,只走能放的位置。完整程式和實測(n = 9 約快 5~6 倍)在程式碼頁第 2 節。
第 9 題14 分
解是左右對稱成對出現的。能不能只算一半?
解答與說明 · ANSWER▾
可以:每個解左右翻轉後還是解,而且第 0 列的欄 c 會變成 n − 1 − c。

所以只讓第 0 列試前一半的欄,答案 × 2;n 是奇數時,第 0 列放正中間那欄的解另外算一次、不乘 2。n = 4 的兩個解 [1,3,0,2]、[2,0,3,1] 就是一對鏡像。
