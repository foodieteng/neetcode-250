PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
為什麼「全部數字放完」就能回傳 true,不用再檢查每個桶是不是剛好 target?
解答與說明 · ANSWER▾
每個桶都 ≤ target(放不下就跳過),k 個桶加起來 = total = k · target ⇒ 每個桶只能剛好 = target。

所以只要所有數都放進去了就一定成功。這也是為什麼拿掉 total % k 不會錯:整除不了時 k · target < total,數字一定放不完。
第 2 題10 分
為什麼 k 越大,拿掉同高去重的代價越大?
解答與說明 · ANSWER▾
空桶全都一樣,k 個空桶互換就有 k! 種等價排列;不去重會每種都走一次。

實測難例:k = 3 去重省 6 倍(666,421 → 111,073)、k = 5 省 120 倍(23,123,251 → 192,721)、k = 8 省約 5 萬倍(41,578,721 → 845)。
第 3 題10 分
[2,2,2,2,3,4,5], k = 4 的動畫裡,#7、#10、#12 都停在 [5,4,5,4]。同高去重為什麼沒擋掉這些重複?
解答與說明 · ANSWER▾
同高去重只看「桶的高度」,看不出「這個 2 和上一個 2 是同一個值」。

四個 2 分到 b2(已有 3)和 b3 的方式,只是順序不同就會被當成不同分支:#4 先放 b2 或 b3、#8 先放 b2 或 b3 …… 結果都走到 [5,4,5,4] + 一個 2 的死局。 bitmask DP 只記「哪些數用過」,不在乎順序,所以沒有這種重複。
第 4 題10 分
你的「每個數選一個桶」和「一次填滿一個桶」,誰比較快?
解答與說明 · ANSWER▾
沒有誰一定快,實測各有剋星。

k = 3、4、5 的難例:一次填一桶 6,440 / 1,690 / 703 次,你的 111,073 / 206,649 / 192,721 次。 k = 8、數字很小(≤ 15)的難例反過來:你的 845 次,一次填一桶 126,593 次。都在幾 ms 內,這題兩種都能過。
第 5 題10 分
k = 1 和 k = n 時答案是什麼?你的程式要特判嗎?
解答與說明 · ANSWER▾
k = 1 永遠 true;k = n 時 ⇔ 所有數相等。不用特判。

實測窮舉:k = 1 的 1,547 組全是 true;k = n 的 1,547 組,輸出和「全部相等」完全一致。[5], k = 1 → true(2 次呼叫);[1,1,1,1], k = 4 → true(5 次)。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,照程式手走 [2,2,2,2,3,4,5], k = 4 · 回溯在哪裡發生:逐步寫出關鍵變數的變化,最後回傳什麼?決定結果的是哪一步?
解答與說明 · ANSWER▾

概念頁動畫那組的骨架(插樁實跑,只列放入、死局和拿回)。排序後 [5,4,3,2,2,2,2],target 5。

// 前三個數:5 → b0、4 → b1、3 → b2 #1 5 → [5,0,0,0] #2 4 → [5,4,0,0] #3 3 → [5,4,3,0] #4 第一個 2 → b2 [5,4,5,0] #5 2 → b3 [5,4,5,2] #6 2 → b3 [5,4,5,4] #7 最後的 2 哪都放不下 → false 拿回到 #4,改放 b3 → [5,4,3,2] #8 2 → b2 [5,4,5,2] #9 2 → b3 [5,4,5,4] #10 放不下 → false #8 改放 b3 → [5,4,3,4] #11 2 → b2 [5,4,5,4] #12 放不下 → false;#11 改 b3 也超過
// 一路拿回到根:空桶全被同高跳過 #3 拿回 3 → [5,4,0,0];b3 = b2 = 0 同高跳過 #2 拿回 4 → [5,0,0,0];b2、b3 同高跳過 #1 拿回 5 → [0,0,0,0];b1、b2、b3 同高跳過 // OUTPUT: false(12 次 exist)
同高去重剪掉的是「空桶互換」;剪不掉的是「同樣的 2 換個順序放」—— 這三個死局就是這樣來的。 n ≤ 16、每個值最多 4 次,這點重複不影響通過;要徹底消掉就是 bitmask DP(狀態只看「用了哪些數」)。

PART C · 應用題// 3 題 × 13–14 分

第 7 題13 分
寫出「一次填滿一個桶」的回溯:參數有哪些?怎麼去重?
解答與說明 · ANSWER▾
fill(k, cur, start):還要填 k 個桶、目前這桶已有 cur、從 start 往後挑。

cur == target → fill(k - 1, 0, 0);k == 0 → true。迴圈 j 從 start:跳過 used、跳過 cur + nums[j] > target、 跳過 j > start && nums[j] == nums[j-1] && !used[j-1](和 47 同一個同層去重)。實測 0 錯。
第 8 題13 分
寫出 bitmask DP 的狀態和轉移。
解答與說明 · ANSWER▾
dp[mask] = 用掉 mask 這些數之後,「正在填的那一桶」已經有多少(不可行 = −1)。

dp[0] = 0;沒用過的 j 若 dp[mask] + nums[j] ≤ target,則 dp[mask | 1<<j] = (dp[mask] + nums[j]) % target。答案 dp[full] == 0。 和 473 的 第 7 題 一模一樣,只是 4 → k(其實轉移裡根本沒有 k)。
第 9 題14 分
k = 2 時這題變成哪一題?有沒有更快的做法?
解答與說明 · ANSWER▾
k = 2 就是 416 Partition Equal Subset Sum ↗:找一個子集和 = total / 2。

用 0/1 背包:can[s] = 能不能湊出 s,對每個數 x,s 由大到小更新 can[s] |= can[s - x],O(n · total)。 一個子集湊到 total / 2,剩下的自動也是 total / 2。
