範例 Trace// n = 2 · 8 次呼叫

n = 2,正解 2 個:(())、()()。這是最小的「有分叉」輸入。

// 第一支:"(" 後面再放 "(" call#1 "" o0 c0 只能放 '('(close 0 不 < open 0) call#2 "(" o1 c0 兩支都能走 ← 唯一的分叉點 call#3 "((" o2 c0 '(' 用完了,只能放 ')' call#4 "(()" o2 c1 只能放 ')' call#5 "(())" o2 c2 長度 4 → ans #1
// 回到 call#2("(" 那層,res 還是 "("),走 ')' 支 call#6 "()" o1 c1 只能放 '('(close 1 不 < open 1) call#7 "()(" o2 c1 只能放 ')' call#8 "()()" o2 c2 長度 4 → ans #2 // OUTPUT: ["(())","()()"]
8 個節點、2 個答案,沒有一條路是白走的。 call#2 是唯一兩個 if 都成立的地方 —— else if 和「傳參考沒 pop」都是在這裡壞掉,所以 n = 2 是最小的有效測資。

// ANSWERS
A1. 因為這題從頭到尾沒有改過 res。

res + '(' 是做一個新字串交給下一層,這層的 res 還是原樣,第二個 if 拿到的就是對的 res。 78 是在迴圈裡 path.push_back(...),改的是這層自己的 path,下一圈要用就得先 pop。判斷標準:這層有沒有「改」自己的變數。
A2. 兩個 if 已經保證每個前綴 close ≤ open ≤ n。

長度 2n 時 open + close = 2n,兩個都 ≤ n,只能都等於 n;前綴又從來沒有 ) 比 ( 多,所以一定合法。實測 n = 1~8 輸出和暴力窮舉完全相同。
A3. 能放 ( 的節點就不會再試 ),每次只剩最左邊那條路。

實測 n = 2 只剩 ["(())"],n = 2~8 都錯(7 / 8)。n = 1 只有一條路 "" → "(" → "()",沒有任何節點兩個 if 同時成立,所以測不出來。
A4. 不是巧合:永遠先走 ( 支,而 ((ASCII 40)比 )(41)小。

DFS 先把 ( 開頭的全部列完才換 ),每一層都這樣,就是字典序。把兩個 if 對調,實測順序整個反過來:()()() ()(()) (())() (()()) ((()))。題目不要求順序,所以兩種都對。
A5. 沒有死路 → 節點數只比答案數多常數倍,時間就由答案數決定。

實測呼叫數 ÷ 答案數:n = 3 是 22 / 5 = 4.4,n = 8 是 6,917 / 1,430 ≈ 4.8。 每個節點 O(n),所以總共 O(n · Cn) = O(4ⁿ / √n)。如果有死路(例如只在葉子才檢查),不剪枝的樹 n = 8 有 131,071 個節點。
A-App 1. 不用,答案就是 Catalan 數 Cn = C(2n, n) / (n + 1)。

也可以用 DP:第一個 ( 和它配對的 ) 把字串切成「裡面 i 對」和「後面 n − 1 − i 對」,所以 Cn = Σ Ci · Cn−1−i,C0 = 1。 算出來 1, 2, 5, 14, 42, 132, 429, 1430,和這題實跑的答案數一樣。
A-App 2. 可以,一個計數器就夠:遇 ( +1、遇 ) −1,中途不能變負數,最後要是 0。

「中途不能變負」就是這題的 close ≤ open,「最後是 0」就是長度 2n 時 open = close。 只有一種括號才能這樣做;20 有三種括號,要知道「最近沒配對的是哪一種」,才需要 stack。
A-App 3. 一樣:一格一格往下長,長度到了就收,字串用 res + c 傳值往下。

不一樣:每格的選擇從 2 個變成 3~4 個字母,而且沒有任何剪枝,每一條路都合法 —— 那題的樹是完整的,這題的樹是被兩個 if 剪過的。
