題目簡介// THE QUESTION

QUESTION

在 n × n 的棋盤放 n 個皇后,任兩個不能同列、同欄、同一條斜線。回傳有幾種擺法(不用給盤面)。
1 ≤ n ≤ 9。

範例:n = 4 → 2;n = 1 → 1。 n = 1~9 的答案:1、0、0、2、10、4、40、92、352。

就是 51 · N-Queens 拿掉棋盤:搜尋、剪枝、撤銷一行都不改。 51 在 r == n 要複製整個棋盤;這題只要 ans += 1。所以這頁的重點是「回溯怎麼數數」,衝突檢查的細節看 51。

核心策略 · 三步驟// THE SHAPE

  1. 一層一列:dfs(r) 在第 r 列放一個皇后;r == n 代表 n 列都放好了 → ans += 1、return。
  2. 三個旗標 O(1) 檢查:col[c]、diag1[r + c](/)、diag2[r - c + n - 1](\),任一為 true 就 continue。
  3. 放 → 下一列 → 拿掉:旗標設 true,dfs(r + 1),回來設回 false。ans 用 int& 傳,所有層加在同一個變數上。

兩個要能講清楚的點// TWO LEMMAS

LEMMA 1 · 回溯數數 = 數「走到 r == n 的葉子」;int& 和回傳值是同一件事

每個解恰好對應搜尋樹上一條從根走到 r == n 的路,所以 ans 每 +1 一次就是一個不同的解,不會重複(每列的欄由 0 到 n−1 只試一次)。 寫法有兩種:像你的程式傳 int& ans,在葉子 +1;或讓 dfs 回傳這棵子樹的個數,父節點把子節點的回傳值加起來 —— 動畫裡每個節點的小計就是這個回傳值。 忘了 &、把 ans 傳值:每一層加在自己的副本上,實測 n = 1~9 全部回傳 0。

LEMMA 2 · 左右翻轉:第 0 列放 c 和放 n − 1 − c 的解數一樣

把一個合法盤面左右翻轉,欄 c 變 n − 1 − c;同欄還是同欄,「/」和「\」互換,所以翻過去還是合法解。 第 0 列在左半邊的解和右半邊的解一一對應 → 只讓第 0 列試前 ⌊n/2⌋ 欄,結果 × 2;n 是奇數時,正中間那欄的鏡像是自己,單獨算一次不乘 2。 和 51 不同,這題只要個數,所以這個優化直接能用:在 bitmask 版上再快約 2 倍(程式碼頁第 2 節)。
