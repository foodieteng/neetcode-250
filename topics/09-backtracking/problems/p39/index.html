題目簡介// THE QUESTION

QUESTION

candidates 裡的數都不相同,找出所有加起來等於 target 的組合。同一個數可以用無限次; 組合只看「每個數用了幾次」,[2,2,3] 和 [3,2,2] 算同一個。
1 ≤ n ≤ 30,2 ≤ candidates[i] ≤ 40,1 ≤ target ≤ 40,保證答案少於 150 組。

範例:[2,3,6,7], 7 → [[2,2,3],[7]];[2,3,5], 8 → [[2,2,2,2],[2,3,3],[3,5]];[2], 1 → []。

骨架和 78 Subsets 一樣:for 迴圈從 s 挑下一個、path push / pop。 只改兩個地方:遞迴傳 i(不是 i + 1)讓同一個數能再選;湊到 target 才收、超過就停。

核心策略 · 三步驟// THE SHAPE

  1. 排序:讓迴圈裡的數由小到大,超過 target 之後的都不用試。
  2. 湊到就收:res == target → ans.push_back(path),return。
  3. 從 s 挑下一個:res + c[i] > target 就 break;否則 push → dfs(..., i) → pop。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 為什麼可以 break,不只是 continue

排序後 c[i] ≤ c[i+1] ≤ …。如果 res + c[i] > target,後面每一個 res + c[j] 都更大,不可能湊到。 所以 continue 雖然也對,只是白白檢查完整個迴圈:壓力測試(2~31 共 30 個數、target 40)呼叫次數一樣,迴圈卻跑了 635,407 圈,break 只跑 68,380 圈。 沒排序就 break 會錯:[3,2], 2 在 3 就停了,看不到後面的 2 → 回 []。

LEMMA 2 · 為什麼不會有 [2,3] 和 [3,2] 兩個

每條路徑上的 index 都是不遞減的:小孩從 i 開始挑,不會回頭挑比 i 小的。 每個組合排好序之後只有一種不遞減的寫法,所以只會出現一次。 改成 dfs(..., s) 或迴圈從 0 開始,就會回頭:[2,3], 5 → [[2,3],[3,2]],窮舉都錯 1,338 / 3,024。

一句洞察// INSIGHT

78 的 for 迴圈樹,把 i + 1 改成 i 就能重複選;湊到才收,排序後超過就 break。 迴圈從 s 開始(不回頭)保證不重複,排序保證 break 不會漏。
