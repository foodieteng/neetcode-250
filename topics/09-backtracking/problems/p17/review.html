PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
46、131 都有 pop_back,這題為什麼沒有?
解答與說明 · ANSWER▾
46、131 的 path 是傳參考、大家共用一份,所以要 pop 還原;這題 res 傳值,每層各一份。

res + c 是新字串,交給小孩之後,這一層的 res 完全沒變,下一圈直接接新字母就好。
第 2 題10 分
把參數改成 string& res,迴圈要怎麼寫才對?只寫 res += c 會怎樣?
解答與說明 · ANSWER▾
res.push_back(c); dfs(ans, res, digits, i + 1); res.pop_back();

只寫 res += c(沒有 pop):"2" 得到 [a,ab,abc],4,680 組全錯。push / pop 版 0 錯,而且 "7979" 從 9.89 µs 變 4.58 µs。
第 3 題10 分
mp 為什麼前兩個是 ""?
解答與說明 · ANSWER▾
讓 digits[i] - '0' 直接就是 index:'2' - '0' = 2 → mp[2] = "abc"。

0、1 沒有字母,放 "" 正好:輸入裡出現 0 或 1 時迴圈跑 0 次,那條路沒有答案(實測 "1"、"21" 都回 [])。
第 4 題10 分
輸入 "" 你的程式回傳什麼?為什麼舊版 LeetCode 會判錯?
解答與說明 · ANSWER▾
回傳 [""]:i = 0 已經 ≥ size,直接把空的 res 收進去。

舊版題目允許空字串,要求 [],所以會錯。現在限制 1 ≤ digits.length,不會遇到;要保險就在開頭加 if (digits.empty()) return {};。
第 5 題10 分
"7979" 為什麼剛好 341 次 dfs?
解答與說明 · ANSWER▾
每一層的節點數 × 4:1 + 4 + 16 + 64 + 256 = 341。

7 和 9 都有 4 個字母,所以每個節點有 4 個小孩。"2222" 每層 × 3:1 + 3 + 9 + 27 + 81 = 121。最後一層就是答案數。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,照程式手走 "2" · 在迴圈裡 += 不撤銷 vs push / pop:逐步寫出關鍵變數的變化,最後回傳什麼?決定結果的是哪一步?
解答與說明 · ANSWER▾

第 2 題 的兩種寫法,插樁實跑。差別在第二圈開始時 res 是什麼。

// 錯:迴圈裡 res += c,沒有撤銷 c='a' res → "a" 收 "a" c='b' res → "ab" 收 "ab" ← 上一圈的 a 還在 c='c' res → "abc" 收 "abc" // OUTPUT: [a,ab,abc] ✗
// 對:string& res + push_back / pop_back push 'a' → "a" 收 "a" pop → "" push 'b' → "b" 收 "b" pop → "" push 'c' → "c" 收 "c" pop → "" // OUTPUT: [a,b,c]
每一圈開始時 res 必須回到「這一層進來時的樣子」。 傳值 + res + c 天生做到;共用一份就要靠 pop_back。

PART C · 應用題// 3 題 × 13–14 分

第 7 題13 分
不用遞迴,用一個 queue / vector 一位一位擴展,要怎麼寫?
解答與說明 · ANSWER▾
從 {""} 開始,每一位把目前每個字串都接上這位的每個字母,換成新的一排。

vector<string> cur = {""}; for (char d : digits) { vector<string> nxt; for (auto& s : cur) for (char c : mp[d - '0']) nxt.push_back(s + c); cur = nxt; }。 對拍用的就是這種,4,680 組和你的輸出連順序都一樣。
第 8 題13 分
再給一本字典,只要列出「字典裡有的單字」,要怎麼提早剪掉?
解答與說明 · ANSWER▾
把字典建成 Trie,dfs 時同時沿著 Trie 往下走;Trie 節點沒有這個字母就不往下。

和 79 複習頁 第 8 題 提到的 212 是同一招:前綴已經不是任何單字的開頭,就整棵子樹剪掉。
第 9 題14 分
只要第 k 個組合(照字典序,從 0 算),不想列出全部,怎麼直接算?
解答與說明 · ANSWER▾
把 k 寫成「混合進位」:最後一位的進位是它的字母數,往前每一位乘上後面所有位的字母數。

從最後一位開始:c = mp[d][k % len],k /= len,一路往前,再把字串反過來。O(n),不用列出前面 k 個。 例如 "23" 的第 4 個(從 0 算):4 % 3 = 1 → e,4 / 3 = 1 → b,得到 "be",和走讀裡的 ans#5 一致。
