題目簡介// THE QUESTION

QUESTION

nums 可能有重複的值,回傳所有子集,答案裡不能有重複的子集,順序不限。
1 ≤ n ≤ 10,-10 ≤ nums[i] ≤ 10。

範例:[1,2,2] → [[],[1],[1,2],[1,2,2],[2],[2,2]](6 個,不是 2³ = 8 個);[0] → [[],[0]]。

程式就是 78 加上 40 的那一行:排序,然後 if (i > s && nums[i] == nums[i-1]) continue;。 78 每個節點都收,所以沒有 break;去重規則和 40 一模一樣。
2

重複從哪裡來// WHERE DUPLICATES COME FROM

照 78 的寫法跑 [1,2,2],樹會有 8 個節點,其中 [1,2] 和 [2] 各出現兩次 —— 一次用 2₁、一次用 2₂。 重複的永遠是「同一個父節點底下,選了值一樣的兩個兄弟」,它們長出來的子樹內容一模一樣。

寫法[1,2,2] 的呼叫結果
78 原樣(沒有去重)8[1,2]、[2] 各兩次
78 + 最後丟 set8對,但重複的都要先走出來
排序 + 同層去重(我的)6對,重複的子樹整棵不長
差距在重複多的時候才看得出來:20 個 5,答案只有 21 個(0~20 個 5),同層去重 21 次呼叫; 不去重要 1,048,576 次(113.6 ms),全部都是重複。
3

核心策略 · 三步驟// THE SHAPE

  1. 排序:相同的值排在一起,才能只比相鄰的。
  2. 一進來就收:ans.push_back(path)(和 78 一樣,每個節點都是子集)。
  3. 同層只試第一個:i > s 且和前一個相同就跳;否則 push → dfs(i + 1) → pop。

5

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 為什麼留「第一個」,不是最後一個

同一層選 2₁ 之後,下一層還能挑 2₂(所以 [2,2] 拿得到);選 2₂ 之後就沒有 2 可以挑了。 第一個的子樹包含了後面每一個的子樹,所以要留第一個。 改成和 nums[i+1] 比(留最後一個)會漏掉兩個都選的情況:[1,1] → [[],[1]],3,279 組錯 3,264 組。

LEMMA 2 · 為什麼是 i > s

和 40 同一個理由:i == s 是這一層的第一個選擇,和 nums[i-1] 相同只代表上一層剛選了同樣的值,那是「同一個子集裡有兩個 2」,要留。 寫 i > 0 一樣會漏:[1,1] → [[],[1]]。

一句洞察// INSIGHT

78 + 排序 + 「同一層相同的值只試第一個」。 每個節點剛好對應一個不同的子集,呼叫次數就是答案數。
