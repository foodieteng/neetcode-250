題目簡介// THE QUESTION

QUESTION

m × n 的字母格 board 和一個字串 word。word 能不能由上下左右相鄰的格子依序拼出來?同一格最多用一次。
1 ≤ m, n ≤ 6,1 ≤ word.length ≤ 15,只有大小寫英文字母。

範例 board = [[A,B,C,E],[S,F,C,S],[A,D,E,E]]:"ABCCED" → true、"SEE" → true、"ABCB" → false(第二個 B 要回頭用同一格)。

和 46 一樣是「做選擇 → 遞迴 → 撤銷」,只是選擇變成「往哪個方向走」,而 used[] 直接寫在 board 上: 走進來就把格子改成 '#',四個方向都失敗就改回原本的字母。
2

為什麼用 DFS + 回溯// WHY BACKTRACKING

A 先列出所有路徑,再比對是不是 word 指數爆炸
每條不重複走的路徑都生出來。大部分路徑第一、二個字母就不對了,卻還是整條走完。
× REJECT · TLE
B BFS 狀態太大
「每格只能用一次」是每條路徑自己的限制。BFS 同時展開很多路徑,每個 queue 元素都要帶一份自己的 visited,記憶體跟著路徑數長。
△ REJECT · 記憶體
BOTH FAIL · ADOPT
C DFS + 回溯,visited 原地寫成 '#' 一次只走一條路
一次只有一條路徑,所以整張 board 就是那唯一一份 visited:進來標 '#',失敗離開時改回去。 第 i 個字母不符就立刻回頭(剪枝),不會白走。額外空間只有遞迴深度 O(L)。
● ADOPT · 不符就剪,board 當 visited
3

核心策略 · 三步驟// THE SHAPE

  1. 掃起點:每一格都當一次 dfs(r, c, 0) 的起點,有一個成功就回傳 true。
  2. dfs 先比字元:board[r][c] != word[i] → false;相等而且 i 是最後一個 → true。
  3. 標 → 走 → 還原:標 '#',試上下左右(出界或是 '#' 就跳過),任一成功就直接 true;全部失敗 → 改回原字母、回傳 false。
4

5

標記和還原,少一個都不行// TWO LEMMAS

LEMMA 1 · 不標 # → 同一格被用兩次(答案變多)

board = ["AA"]、word = "AAA":只有兩格,不可能拼出三個 A。 不標記的話會走 (0,0) → (0,1) → (0,0),回傳 true。 實測窮舉 42,284 組錯 8,584 組,全部都是「不該 true 卻 true」。 把還原寫在 for 迴圈前面(標完馬上改回去)效果完全一樣,錯的組數一模一樣。

LEMMA 2 · 失敗不還原 → 上一個起點留下的 # 擋住正解(答案變少)

board = ["BAA"]、word = "AAB":起點 (0,1) 標 #、走到 (0,2) 標 #,之後走不下去,但兩格都沒改回來。 輪到起點 (0,2) 時,它自己已經是 #,唯一的正解 (0,2) → (0,1) → (0,0) 被擋掉 → 回傳 false。 窮舉錯 4,878 組,全部都是「該 true 卻 false」。 成功時不還原沒關係:回傳 true 之後沒有人再讀 board(但 board 會留著 #,呼叫的人要用就要先複製)。

一句洞察// INSIGHT

一次只走一條路,所以 board 本身就能當 visited:進來標 #,失敗改回去。 不標 → 重複用格(多出 true);不還原 → 擋住別的起點(少了 true)。

// ONE-LINE TAKEAWAY
每格當起點 dfs;先比字元、最後一個就 true;標 '#' → 上下左右 → 全失敗才改回原字母。不標會重複用格,不還原會擋住後面的起點。O(m·n·3^L)、O(L)。
