PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
dfs 開頭為什麼要「先比字元,再看 i == word.size() - 1」?順序對調會怎樣?
解答與說明 · ANSWER▾
i == last 只代表「走到第 L 格」,不代表第 L 個字母對;要先比完才能收。

對調後最後一個字母永遠不會被比:["A"],"B" 直接回傳 true。實測窮舉 42,284 組錯 5,622 組,全部是多出來的 true。
第 2 題10 分
四個方向都失敗時,為什麼一定要把格子改回原字母?找一個不還原就錯的最小例子。
解答與說明 · ANSWER▾
失敗的路留下的 # 會擋住之後的起點(或之後的方向)要走的路。

最小例子 ["BAA"],"AAB":起點 (0,1) 標了 (0,1)、(0,2) 後失敗沒改回;輪到起點 (0,2) 時它已經是 #,唯一的正解 (0,2) → (0,1) → (0,0) 走不了 → false(正解 true)。窮舉錯 4,878 組,全部是少掉的 true。
第 3 題10 分
成功時直接 return true,路上的格子都沒還原。這樣對嗎?有什麼副作用?
解答與說明 · ANSWER▾
答案對:回傳 true 之後沒有人再讀 board。副作用是 board 被改掉了。

"SEE" 跑完是 A B C E / S F C # / A D E #。隨機 200,000 組裡,word 長度 ≥ 2 而回傳 true 的,board 全部留著 #;回傳 false 的 149,236 組全部還原乾淨。 如果呼叫的人之後還要用 board,就傳一份複本,或在 return true 前也還原(實測同樣 0 錯)。
第 4 題10 分
為什麼 visited 可以直接寫在 board 上,不用像 BFS 那樣每條路徑一份?
解答與說明 · ANSWER▾
DFS 一次只有一條路徑在進行,而且 # 一定在離開時清掉 —— 任何時刻 board 上的 # 剛好就是目前這條路徑。

這和 46 的 used[] 是同一件事:一份共用的狀態,做選擇時改、撤銷時改回。BFS 同時有很多條路徑,共用一份就分不清是誰標的。
第 5 題10 分
鄰居判斷裡的 board[nr][nc] == '#' 拿掉會錯嗎?那把 '#' 換成 'A' 呢?
解答與說明 · ANSWER▾
拿掉不會錯:# 不是字母,進到下一層會被「先比字元」擋掉。換成 'A' 會錯:標過的格子又能被配到。

拿掉檢查:窮舉、隨機都 0 錯。標記用 'A':窮舉錯 6,478 組,最小反例 ["AA"],"AAA" → true。標記一定要用 word 裡不可能出現的字元。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,照程式手走 "ABCCED" · 8 次 dfs,一次都沒回頭:逐步寫出關鍵變數的變化,最後回傳什麼?決定結果的是哪一步?
解答與說明 · ANSWER▾

board A B C E / S F C S / A D E E,範例 1。概念頁的 "SEE" 有回頭,這組沒有 —— 拿來對照「沒失敗就不會還原」。

// 起點 (0,0) 就對了 #1 (0,0) A i=0 標 # 下 (1,0) → #2 S ≠ B #3 (0,1) B i=1 標 # 下 (1,1) → #4 F ≠ C · 左 (0,0) 是 # 跳過 #5 (0,2) C i=2 標 # 下 (1,2) → #6 (1,2) C i=3 標 # 上 (0,2) 是 # 跳過 · 下 (2,2) → #7 (2,2) E i=4 標 # 上 (1,2) 是 # 跳過 · 下 出界 · 左 (2,1) → #8 (2,1) D i=5 最後一個 → true
// 一路往上傳 #8 → #7 → #6 → #5 → #3 → #1 → exist 回傳 true // OUTPUT: true(8 次 dfs;board 留下 # # # E / S F # S / A D # E)
#2、#4 不符只是那一次呼叫回 false,不會觸發還原 —— 還原只發生在「標過 # 的那一層四個方向全失敗」。 這組沒有那種層,所以 0 次還原;"SEE" 有 2 次((1,0) 和 (0,3))。

PART C · 應用題// 3 題 × 13–14 分

第 7 題13 分
Follow-up:board 變大時怎麼剪枝?6×6 全 A、找 "A"×14 + "B" 要怎麼救?
解答與說明 · ANSWER▾
兩招:先數字母(word 某個字母比 board 多 → 直接 false),以及從比較稀有的那一端開始找(必要時把 word 反過來)。

6×6 全 A、"A"×14 + "B":原本 4,120,732 次 dfs(約 70 ms);反過來找 "B" + "A"×14 只要 36 次(每個起點第一個字就不符);先數字母 board 沒有 B,0 次。
第 8 題13 分
改成一次給很多個 word(212 · Word Search II ↗),每個 word 跑一次這題的解法會有什麼問題?
解答與說明 · ANSWER▾
每個 word 都把整張 board 重新搜一次,共同前綴(例如 oath、oat)被重複走。

212 的做法:把所有 word 建成 Trie,每個起點只跑一次 dfs,沿著 Trie 往下走;Trie 節點沒有這個字母就剪掉,走到結尾就收答案。標 # / 還原的骨架和這題一樣。
第 9 題14 分
如果 board 是 const、不能改,要怎麼記 visited?
解答與說明 · ANSWER▾
另外開一個 bool visited[6][6](或用 bitmask),標記、還原的位置和現在一模一樣。

進 dfs 時 visited[r][c] = true,四方向全失敗時改回 false;鄰居判斷改成看 visited。時間不變,多 O(m · n) 空間。成功時也記得 visited 是自己的,不會動到 board。
