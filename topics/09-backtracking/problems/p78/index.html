題目簡介// THE QUESTION

QUESTION

nums 裡的數字都不相同,回傳所有子集(包含空集合),不能重複,順序不限。
1 ≤ n ≤ 10,-10 ≤ nums[i] ≤ 10。

範例:[1,2,3] → 8 個子集 [] [1] [2] [1,2] [3] [1,3] [2,3] [1,2,3];[0] → [] [0]。

和 1863 是同一棵樹,差別只在每個節點要存的東西:1863 只要一個數字 cur,這題要存整個子集。 所以要帶著一個 path 往下走,走下去時 push、回來時 pop —— 這就是「回溯」。

核心策略 · 三步驟// THE SHAPE

  1. 一進來就記:ans.push_back(path) —— for 迴圈寫法每個節點都是一個子集。
  2. 從 s 開始挑下一個:path.push_back(nums[i]),遞迴 dfs(i + 1)(只往後挑,不會重複)。
  3. 回來就撤銷:path.pop_back(),讓下一圈的兄弟從同一個 path 出發。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 傳值了,為什麼還要 pop?

傳值只保證「被呼叫的那層改不到我的 path」。可是 for 迴圈是在同一層裡跑的: 第一圈 push 了 nums[s],不 pop 的話,第二圈的 push 會疊在上面。 實測:傳值但拿掉 pop,[1,2] → [[],[1],[1,2],[1,2]],應該是 [2] 的地方變成 [1,2];窮舉錯 3,612 / 3,619。

LEMMA 2 · 傳參考時,ans.push_back(path) 會不會跟著被改掉?

不會。ans.push_back(path) 把 path 複製一份放進 ans,之後 path 怎麼 push / pop 都影響不到已經存進去的那份。 所以傳參考只少了「參數那一次複製」,存答案那次複製兩種寫法都有。 n = 20 實測:傳值多複製 10,485,760 個元素,121.71 ms vs 104.14 ms。

一句洞察// INSIGHT

path 跟著遞迴走:往下 push、回來 pop,兄弟節點才會從同一個 path 出發。 傳值或傳參考都對;pop 在兩種寫法裡都不能省,存答案時 push_back 會自動複製。
