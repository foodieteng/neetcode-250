題目簡介// THE QUESTION

QUESTION

把字串 s 切成好幾段,每一段都要是回文。回傳所有切法,順序不限。
1 ≤ s.length ≤ 16,只有小寫英文字母。

範例:"aab" → [["a","a","b"],["aa","b"]];"a" → [["a"]]; "racecar" → 4 種(r a c e c a r、r a cec a r、r aceca r、racecar)。

和 78 / 39 一樣是「從 start 往後挑」,只是這題挑的不是一個數,而是一段 s[start..end]。 這段是回文就切下來,下一層從 end + 1 繼續;切到 start 走到底,就收一個答案。

3

核心策略 · 三步驟// THE SHAPE

  1. start 走到底就收:start >= s.size() → 整條都切完了,ans.push_back(path)。
  2. end 從 start 往右:第一段 = s[start..end],長度 end - start + 1;不是回文就換下一個 end(continue,不是 break)。
  3. 切 → 遞迴 → 撤銷:push 這段,dfs(end + 1),回來後 pop。

輸出順序是「第一段短的先」:[a,a,b] 在 [aa,b] 前面;整個字串一段永遠最後。 因為 end 從 start 開始往右試,短的先切。
5

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 不是回文要 continue,不能 break(和 47 同一個判斷)

47 的規則:只有「這個 i 不行,後面的 i 一定也不行」才能 break。 回文不是這樣:"aba" 裡 "ab" 不是回文,再長一格的 "aba" 是。 寫成 break → "aba" 只剩 [[a,b,a]],少了 [aba]。 窮舉 3,138 組錯 2,668 組;全部同一個字母的輸入("aaa" 這種)每段都是回文,break 永遠不會執行 —— 470 組剛好過。

LEMMA 2 · 下一層從 end + 1 開始,不是 start + 1、也不是 end

切下的是 s[start..end],剩下的從 end + 1 開始。 寫成 start + 1:切了 "aa" 之後第二個 a 又被切一次,"aa" → [[a,a],[aa,a]](段重疊,窮舉錯 3,101 組)。 寫成 end:end == start 時用同一個 start 遞迴自己,"a" 就無限遞迴,實跑 Segmentation fault。

複雜度// COMPLEXITY

最壞是全部同一個字母:每個空隙都可以切或不切,2n−1 種切法全都是答案,每個答案總長 n。光是把答案寫出來就要 n · 2n−1 個字元。

一句洞察// INSIGHT

每一層只決定「第一段切到哪」,是回文才往下走,下一層從 end + 1 開始。 回文不會因為變長就一定不是 → 不是回文只能 continue。

每層決定「第一段切多長」:end 從 start 往右,s[start..end] 是回文才 push、遞迴 end + 1、pop;不是回文要 continue 不能 break(「ab」不是回文,「aba」是)。最壞全同字母 2^(n-1) 種切法,O(n·2^n)。
