PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
s[start..end] 不是回文時,為什麼要 continue,不能 break?找一個 break 會錯的最短輸入。
解答與說明 · ANSWER▾
break 的前提是「後面的 end 一定也不行」,但回文不是這樣:短的不是,長的可能是。

最短反例 "aba":"ab" 不是回文,"aba" 是。break 版輸出 [[a,b,a]],少了 [aba]。窮舉 3,138 組錯 2,668 組;全部同字母的輸入剛好都過。
第 2 題10 分
遞迴為什麼傳 end + 1?傳 start + 1 或 end 各會發生什麼事?
解答與說明 · ANSWER▾
切下的是 s[start..end],沒切的部分從 end + 1 開始。

start + 1:下一層又從這段中間開始,段會重疊,"aa" → [[a,a],[aa,a]],而且答案數爆量。 end:end == start 那一圈會用同一個 start 遞迴自己 → 無限遞迴,"a" 就 Segmentation fault。
第 3 題10 分
path.push_back(s.substr(start, L)) 的第二個參數是什麼?寫成 s.substr(start, end) 會怎樣?
解答與說明 · ANSWER▾
substr(pos, len) 的第二個參數是長度,不是結尾位置。

所以要 L = end - start + 1。寫成 substr(start, end) 時,"a" 的 start = end = 0,長度 0 → [[""]],所有輸入都錯。少寫 +1 也一樣得到 [[""]]。
第 4 題10 分
為什麼最壞情況是「全部同一個字母」?答案有幾個?
解答與說明 · ANSWER▾
全部同字母時每一段都是回文,n − 1 個空隙每個都能切或不切 → 2n−1 個答案,一個都剪不掉。

實測 n = 16 的所有 {a,b} 字串(65,536 個):最多 32,768 個答案,只有 "a"×16 和 "b"×16 達到;第二名 16,384(例如 "aaaaaaaaaaaaaaab")。答案總字元 524,288 = n · 2n−1。
第 5 題10 分
面試官說「isPalindrome 可以更快」。你第一個改什麼?回文表 pal[i][j] 一定更快嗎?
解答與說明 · ANSWER▾
先把 string s 改成 const string& s:不用每次複製字串,"a"×16 從 14.78 ms 變 4.27 ms。

回文表在 n = 16 沒有更快(4.63 ms):最壞情況每段都是回文、本來就沒剪掉什麼,剩下的時間在 substr 和把 path 複製進 ans。回文表要等字串長、判斷佔大宗時才划算。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,照程式手走 "aba" · continue 跳過 "ab",才走得到 "aba":逐步寫出關鍵變數的變化,最後回傳什麼?決定結果的是哪一步?
解答與說明 · ANSWER▾

第 1 題 的反例,插樁實跑。重點在 #1 的迴圈:end = 1 不是回文,end = 2 是。

// end = 0:第一段 "a" #1 dfs(0) end=0 "a" 回文 → push [a] → #2 dfs(1) #2 end=1 "b" 回文 → push [a,b] → #3 dfs(2) #3 end=2 "a" 回文 → push [a,b,a] → #4 dfs(3) 收 ans#1 [a,b,a] → pop #2 end=2 "ba" 不是回文 #1 pop → []
// end = 1、2:break 和 continue 在這裡分岔 #1 end=1 "ab" 不是回文 → continue(break 的話迴圈在這裡結束) #1 end=2 "aba" 回文 → push [aba] → #5 dfs(3) 收 ans#2 [aba] → pop // OUTPUT: [[a,b,a],[aba]](5 次 dfs、6 次回文檢查)
"ab" 不是回文,不代表 "aba" 不是 —— 這就是回文「不單調」。 break 版在 end = 1 就停,輸出只剩 [[a,b,a]]。

PART C · 應用題// 3 題 × 13–14 分

第 7 題13 分
寫出 pal[i][j] 回文表的遞推式和填表順序。
解答與說明 · ANSWER▾
pal[i][j] = (s[i] == s[j]) && (j - i < 2 || pal[i+1][j-1])。

pal[i][j] 要用到 pal[i+1][j-1],所以 i 從大到小、j 從 i 往右填。O(n²) 時間和空間。dfs 裡把 isPalindrome(s, start, end) 換成 pal[start][end]。
第 8 題13 分
如果只要「有幾種切法」,不用列出來,要怎麼改?
解答與說明 · ANSWER▾
不用列出來就不用回溯:cnt[i] = 從 i 開始的後綴有幾種切法。

cnt[n] = 1;cnt[i] = Σ cnt[j+1](所有 pal[i][j] 為真的 j)。答案 cnt[0],O(n²)。 它算出來的數就是本題的答案個數,例如 "a"×16 是 32,768、"abababababababab" 是 987。
第 9 題14 分
改成「最少切幾刀才能讓每段都是回文」(132 ↗),回溯還適合嗎?
解答與說明 · ANSWER▾
不適合:只要一個最小值,不用列出所有切法,改用 DP。

cut[i] = s[0..i] 最少幾刀;若 pal[0][i] 則 0,否則 cut[i] = min(cut[j-1] + 1)(所有 pal[j][i] 為真的 j)。配上回文表 O(n²)。回溯會把指數多的切法全走一遍。
