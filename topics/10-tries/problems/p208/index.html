題目簡介// THE QUESTION

QUESTION

實作 Trie 類別:insert(word) 加入一個字;search(word) → 這個字完整插入過嗎?startsWith(prefix) → 有沒有任何插入過的字以它開頭?
1 ≤ word.length, prefix.length ≤ 2000,只有小寫字母,三種操作合計最多 3 · 104 次。

範例:insert("apple") 之後 search("apple") → true、search("app") → false、startsWith("app") → true;再 insert("app"),search("app") 才變 true。

search 和 startsWith 走的是同一條路,差別只在走完之後: startsWith 走得完就 true;search 還要問終點「有人在這裡結束嗎」—— 這個問題就是 isWord。
2

為什麼用 Trie// WHY A PREFIX TREE

A vector<string> 存起來,查詢時全部掃 O(N · L) / 次
每次 search / startsWith 都要和已存的 N 個字逐一比。字越多越慢,而且共同前綴(apple、app)被重複比了一次又一次。
× REJECT · TLE
B unordered_set<string> 前綴沒辦法查
search 是 O(L) 雜湊,很好。但 startsWith 問的是「有沒有某個字以它開頭」,雜湊只能比整串。要嘛全掃,要嘛 insert 時把 L 個前綴全塞進另一個 set(O(L²) 字元)。
△ REJECT · 前綴要另外處理
BOTH FAIL · ADOPT
C Trie:每個節點是「一段前綴」,往下一層多一個字元 O(L) / 次,與 N 無關
共同前綴只存一次(app 和 apple 共用 a → p → p)。三個操作都是從 root 沿著字元往下走 L 步,跟已經存了幾個字無關。 走得到 = 前綴存在;走到的節點 isWord = 整個字存在。
● ADOPT · 前綴天生共用
3

核心策略 · 三步驟// THE SHAPE

  1. 節點:child[26] 一格對一個字母(全部初始化成 nullptr)+ 一個 isWord。
  2. insert:從 root 一個字元一層往下;那格是 nullptr 才 new,已經有就沿用;走完把終點 isWord = true。
  3. search / startsWith:一樣往下走,半路遇到 nullptr → false;走完了,startsWith 直接 true,search 回傳終點的 isWord。

兩種 false、一個 new 的條件// TWO LEMMAS

LEMMA 1 · 節點存在 ≠ 這個字存在

只插入 "apple" 時,節點 "app" 已經在樹上(它是 apple 的必經之路),但沒有人在這裡結束。 所以 search 不能只看「走不走得到」,要看 isWord;startsWith 問的正好就是「走不走得到」,所以不看。 search("app") = false、startsWith("app") = true,差別就只有最後那一行。

LEMMA 2 · insert 一定要「nullptr 才 new」

如果每個字元都無條件 child[i] = new TrieNode(),插入 "app" 時會把 a、ap、app 換成全新的空節點, 原本掛在下面的 appl → apple 整串被切斷(舊節點也洩漏)。之後 search("apple") 就變 false。 Trie 的重點就是共用前綴;每次重建等於把共用拆掉。
實測隨機 20,000 組錯 147 組,最小反例只要三步:insert("a") → insert("aa") → search("a") 回傳 false(第二次 insert 把有 isWord 的 "a" 節點換掉了)。

複雜度// COMPLEXITY

每個操作從 root 往下最多走 L 步,每步是一次陣列索引。空間是節點數 × 每個節點的大小:每次 insert 最多新增 L 個節點。

每次操作 O(L)　·　空間 O(總插入字元數 · 26)(每個節點 26 個指標)
實測(64-bit, -O2)值
sizeof(TrieNode)216 B(26 × 8 + bool,補齊到 8)
3 · 104 次 insert 同一個 "a"×20002,001 個節點
10,000 個隨機長度 2000 的字19,978,192 個節點、峰值約 4.2 GiB、3.3 s

一句洞察// INSIGHT

節點代表前綴,isWord 代表「有字在這裡結束」。 insert 缺才建;search 要走得完而且 isWord;startsWith 只要走得完。
