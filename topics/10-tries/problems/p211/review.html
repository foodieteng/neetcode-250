範例 Trace// "..x" · 找不到,每條路都要走完

同一個字典 {bad, dad, mad}。概念頁的三個查詢都找到就停;這組找不到,看「全部失敗」要付多少。實跑插樁輸出。

// 第 0 層 '.':root 的 26 格 dfs(0, root) '.' → 試 a..z a、c、e..l、n..z → 23 次 dfs(1, null),① 擋下 b、d、m → 3 個真的節點,各自往下
// 第 1 層 '.':每個真節點再試 26 格(以 b 為例) dfs(1, "b") '.' → 試 a..z a → dfs(2, "ba") 'x' → child['x'] → dfs(3, null) ✗ b..z → 25 次 dfs(2, null) ✗ d、m 兩條一模一樣
// 加總 真節點 7 次:root、b、ba、d、da、m、ma null 101 次:23 + 3 × 26 // OUTPUT: false(108 次 dfs,其中 101 次是 null)
找不到時沒有提早 return,'.' 的每一格都要試過 —— 108 次裡 94% 是 null。 對照:"..d" 只要 5 次(1 次 null)、"b.d" 只要 4 次,因為第一條路就成功。

應用題// APPLY IT

App 1. search 改成回傳「有幾個加過的字和 pattern 吻合」。dfs 要怎麼改?還能提早停嗎?
App 2. 萬用字元改成 '*',代表任意長度(含 0 個)的字母。dfs 遇到 '*' 有哪幾種選擇?
App 3. 字母格上一次找很多個 word(212 ↗)。這題的「dfs 帶著 Trie 節點往下走」要怎麼和 79 · Word Search 的回溯結合?
// ANSWERS
A1. null 有兩個來源:字母走到不存在的子節點、'.' 迴圈把空格也丟下去。放在開頭一行就全部處理,兩個分支都變短。

拿掉之後,下一層會讀 node->isWord 或 node->child[...],就是對 nullptr 取值。實測隨機 20,000 組有 17,244 組當掉,最小反例是空字典 search("a")。
A2. return dfs(...) 會在第一圈就把結果交出去,不管它是 true 還是 false。

第一圈是 child['a'];它不存在就直接回 false,後面 25 格根本沒試。最小反例 add("b") → search(".") 回 false(正解 true),隨機 20,000 組錯 1,972 組。規則:true 才提早走,false 要繼續。
A3. 會過(只有 -Wreturn-type 警告),但這是未定義行為。

實測 g++ 13 在 -O2 把「函式結尾」當成不可能到達,沒產生 ret 指令,程式直接掉進後面的程式碼:search("a") 在 -O2 segfault、-O0 是 SIGILL,隨機 20,000 組有 17,533 組當掉。這種錯不會「剛好回 false」,要靠 -Wall 抓。
A4. '.' 在前面,分叉發生在樹最寬的上層,每條分支後面還要走二十幾層;'.' 在後面,前面的字母已經把範圍縮成一條路。

實測 5,000 字、114,991 個節點的字典:"..zzz…zb" 要 16,251 次 dfs(1 + 26 + 676 × 24),"zzz…z..b" 只要 76 次。
A5. 跳過 nullptr 的邏輯是對的(0 錯),但幾乎不會變快;真正花時間的是每個節點一次 new。

最壞查詢的 workload 上兩者分不出差別(16,251 次 dfs 裡只有 4.2% 是 null);改成節點池(整塊陣列、編號當指標)才有感:類 LeetCode 測資 167.2 → 33.2 ms。只有 '.' 落在很稀疏的節點上時,跳過 null 才省得多(例如 "z…z.." 那種 93% 的呼叫是 null 的情況)。
A-App 1. 不能提早停:'.' 的迴圈改成把 26 個 dfs 的回傳值加起來,終點回傳 isWord ? 1 : 0,null 回傳 0。

每條路都要走完,所以時間永遠是最壞情況(就像 Trace 那組的 108 次)。字母分支照舊走一條。
A-App 2. '*' 有兩種選擇:配 0 個字母(dfs(idx + 1, node),節點不動),或吃掉一個字母但留在 '*'(對每個存在的子節點 dfs(idx, child))。

任一個 true 就 true。終點條件也要改:idx 到底時看 isWord,但如果剩下的全是 '*' 也能配。狀態 (idx, node) 會重複,可以加記憶化。
A-App 3. 把所有 word 建成 Trie,每個格子當起點跑 79 的回溯;每走一格,同時在 Trie 上往下走一層 —— 和這題的 dfs(idx, node) 一樣,只是「下一個字元」來自格子而不是 pattern。

Trie 上沒有這個字母 → 剪掉這條路;走到 isWord → 收答案(收完把 isWord 關掉避免重複)。標 # / 還原的骨架照 79。
