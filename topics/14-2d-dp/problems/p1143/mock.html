Hmm, let me think about this for a second.

A naive approach would try every subsequence of one string — 2m of them, hopeless at 1000.

This problem reminds me of a two-string grid DP, where each axis is a prefix of one string. dp[i][j] = LCS length of the first i characters of text1 and the first j of text2. If the current characters match, I pair them: the diagonal dp[i-1][j-1] + 1, since both characters get consumed. If they differ, I drop one: max(dp[i-1][j], dp[i][j-1]), up or left. The first row and column are 0 — LCS with an empty string.

The 2-D table: the padding shifts everything by one, so character i-1 sits at row i, and the zero border is the empty string.

class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0)); // first row/col = 0

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1]) {       // equal → pair them
                    dp[i][j] = dp[i - 1][j - 1] + 1; // diagonal +1
                } else {                                // different → drop one char
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); // max of up, left
                }
            }
        }

        return dp[m][n];
    }
};

And the O(n)-space version — one row plus a saved diagonal.

class Solution {
public:
    int longestCommonSubsequence(string a, string b) {
        int m = a.size(), n = b.size();
        vector<int> dp(n + 1, 0);

        for (int i = 1; i <= m; i++) {
            int prev = 0;                     // prev = dp[i-1][j-1] (diagonal)
            for (int j = 1; j <= n; j++) {
                int tmp = dp[j];              // save dp[i-1][j] first (next cell's diagonal)
                if (a[i - 1] == b[j - 1])
                    dp[j] = prev + 1;          // use the saved diagonal
                else
                    dp[j] = max(dp[j], dp[j - 1]); // dp[j]=up, dp[j-1]=left
                prev = tmp;                    // pass the diagonal on to the next cell
            }
        }
        return dp[n];
    }
};

Both are O(mn) time. One thing worth flagging — prev holds the diagonal; I snapshot dp[j] into tmp before overwriting it, since that old value becomes the next cell's diagonal.

And prev resets to 0 at the start of every row, because column 1's diagonal is the empty-string border.

Time is O(mn), space O(mn), or O(n) with one row.

Oh, one more thing — this two-string, diagonal-plus-max pattern is the template for a whole family. Edit distance is the same table, with "inherit the diagonal if equal, else 1 + min of three." The minimum deletions to make two strings equal is just m + n - 2·LCS. And for the contiguous substring version, a mismatch would reset to 0, and the answer would be the table max.
