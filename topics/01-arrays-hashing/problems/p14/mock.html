Here's the code.

class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string prefix = strs[0];              // initial candidate

        for (string str : strs) {
            while (str.find(prefix) != 0) {   // not at the start of str?
                prefix = prefix.substr(0, prefix.size() - 1);  // chop the last char
            }
            if (prefix.empty()) return "";    // nothing left: no common prefix
        }
        return prefix;
    }
};

One loop over the strings, and inside it a while loop that trims prefix until it matches the start of the current string, plus an early return once it's empty.

One thing worth flagging — the loop compares find's result with 0, not with npos. A not-found check would accept a prefix that appears in the middle of the string, which is wrong.

O(S) where S is the total number of characters. Extra space is just prefix.

I
INTERVIEWER

Is there a faster approach, and does yours handle the empty-string case?

C
CANDIDATE

The empty case is handled for free: if any string is empty, prefix gets chopped all the way to "" and I return early — no special-casing.

For speed, a vertical scan is often better: compare column 0 of all strings, then column 1, and stop at the first mismatch or when any string ends. Its edge is early termination — if the prefix is short, it stops after a few columns instead of scanning a long string with find. Both are O(S) worst case; vertical wins when the common prefix is short relative to the strings, horizontal wins on brevity of code.

Time O(S), space O(1) beyond the prefix.

Oh, one more thing — if I had to answer many prefix queries or group strings by shared prefix, I'd build a trie instead; the common prefix is just the path from the root until it branches. And a neat property: the longest common prefix is associative — LCP(a,b,c) = LCP(LCP(a,b),c) — so for huge inputs you can divide and conquer or parallelize the merge. The same trick handles the longest common suffix: reverse every string, run this, reverse the result.
