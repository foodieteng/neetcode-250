Merge Triplets to Form Target Triplet

完整實作// FILTER · MERGE ALL SAFE · COMPARE

p1899.cpp C++17 
class Solution {
public:
    bool mergeTriplets(vector<vector<int>>& triplets, vector<int>& target) {
        vector<int> ans(3, 0);

        for (auto &t : triplets) {
            if (t[0] <= target[0] && t[1] <= target[1] && t[2] <= target[2]) {
                ans[0] = max(ans[0], t[0]);
                ans[1] = max(ans[1], t[1]);
                ans[2] = max(ans[2], t[2]);
            }
        }

        return ans == target;
    }
};

三個官方範例 → true、false、true,都正確。 和「一直兩兩取 max 直到集合不再變大」的暴力閉包比對:n ≤ 3、值 1..3 全部窮舉 551,853 組,加上隨機 200,000 組(n ≤ 6、值 1..4),共 751,853 組,0 筆不一致。原本寫的 ans(3, 1) 在同一批測資錯 21,220 組,所以這裡改成 ans(3, 0),其他一字不改。

每一行各自的意思:

  • ans(3, 0):「目前合出來的結果」。0 比任何真實值(≥ 1)都小,所以沒有三元組被合進來時,ans 一定不會等於 target。
  • auto &t:用參考,不要複製。每個 t 都是一個 vector<int>,複製會配置記憶體;n = 105 實測慢 7 倍。
  • 三個 <= 用 && 串:三位全部不超過才安全。等於是可以的 —— 等於 target 的那一位正是我們要湊的。
  • 三行 max:把這個安全的三元組合進來。順序無關,哪個先合結果都一樣。
  • ans == target:vector 的 == 會逐位比。安全的合起來不會超過 target,所以不相等只代表某一位沒被湊到。

概念頁動畫走了範例 1、範例 3 和起始值陷阱。這裡把範例 2(全部被丟掉)和範例 3(三位各由不同的三元組湊到)用文字再走一次,每一行都是實際印出來的。

// 範例 2:triplets = [[3,4,5],[4,5,6]], target = [3,2,5] ans = [0,0,0] [3,4,5] 第 1 位 4 > 2 → 丟掉 ans = [0,0,0] [4,5,6] 4 > 3、5 > 2、6 > 5 → 丟掉 ans = [0,0,0] ans = [0,0,0] ≠ [3,2,5] // OUTPUT: false target 的第 1 位是 2,但每個三元組的第 1 位都比 2 大

範例 3 至少要三個三元組:[5,2,3]、[2,5,3]、[1,2,5] 各負責一位,沒有哪一個能同時湊到兩位。程式不用管「最少要幾個」,把安全的全部合起來就好 —— 多合的 [2,3,4] 不會讓任何一位超過 5。

三位都 <= target 才合,合就是逐位 max,最後 ans == target。最容易錯:起始值寫 1([[1,1,2]] / [1,1,1] → true)、過濾用 <([[1,1,1]] / [1,1,1] → false)、不過濾或只檢查兩位。O(n) / O(1),用 auto &t 不要複製。
