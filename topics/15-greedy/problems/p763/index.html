題目簡介// THE QUESTION

QUESTION

把小寫字串 s 切成越多段越好,條件是每個字母只能出現在其中一段(按順序接回去要等於 s)。回傳每一段的長度。
1 ≤ s.length ≤ 500,只有小寫英文字母。

範例:"ababcbacadefegdehijhklij" → [9,7,8](切成 ababcbaca / defegde / hijhklij);"eccbbbbdec" → [10](e 和 c 頭尾都有,整串只能是一段)。

一段裡只要出現某個字母,這一段就必須一路延伸到那個字母的最後一次出現。 所以先記下每個字母最後出現在哪(last[]),由左往右掃時用 r 記「這一段至少要到哪」;i 追上 r 的那一刻,就是最早能切的地方。
2

為什麼用 last[] + r// WHY LAST OCCURRENCE

A 每種切法都試 O(2n−1)
n − 1 個空隙,每個切或不切,檢查每個字母是不是只在一段裡,挑段數最多的。正確(驗證時拿它當參考解),但 n = 500 時有 2499 種切法。
× REJECT · TLE
B 每個 i 回頭檢查能不能切 O(n²)
在 i 後面切一刀的條件是「s[0..i] 的字母都沒有在 i 後面再出現」。每個 i 都把前面的字母拿去後面找一遍。正確(隨機 50,000 組和最終解一致),但同一個字母被反覆檢查。
△ 能用 · 重複檢查
PRECOMPUTE LAST · ADOPT
C last[] 一次算好 · r 只往右推 O(n) / O(1)
B 的條件換個說法就是「s[0..i] 裡每個字母的 last 都 ≤ i」,也就是 max(last) == i。這個 max 一邊掃一邊更新就好。和「每種切法都試」比對:{a,b,c} 長度 ≤ 11、{a,b,c,d} 長度 ≤ 9,共 615,243 組,0 錯。
● ADOPT · 每個字元看一次
3

核心策略 · 三步驟// THE LOOP

  1. 記最後位置 —— 掃一遍,last[c] = i,後面的會蓋掉前面的,留下的就是最後一次。
  2. 推 r —— 再掃一遍,遇到 s[i] 就 r = max(r, last[s[i]]):這一段至少要延伸到這裡。
  3. i == r 就切 —— [l..r] 裡每個字母都不會再出現,記下 r − l + 1,下一段從 l = r + 1 開始。

和 45 Jump Game II 是同一個骨架:那裡用 nextEnd 收集「下一層最遠到哪」、i == curEnd 時 step++;這裡用 r 收集「這一段至少到哪」、i == r 時切一刀。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 在 r 切,是最早、也是唯一對的時機

不能更早:r 是 [l..i] 裡某個字母的最後位置;在 r 之前切,那個字母就會被分到兩段。在 r 切一定合法:[l..r] 裡每個字母的 last 都 ≤ r,後面不會再出現。 每一刀都切在最早合法的位置,剩下的字串最長、能切的刀數最多 —— 這就是貪心。驗證時也確認了:段數最多的切法每次都只有一種,而程式找到的就是它。

LEMMA 2 · 先更新 r,再比 i == r;而且要 max

r 的意思是「目前這一段已經被要求延伸到哪」,只能變大。寫成 r = last[s[i]](直接蓋掉)會把剛才的要求忘掉:"aba" 走到 b 時 r 從 2 掉回 1,當場切成 [2,1]。 兩行對調(先比 i == r 再更新 r)也會錯:比的時候還沒把 s[i] 自己的 last 算進去,"aa" 會在第一個 a 就切,得到 [1,1]。兩種錯法都在複習頁逐步走一遍。

複雜度// COMPLEXITY

T = O(n)　　S = O(1)

兩次掃描,每次每個字元 O(1)。last 固定 26 格,和 n 無關;答案最多 26 段(每段至少有一個別段沒有的字母),所以回傳的 vector 也不會隨 n 變大。
