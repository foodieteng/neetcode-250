for each bill b:

One: keep two counters, pay5 and pay10, for the bills I hold.
Two: a $5, keep it; a $10, hand back a five; a $20, hand back 10 + 5 if I have a ten, otherwise 5 + 5 + 5.

class Solution {
public:
    bool lemonadeChange(vector<int>& bills) {
        int pay5 = 0, pay10 = 0;

        for (int& b : bills) {
            if (b == 5) {
                pay5++;
            } else if (b == 10) {
                if (--pay5 < 0) return false;
                pay10++;
            } else {
                // (10, 5) (5, 5, 5)
                if (pay10) {
                    --pay10;
                    if (--pay5 < 0) return false;
                } else {
                    pay5 -= 3;
                    if (pay5 < 0) return false;
                }
            }
        }

        return true;
    }
};

A $5 bumps pay5; a $10 spends a five; a $20 spends a ten and a five if I hold a ten, else three fives — and any time pay5 dips < 0, I return false right away. If the loop finishes, I return true.

One thing worth flagging — in the $20 branch, if I have a ten but no five, I return false without falling back to 5 + 5 + 5. That's correct: the fallback needs three fives and I have zero. And the check is < 0, not <= 0 — landing on exactly zero fives is fine.
