完整實作// TWO COUNTERS · CHECK RIGHT AWAY

p860.cpp C++17 
class Solution {
public:
    bool lemonadeChange(vector<int>& bills) {
        int pay5 = 0, pay10 = 0;

        for (int& b : bills) {
            if (b == 5) {
                pay5++;
            } else if (b == 10) {
                if (--pay5 < 0) return false;
                pay10++;
            } else {
                // (10, 5) (5, 5, 5)
                if (pay10) {
                    --pay10;
                    if (--pay5 < 0) return false;
                } else {
                    pay5 -= 3;
                    if (pay5 < 0) return false;
                }
            }
        }

        return true;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

官方範例 [5,5,5,10,20] → true、[5,5,10,10,20] → false,都正確。 和「每張 20 兩種找法都試」的記憶化搜尋對拍:窮舉長度 1–12 全部 797,160 組 + 隨機 20,000 組(長度 ≤ 200),0 筆不一致。

三個小地方值得講清楚:

  • if (--pay5 < 0) 把「找一張 5」和「檢查夠不夠」寫在同一行:先扣,扣成負數就代表剛剛根本沒有 5。
  • 20 元分支在 pay10 > 0 但 pay5 == 0 時直接 false,沒有退回去試 5 + 5 + 5 —— 不用試,因為 5 是 0 張,三張 5 更不可能。
  • 找不開時 pay10 已經先被扣了,但反正馬上 return,計數壞掉沒關係。
