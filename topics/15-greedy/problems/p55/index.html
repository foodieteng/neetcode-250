題目簡介// THE QUESTION

QUESTION

從 index 0 出發,nums[i] 是在 i 能跳的最大距離(可以跳 1 到 nums[i] 格)。問能不能到達最後一格。
1 ≤ n ≤ 104,0 ≤ nums[i] ≤ 105。

範例:[2,3,1,1,4] → true(0 → 1 → 4); [3,2,1,0,4] → false(不管怎麼跳都會停在 index 3,而那格是 0)。

不用管「怎麼跳」,只要管「最遠能到哪」。 能到 index k,就能到 0..k 的每一格(少跳一點就好)—— 所以「到得了的格子」永遠是一段從 0 開始的前綴,一個整數 farthest 就描述完了。

為什麼只記最遠// WHY FARTHEST REACH

A 回溯:每一格試每一種跳法 指數
同一格會被不同路徑重複走到,沒有記憶就是指數級。加上記憶就變成 B。
× REJECT · TLE
B 可達性 DP:逐格標記能到哪 O(n²)
reach[0] = true,每個到得了的 i 把 i+1..i+nums[i] 都標成 true。正確(驗證時拿它當參考解),但每格最多標 n 個,最壞 O(n²),還要一個 bool 陣列。
△ 能用 · 但做了白工
ADOPT THE SIMPLEST
C 只記最遠能到的 farthest O(n) / O(1)
B 標出來的 true 永遠是一段前綴,所以只需要記它的右端 farthest。每格先問「i 在前綴裡嗎」,再用 i + nums[i] 把右端往外推。一個 int,n = 104 實測約 7–8 µs;和 B 對拍 307,380 組 0 錯。
● ADOPT · 一個 int
3

核心策略 · 三步驟// THE LOOP

  1. 初值 —— farthest = 0:一開始只站在 index 0。
  2. 每一格 i,先檢查 —— i > farthest 代表 i 不在前綴裡,到不了,回傳 false。
  3. 再擴張 —— farthest = max(farthest, i + nums[i])。迴圈跑完都沒被擋下,回傳 true。

和前三題(53、918、978)一樣是「一趟掃描 + 一個累積狀態」,只是這裡的狀態不是「結尾在 i 的最好」,而是「到目前為止能延伸到哪」。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 到得了的格子是一段前綴

如果某條路能落在 k,那最後一跳是從某個 j < k 跳過來的,跳的距離 ≤ nums[j]。把最後一跳縮短,就能落在 j..k 之間的任何一格;再往前歸納,0..k 全部到得了。 所以「能到哪些格」只要一個數字 farthest 描述:i ≤ farthest 就到得了,i > farthest 就到不了,而且 i 後面也都到不了 —— 可以直接回傳 false。

LEMMA 2 · 先檢查、再擴張,順序不能反

檢查時的 farthest 只用了 0..i−1,問的是「前面有沒有人跳得到 i」。若先擴張,farthest ≥ i + nums[i] ≥ i 一定成立,檢查永遠不會觸發。 實測窮舉 87,380 組:順序反過來錯 45,780 組 —— 正好是全部「到不了」的陣列,一組不差;把 > 寫成 >= 則錯 41,600 組,正好是全部「到得了」的(i = 0 時 0 ≥ 0 就回傳 false)。

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

檢查第 i 格時,i ≤ farthest ⇔ i 到得了。所以程式回傳的 false / true 都是對的。

PROOF · 手法:不變量
  1. 到得了的格子是一段前綴。能落在 k,就能落在 0..k 的任何一格 j:路上一定有一跳從 j 或 j 左邊跳到 j 右邊,把那一跳縮短到剛好落在 j 就好。
  2. farthest 剛好是前綴的右端。檢查 i 時,farthest = 0..i − 1 中到得了的格子能跳到的最遠。i 到得了 ⇒ 最後一跳從某個到得了的 j < i 出發,j + nums[j] ≥ i,所以 farthest ≥ i。反過來 i ≤ farthest:farthest 是某個到得了的 j 跳出來的,j 能落在 j + 1..farthest 的任何一格;i ≤ j 時由第 1 步也到得了。
  3. 兩個回傳都正確。i > farthest:i 到不了;而且所有到得了的格子最遠只跳到 farthest < i,後面每一格也到不了 → false 正確。每一格都通過檢查,最後一格就到得了 → true 正確。
面試這樣說 · 30 秒

能到 k 就能到 k 前面每一格,所以到得了的格子是一段前綴,只要記右端 farthest。檢查 i 時,「i 到得了」剛好等於「i ≤ farthest」。一旦 i 超出去,前面所有人最遠都跳不到 i,後面更不用說,所以直接回傳 false。
