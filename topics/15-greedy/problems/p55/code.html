完整實作// CHECK · THEN EXTEND

p55.cpp C++17 
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int n = nums.size();
        int farthest = 0;

        for (int i = 0; i < n; i++) {
            if (i > farthest) return false;

            farthest = max(farthest, i + nums[i]);
        }

        return true;
    }
};

兩個官方範例 → true、false,都正確。 和「從 0 開始逐格標記能到哪」的可達性 DP 對拍 307,380 組:窮舉值 0..3、長度 1–8 全部 87,380 組(可達 41,600 / 不可達 45,780)+ 隨機 200,000 組(長度 ≤ 15、四成是 0)+ 隨機 20,000 組(長度 ≤ 2000、值 0..105、七成是 0),0 筆不一致。

迴圈裡兩行的意思:

  • if (i > farthest) return false;:檢查這一格到不到得了。此時 farthest 只用了 0..i−1 的資訊;i 超過它,代表前面沒有任何一格跳得到 i,i 後面的更不可能。
  • farthest = max(farthest, i + nums[i]);:i 到得了,就用它的跳躍擴張能到的範圍。要 max,因為後面的格子可能跳得比較近。
  • 迴圈跑完沒被擋下,代表每一格(包括最後一格)都到得了,回傳 true。
