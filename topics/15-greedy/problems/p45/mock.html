Here's the plan. It's BFS, but with two numbers instead of a queue: curEnd, the right edge of the current layer, and nextEnd, the farthest one more jump can reach. First, scan i from 0 to n − 2. Second, at each cell, raise nextEnd to i + nums[i]. Third, when i reaches curEnd, the layer is done — add one jump and move curEnd to nextEnd.

// curEnd = right edge of the layer I can reach with `step` jumps
// nextEnd = farthest index reachable with ONE more jump,
// from any cell scanned so far
step = 0, curEnd = 0, nextEnd = 0
for i = 0 .. n-2:  // standing on n-1 needs no jump
  nextEnd = max(nextEnd, i + nums[i])  // cell i grows the next layer
  if i == curEnd:  // current layer fully scanned
    step++  // I must take one more jump
    curEnd = nextEnd  // the next layer ends here
return step

The key idea: the code never picks which cell to jump from — it only tracks how far each layer goes.

One thing worth flagging — the loop stops at n − 2. Scanning the last index fires the check one extra time, so the answer is always one too high.

A queue-based BFS works too, but this is O(1) space.

Does this approach sound good, or would you rather I think of another way?

class Solution {
public:
    int jump(vector<int>& nums) {
        int step = 0, curEnd = 0, nextEnd = 0;

        for (int i = 0; i < nums.size() - 1; i++) {
            nextEnd = max(nextEnd, i + nums[i]);

            if (curEnd == i) {
                step++;
                curEnd = nextEnd;
            }
        }

        return step;
    }
};

Three ints at 0 — step, curEnd, nextEnd — and one loop while i < nums.size() - 1. Inside, nextEnd takes the max with i + nums[i]; then, if curEnd == i, step++ and curEnd = nextEnd. That matches the plan line by line.

One thing worth flagging — the order inside the loop matters. nextEnd must update before the check, because cell i belongs to the layer I'm closing. Swap them and the first layer closes with edge 0, so example 1 returns 1 instead of 2.

Also, size() - 1 is unsigned, so there's one harmless -Wsign-compare warning; storing int n = nums.size(); first removes it.
