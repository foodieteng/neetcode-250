完整實作// COLLECT NEXT LAYER · CROSS THE BOUNDARY

p45.cpp C++17 
class Solution {
public:
    int jump(vector<int>& nums) {
        int step = 0, curEnd = 0, nextEnd = 0;

        for (int i = 0; i < nums.size() - 1; i++) {
            nextEnd = max(nextEnd, i + nums[i]);

            if (curEnd == i) {
                step++;
                curEnd = nextEnd;
            }
        }

        return step;
    }
};

兩個官方範例 → 2、2,都正確。 和 BFS 最短路對拍 261,600 組(題目保證到得了,所以只測到得了的):窮舉值 0..3、長度 1–8 裡到得了的全部 41,600 組 + 隨機 200,000 組(長度 ≤ 15)+ 隨機 20,000 組(長度 ≤ 2000、值 0..1000),0 筆不一致。

每一行在做什麼(「層」= 跳同樣次數能到的那一段格子,見概念頁):

這一行白話
curEnd = 0跳 0 次的那一層只有 index 0,所以這一層的盡頭是 0
nextEnd = max(nextEnd, i + nums[i])從 i 再跳一次能到 i + nums[i];收集「這一層的格子再跳一次」最遠能到哪
if (curEnd == i)走到這一層的盡頭了:這一層每一格都看過,nextEnd 已經是真的「多跳一次的最遠」
step++; curEnd = nextEnd;要往更遠一定得再跳一次;下一層就是 (curEnd, nextEnd],把盡頭移過去
i < nums.size() − 1站在最後一格不用再跳,所以不看最後一格
step++ 的意思不是「我從 i 跳了一下」,而是「跳 step 次能到的格子都看完了,還沒到終點,所以至少要再多一跳」。 程式從頭到尾沒決定過「從哪一格起跳」—— 只決定下一層的範圍。實際最佳路線藏在「是哪一格把 nextEnd 推到最遠」裡,但答案只問次數,不用記。
