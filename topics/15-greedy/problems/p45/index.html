題目簡介// THE QUESTION

QUESTION

和 55 一樣從 index 0 出發、nums[i] 是最大跳躍距離,但這次保證到得了最後一格,問最少跳幾次。
1 ≤ n ≤ 104,0 ≤ nums[i] ≤ 1000。

範例:[2,3,1,1,4] → 2(0 → 1 → 4);[2,3,0,1,4] → 2(index 2 的 0 不影響)。

「最少幾次」= 最短路徑,本來是 BFS 的工作:第 0 層是起點,第 1 層是跳一次能到的格子,第 2 層是跳兩次才到的……終點在第幾層,答案就是幾。 這題的特別之處:每一層都是連續的一段,所以 BFS 不用 queue,用兩個邊界 curEnd / nextEnd 就能一層一層往右推。
2

先看懂「層」// FROM 55 TO LAYERS

55 證明了:能到 k,就能到 0..k 的每一格(少跳一點就好)。同樣的道理套在「跳幾次」上:

// [2,3,1,1,4] 的三層 index 0 1 2 3 4 nums 2 3 1 1 4 第幾層 0 1 1 2 2 └─┘ └─────┘ └─────┘ 跳 0 次 [0..0] 跳 ≤ 1 次 [0..2] ← 從 0 最遠到 0+2 = 2 跳 ≤ 2 次 [0..4] ← 從第 1 層的 1、2 最遠到 max(1+3, 2+1) = 4,已含終點 // 終點 4 在第 2 層 → 答案 2
  • 跳 ≤ k 次能到的格子永遠是一段前綴 [0..endk],所以第 k 層 = (endk−1, endk]。
  • 下一層的右端 = 這一層每一格的 i + nums[i] 取最大。
  • 程式裡:curEnd 是目前這一層的右端,nextEnd 是邊掃邊收集的「下一層右端」。
3

為什麼用分層// WHY LAYERS

A 每次都跳最遠 錯
直覺的貪心,但「這一步跳最遠」不代表「下一步也能跳遠」。[4,1,1,3,1,1,1] 走 0 → 4 → 5 → 6 要 3 跳,正解 0 → 3 → 6 只要 2;落在 0 上還會卡死(範例 2 就是)。窮舉錯 11,884 組。
× REJECT · WRONG
B DP / 一般 BFS O(n²)
dp[j] = min(dp[i] + 1),所有 i + nums[i] ≥ j 的 i;或把每個 i 往 i+1..i+nums[i] 連邊做 BFS。都正確(驗證時拿 BFS 當參考解),但每格最多連 n 條邊。
△ 能用 · 但做了白工
ADOPT THE LAYERS
C 分層 BFS:只記兩個邊界 O(n) / O(1)
因為每一層是連續的一段,BFS 的 queue 可以換成 curEnd(這一層到哪)和 nextEnd(下一層到哪)。每格看一次,走到 curEnd 就換層、step++。n = 104 實測約 6 µs;和 BFS 對拍 261,600 組 0 錯。
● ADOPT · 兩個邊界
4

核心策略 · 三步驟// THE LOOP

  1. 初值 —— step = 0,curEnd = 0(第 0 層只有起點),nextEnd = 0。
  2. 每一格 i(到 n − 2 為止),先收集 —— nextEnd = max(nextEnd, i + nums[i]):這一層的格子再跳一次最遠到哪。
  3. 走到這一層盡頭就換層 —— i == curEnd 時,這一層看完了:step++,curEnd = nextEnd。

和 55 的差別只有一個變數:55 的 farthest 就是這裡的 nextEnd;45 多一個 curEnd,把「推」的過程切成一層一層來數。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 走到 curEnd 才 step++,剛好就是最少次數

curEnd 是「跳 step 次能到的最遠」。i 還沒走到 curEnd 時,i 自己用 step 次就到得了,不用加。走到 curEnd 時,跳 step 次能到的格子全部看完了 —— 還沒到終點,就一定要再多一次;而多一次最遠能到的,正是剛收集完的 nextEnd。 所以 step 數的是「層數」,每一次 +1 都是被迫的,不會多;每一層都推到最遠,也不會少。

LEMMA 2 · 不用決定「從哪一格起跳」

「每次跳最遠」錯,是因為它太早決定了落點。分層的做法把這一層所有格子的 i + nums[i] 都比過才換層,等於同時試了這一層的每一個起跳點。 [4,1,1,3,1,1,1]:第 1 層是 [1..4],其中 index 3 推到 6;程式只記 6,答案 2。實際路線是 0 → 3 → 6,如果需要,可以在 nextEnd 變大時順便記下是哪一格(見複習頁 App 1)。

一句洞察// INSIGHT

跳 k 次能到的格子是連續的一段,所以 BFS 不用 queue,只要兩個邊界。 nextEnd 在這一層裡收集「再跳一次的最遠」,走到 curEnd 就換層 —— step 數的是層,不是哪一格跳了。

// ONE-LINE TAKEAWAY
隱式 BFS:第 k 層 = 跳 k 次才到的一段格子。nextEnd = max(i + nums[i]) 收集下一層的右端,i == curEnd 時 step++、curEnd = nextEnd。迴圈到 n − 2。O(n) / O(1)。
