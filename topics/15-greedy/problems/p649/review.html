PART A · 觀念題// 5 題 × 10 分

第 1 題10 分
題目說每個人有「禁人」和「宣布勝利」兩種選擇。為什麼可以說每一步其實只有一個決策?
解答與說明 · ANSWER▾
「宣布勝利」只有在場上只剩自己陣營時才能做,條件成立就一定會做;條件不成立時唯一能做的就是禁人。所以每一步要想的只有「禁誰」。

先把題目包裝剝掉、找出真正的選擇,是貪心題的第一步。選擇縮小成「從敵人裡挑一個」之後,才看得出敵人之間唯一的差別是行動時間。
第 2 題10 分
為什麼要禁「下一個會行動的敵人」,而不是隨便一個敵人?「下一個」為什麼要繞圈算?
解答與說明 · ANSWER▾
所有敵人的能力一樣,每人每輪禁一個;唯一的差別是誰先動手。下一個會動的敵人最快造成傷害,禁他不會比禁別人差(交換論證:換成禁他,原本的目標只會更晚動手)。

「繞圈」是因為一輪走完會從頭再來:我後面已經沒有敵人時,下一個會動的是下一輪排最前面的那個。第 6 題的 "DRDRR" 改禁隊尾就錯了,1,990 組。和博弈樹窮舉(每一步把所有禁法都試過)比對 8,190 組 0 錯,證實「禁下一個」就是最佳策略。
第 3 題10 分
queue 裡出現 7,n = 5,它代表誰?為什麼贏家要存成 位置 + n?
解答與說明 · ANSWER▾
7 = 5 × 1 + 2:座位 2,第 2 輪(v % n 是座位,v / n + 1 是第幾輪)。程式碼頁 "RDRDD" 第 2 步的 R2 就是在這裡被存成 7。

贏家這輪已經動過,下一輪才能再動。存成 位置 + n,值就比這一輪所有還沒動的人大,會排在他們後面;而下一輪彼此之間的大小,又和原本座位順序一樣。拿掉 + n 會錯 9,794 組,最小反例 "DRR"(見第 6 題)。
第 4 題10 分
r < d 改成 r <= d 會錯嗎?改成 r + 1 呢?
解答與說明 · ANSWER▾
<= 不會錯:每個值都是「座位 + 輪數 × n」,R 和 D 不可能有同一個值,r == d 永遠不成立。窮舉 32,766 組 0 差異。

+ 1 會錯 6,716 組,最小反例也是 "DRR":D0 變成 1,還是比 R2 小,一樣在同一輪多動一次。要的是「整整一輪之後」,所以一定是 + n。
第 5 題10 分
為什麼 while 最多跑 n − 1 次?為什麼不會因為「一輪又一輪」而變成 O(n²)?
解答與說明 · ANSWER▾
每次 while 都 pop 兩個、push 一個,兩個 queue 加起來剛好少 1 人;一開始 n 人、結束時至少剩 1 人,所以最多 n − 1 次。

「一輪又一輪」是值變大(+ n),不是重新掃一遍所有人:被禁的人已經不在 queue 裡,完全不會再碰到。對照「一輪一輪掃字串」的寫法,它每一輪都要掃過已經出局的人。

PART B · 手走模擬// 1 題 × 10 分

第 6 題10 分
拿一張紙,每一步寫下 r vs d、誰禁誰、push 了什麼、兩個 queue 剩什麼:
(a) "DRR"(n = 3)先照正解走,再改成拿掉 + n(qd.push(d))走一次;
(b) "DRDRR"(n = 5)先照正解(禁對方隊首)走,再改成禁對方隊尾走一次。
四個版本各回傳什麼?錯的那兩個,是在哪一步、因為什麼走歪的?
解答與說明 · ANSWER▾
// "DRR", n = 3 · 正解 init qr = [1, 2] qd = [0] 1 r=1 vs d=0 D0 禁 R1,qd push 0+3 = 3 qr [2] qd [3] 2 r=2 vs d=3 R2 禁 D3,qr push 2+3 = 5 qr [5] qd [] // OUTPUT: "Radiant"
// "DRR" · 拿掉 + n(qd.push(d)) init qr = [1, 2] qd = [0] 1 r=1 vs d=0 D0 禁 R1,qd push 0 qr [2] qd [0] 2 r=2 vs d=0 D0 又先動,禁 R2 qr [] qd [0] // OUTPUT: "Dire"(錯):D0 在同一輪動了兩次,R2 輪不到
// "DRDRR", n = 5 · 正解(禁對方隊首) init qr = [1, 3, 4] qd = [0, 2] 1 r=1 vs d=0 D0 禁 R1,qd push 5 qr [3, 4] qd [2, 5] 2 r=3 vs d=2 D2 禁 R3,qd push 7 qr [4] qd [5, 7] 3 r=4 vs d=5 R4 禁 D5,qr push 9 qr [9] qd [7] 4 r=9 vs d=7 D7 禁 R9,qd push 12 qr [] qd [12] // OUTPUT: "Dire"
// "DRDRR" · 改禁對方隊尾 init qr = [1, 3, 4] qd = [0, 2] 1 r=1 vs d=0 D0 禁 R4(隊尾),qd push 5 qr [1, 3] qd [2, 5] 2 r=1 vs d=2 R1 還在,先動,禁 D5,qr push 6 qr [3, 6] qd [2] 3 r=3 vs d=2 D2 禁 R6,qd push 7 qr [3] qd [7] 4 r=3 vs d=7 R3 禁 D7,qr push 8 qr [8] qd [] // OUTPUT: "Radiant"(錯):D0 放過馬上要動的 R1,R1 反過來禁掉 D 方一人
"DRDRR" 那兩段就是第 2 題的答案:D0 禁 R4 是浪費 —— R4 要等很久才動,R1 卻是下一個。R1 一動手,D 方少一人,整局翻盤。 "DRR" 那兩段就是第 3 題的答案:值 0 放回去還是 0,永遠比 R 小,等於「同一輪再動一次」;+ n 之後變 3,才會排到 R2 後面。

PART C · 應用題// 3 題 × 12–14 分

第 7 題12 分
除了回傳哪一方贏,還要回傳最後還有權利的是哪些座位。要怎麼改?"DDRRR"、"RRDD" 的答案是什麼?
解答與說明 · ANSWER▾
迴圈結束後,把非空那個 queue 裡的值逐一取出,值 % n 就是座位。

實測:"DDRRR" → Dire,剩座位 1(qd = [11],11 % 5 = 1);"RRDD" → Radiant,剩座位 0、1(qr = [4, 5]);"RDRDD" → Radiant,剩座位 2(qr = [12])。
第 8 題14 分
不存位置、只用一個 queue<char> 讓所有人照順序輪流,能不能做?需要多記什麼?
解答與說明 · ANSWER▾
可以。多記四個數:兩邊還活著幾人(aliveR、aliveD),和兩邊「欠幾個要被禁」(banR、banD)。

每次取隊首 c:如果 c 的陣營有欠(例如 c 是 R 且 banR > 0),他就是被禁的那個 → banR--、aliveR--,不放回去;否則他去禁對方 → banD++,自己放回隊尾。任一方 alive 歸 0 就結束。這就是「禁下一個會動的敵人」:欠的債由對方下一個輪到的人來還。實測和正解對拍:長度 1–16 全部 131,070 組 + 隨機 5,000 組(n ≤ 104),0 錯。
第 9 題14 分
1823 Find the Winner of the Circular Game:n 個人圍成一圈,每數到第 k 個就淘汰。和這題的「繞圈輪流」有什麼相同的地方?用 queue 怎麼寫?
解答與說明 · ANSWER▾
相同點:都是「繞圈輪流、有人出局、出局的人之後跳過」—— queue 的「pop 隊首、放回隊尾」天然就是繞圈。

寫法:把 1..n 放進 queue;只要不只 1 人,就把隊首搬到隊尾 k − 1 次,再 pop 掉第 k 個;剩下的就是答案。官方範例 n=5, k=2 → 3、n=6, k=5 → 1;和用 vector 直接刪除的模擬比對 n ≤ 60 的全部 1,830 組 (n, k),0 錯。差別是 1823 沒有「挑誰出局」的選擇,649 才需要貪心決定禁誰。
