完整實作// SPLIT · COMPARE FRONTS · WINNER + n

p649.cpp C++17 
class Solution {
public:
    string predictPartyVictory(string senate) {
        int n = senate.size();
        queue<int> qr, qd;

        for (int i = 0; i < n; i++) {
            if (senate[i] == 'R') {
                qr.push(i);
            } else {
                qd.push(i);
            }
        }

        while (!qr.empty() && !qd.empty()) {
            int r = qr.front(); qr.pop();
            int d = qd.front(); qd.pop();

            if (r < d) {
                qr.push(r + n);
            } else {
                qd.push(d + n);
            }
        }

        return !qr.empty() ? "Radiant" : "Dire";
    }
};

兩個官方範例 → "Radiant"、"Dire",都正確。 和博弈樹窮舉(每一步把所有可能的禁法都試過,不假設貪心)比對長度 1–12 全部 8,190 組,0 筆不一致;另外和「一輪一輪掃字串」的計數模擬隨機對拍 20,000 組(n ≤ 2000),0 筆不一致。

每一行各自的意思:

  • qr / qd 存的是位置,不是字元:位置大小就是行動先後,比較時才知道誰先動。
  • 兩個隊首各 pop 一次:不管誰贏,兩個人都先離開 queue —— 輸的人不再回來(被禁),贏的人等一下重新排隊。
  • r < d:R 的位置比較前面,R 先動,禁掉的正是 D 方「下一個要動的人」(隊首)。
  • r + n:同一個座位、下一輪。比這一輪所有還沒動的人都大,所以排在他們後面。
  • 迴圈條件用 &&:任一方空了就停;最後非空的那一方贏。

細節走讀// WALKTHROUGH · "RDRDD"

"RDRDD",n = 5(概念頁動畫走的是 "RDD" 和 "DDRRR")。R 只有 2 人、D 有 3 人,但 R 搶在前面。每一行都是實際印出來的。

// 第 1 輪:兩個 R 先動 init qr = [0, 2] qd = [1, 3, 4] 1 r=0 vs d=1 0 < 1 → R0 禁 D1,qr push 0+5 = 5 qr [2, 5] qd [3, 4] 2 r=2 vs d=3 2 < 3 → R2 禁 D3,qr push 2+5 = 7 qr [5, 7] qd [4]
// 第 1 輪最後一人 D4,接著進第 2 輪 3 r=5 vs d=4 4 < 5 → D4 禁 R5(座位 0),qd push 4+5 = 9 qr [7] qd [9] 4 r=7 vs d=9 7 < 9 → R7(座位 2)禁 D9(座位 4),qr push 12 qr [12] qd [] // OUTPUT: qd 空了 → return "Radiant"(while 4 次 = n − 1)

第 3 步就是 + n 在做的事:R0 已經在第 1 輪動過,值變成 5;D4 是 4,還在第 1 輪,所以 D4 先動。第 4 步 R 方的 7(座位 2,第 2 輪)比 D 的 9(座位 4,第 2 輪)小,第 2 輪裡座位 2 本來就在座位 4 前面。
