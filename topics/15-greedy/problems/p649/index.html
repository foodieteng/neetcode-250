題目簡介// THE QUESTION

QUESTION

字串 senate 的每個字元是一位參議員:'R'(Radiant)或 'D'(Dire)。大家照位置順序輪流行動,一輪走完再從頭開始,被禁的人之後都跳過。輪到自己時可以禁掉任何一個人(永久),或在場上只剩自己陣營時宣布勝利。每個人都用最佳策略,問哪一方贏。
1 ≤ n ≤ 104,senate[i] 只有 'R' / 'D'。

範例:"RD" → "Radiant"(R 先動,禁掉 D);"RDD" → "Dire"(R 禁掉第一個 D,第二個 D 在同一輪禁掉 R)。

「宣布勝利」不是選擇,條件到了自然發生。真正要決定的只有一件事:禁誰。 對 R 來說,所有 D 的能力都一樣(每人每輪禁一個),唯一的差別是誰先行動 —— 所以禁「下一個會行動的 D」。

核心策略 · 三步驟// THE LOOP

  1. 分隊 —— 把每個 R 的位置放進 qr、每個 D 的位置放進 qd。queue 裡的順序就是行動順序。
  2. 隊首比大小 —— 各 pop 一個:r < d 代表 R 先動,他禁掉 d(d 不再回來);反之 D 先動,禁掉 r。
  3. 贏家 + n 回隊尾 —— 他這輪動完了,下一輪還坐同一個位置,所以存 位置 + n。任一 queue 空了就結束,另一方贏。

和 846 一樣,每一步的選擇是被逼出來的:那裡是「最小的牌沒有前一張,只能當開頭」,這裡是「最快行動的敵人威脅最大,只能先禁他」。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 禁「下一個會行動的敵人」不會比較差

輪到 R,敵人裡 y 是下一個會行動的,x 比 y 晚。如果 R 去禁 x,y 會比 x 先動手,可能馬上禁掉 R 方一個還沒動的人;改禁 y 的話,x 雖然還在,但他動手的時間比 y 晚 —— y 能造成的傷害,x 只能更晚才造成,中間 R 方的隊友還有機會先把 x 禁掉。所以換成禁 y 永遠不會變差。 「下一個」要繞圈算:我後面已經沒有敵人時,下一個會動的是下一輪排最前面的那個。兩個 queue 的隊首剛好就是「每一方下一個要動的人」。

LEMMA 2 · + n 就是「同一個位置,下一輪」

queue 裡的值 v 代表「位置 v % n,第 v / n + 1 輪」。贏家這輪動完了,存成 位置 + n,和還沒動的人比的時候一定比他們大,所以會排在他們後面;下一輪彼此之間的大小關係又和原本的座位順序一樣。 每個值都是某個座位在某一輪的唯一編號,兩邊不可能相等 —— 所以 r < d 寫成 r <= d 結果完全一樣(窮舉 32,766 組 0 差異)。真正會錯的是拿掉 + n:錯 9,794 組,最小反例 "DRR"(見複習頁)。

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

每個人都「禁下一個會行動的敵人」是最好的策略;程式的兩個 queue 就是在模擬這件事。

PROOF · 手法:交換論證
  1. 能禁就禁。多禁掉一個敵人,對自己這方只會更好,沒有理由放棄。宣布勝利只會發生在對方已經全被禁掉的時候,也就是某個 queue 空了。
  2. 禁最快要動的那個。設 y 是下一個會動的敵人,x 比 y 晚動。禁 x 和禁 y 相比,剩下的敵人只差在:一邊留下 y,一邊留下 x。x 動手的時間比 y 晚 —— y 能做的事,x 只能更晚才做,中間我方隊友有更多機會先把他禁掉。所以換成禁 y 不會變差(LEMMA 1)。
  3. queue 就是這個策略。兩個隊首就是兩方「下一個要動的人」,比位置就知道誰先動;先動的禁掉對方隊首,自己 + n 排到下一輪。實測和「每一步試遍所有禁法」的博弈樹窮舉比對 8,190 組,0 錯。
面試這樣說 · 30 秒

輪到我時,禁人一定不吃虧。要禁誰?敵人之間只差在誰先動;禁掉最快要動的那個,剩下的敵人動手都比較晚,我方有更多機會先出手。所以每個人都禁對方下一個要動的人,用兩個 queue 比隊首,就把整場模擬完了。

複雜度// COMPLEXITY

T = O(n)　　S = O(n)

每一次 while 都 pop 兩個、push 一個,兩個 queue 加起來剛好少 1 人。一開始 n 人、結束時至少剩 1 人,所以迴圈最多 n − 1 次。實測長度 1–16 的全部字串,while 最多剛好 n − 1 次;n = 104 的各種極端輸入也都沒超過。
