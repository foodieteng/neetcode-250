完整實作// COPY PREV · THEN CROSS-UPDATE

p978.cpp C++17 
class Solution {
public:
    int maxTurbulenceSize(vector<int>& arr) {
        int n = arr.size();
        int maxL = 1, curMx = 1, curMi = 1;

        for (int i = 1; i < n; i++) {
            int prevMx = curMx, prevMi = curMi;
            curMx = (arr[i] > arr[i - 1]) ? prevMi + 1 : 1;
            curMi = (arr[i] < arr[i - 1]) ? prevMx + 1 : 1;
            maxL = max(max(curMx, curMi), maxL);
        }

        return maxL;
    }
};

三個官方範例 → 5、2、1,都正確。 和照定義直接檢查的 O(n³) 暴力解對拍 223,279 組:窮舉值 0..2、長度 1–7 全部 3,279 組 + 隨機 200,000 組(長度 ≤ 12、值 0..3)+ 隨機 20,000 組(長度 ≤ 200、值 0..109),0 筆不一致。

三行各自的意思:

  • prevMx / prevMi:先把上一格的兩個值存起來。下面兩行要讀的都是上一格,而它們會互相覆蓋。
  • curMx:結尾在 i、最後一步往上的最長長度。往上之前必須是往下,所以接在 prevMi 後面;不是往上就重設成 1。
  • curMi:結尾在 i、最後一步往下的最長長度,接在 prevMx 後面。相等時兩個都變 1。
