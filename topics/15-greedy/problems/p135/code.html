完整實作// ALL 1 · LEFT PASS · RIGHT PASS WITH MAX

p135.cpp C++17 
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> c(n, 1);

        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) c[i] = c[i - 1] + 1;
        }

        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) c[i] = max(c[i], c[i + 1] + 1);
        }

        return accumulate(c.begin(), c.end(), 0);
    }
};

兩個官方範例 → 5、4,都正確。 和「每種發法都試、取總和最少」比對:長度 1–7、分數 0–3 全部窮舉 21,844 組 + 隨機 100,000 組(n ≤ 7、分數 0–6),0 筆不一致。另外和「反覆修正到沒人違規」對拍 20,000 組(n ≤ 200),0 筆不一致。

每一行各自的意思:

  • c(n, 1):每人至少 1 顆。不比任何鄰居高的人(谷底),兩輪都不會動他,最後就是 1。
  • 第一個迴圈從 i = 1 開始:第 0 個人左邊沒人。比左邊高就 c[i − 1] + 1;否則(低或同分)保持 1 —— 同分不算比較高,規則沒要求。
  • 第二個迴圈從 i = n − 2 開始、往左走:最後一個人右邊沒人;而 c[i + 1] 必須已經是最終值,所以一定要從右往左。
  • max(c[i], c[i + 1] + 1):右規則要求至少 c[i + 1] + 1,但左掃可能已經給了更多,不能蓋掉。
  • accumulate(…, 0):起始值 0 是 int,所以用 int 加。最多 1,250,025,000,不會溢位(見下表)。

細節走讀// WALKTHROUGH · 範例 1 · 範例 2

概念頁動畫走了三個例子,這裡把兩個官方範例用文字走一次,每一行都是實際印出來的。

// 範例 1:ratings = [1,0,2] c = [1,1,1] ── 左往右 ── i=1 0 > 1 ? 否 c = [1,1,1] i=2 2 > 0 ? 是 → c[1]+1 = 2 c = [1,1,2] ── 右往左 ── i=1 0 > 2 ? 否 c = [1,1,2] i=0 1 > 0 ? 是 → max(1, 1+1) = 2 c = [2,1,2] sum = 2 + 1 + 2 // OUTPUT: 5 中間的 0 是谷底,兩邊各自從它爬上來一步
// 範例 2:ratings = [1,2,2] c = [1,1,1] ── 左往右 ── i=1 2 > 1 ? 是 → c[0]+1 = 2 c = [1,2,1] i=2 2 > 2 ? 否(同分) c = [1,2,1] ── 右往左 ── i=1 2 > 2 ? 否(同分) c = [1,2,1] i=0 1 > 2 ? 否 c = [1,2,1] sum = 1 + 2 + 1 // OUTPUT: 4 兩個 2 同分,彼此沒有任何要求

// ONE-LINE TAKEAWAY
c(n, 1);左往右比左邊高就 c[i−1] + 1;右往左比右邊高就 max(c[i], c[i+1] + 1);加總。最容易錯:右掃不取 max([0,1,2,0] → 6)、右掃方向反了([2,1,0] → 5)、同分用 >=([0,0] → 3)。O(n) / O(n),最壞 1,250,025,000 仍在 int 內。
