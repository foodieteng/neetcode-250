完整實作// DIFF · TOTAL · CUR · RESET

p134.cpp C++17 
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        int total = 0, cur = 0, start = 0;

        for (int i = 0; i < n; i++) {
            int diff = gas[i] - cost[i];
            total += diff;
            cur += diff;

            if (cur < 0) {
                start = i + 1;
                cur = 0;
            }
        }

        return total < 0 ? -1 : start;
    }
};

每一行各自的意思:

  • diff:這一站加的油減掉開到下一站的路費,正的是賺、負的是虧。
  • total:整圈的 diff 總和,只用來回答「有沒有答案」,中途不重設。
  • cur:從目前候選 start 開到這裡,油箱還剩多少。
  • cur < 0:開不到 i+1。start..i 全部淘汰(概念頁 LEMMA 1),候選換成 i+1,油箱歸零重來。
  • total < 0 ? −1 : start:油不夠一圈就沒有答案;夠的話,最後的候選就是答案(LEMMA 2)。

細節走讀// WALKTHROUGH · 範例 2 → −1

範例 2 gas=[2,3,4], cost=[3,4,3](概念頁動畫走的是範例 1 和兩次重設的例子)。每一行都是實際印出來的。

// 一站一站累加 i=0 diff = 2−3 = −1 total = −1 cur = −1 < 0 → start = 1,cur = 0 i=1 diff = 3−4 = −1 total = −2 cur = −1 < 0 → start = 2,cur = 0 i=2 diff = 4−3 = 1 total = −1 cur = 1
// 掃完看 total total = −1 < 0 → 油總共 9、路費總共 10,不管從哪出發都不夠 // OUTPUT: −1(start 停在 2,但不會被回傳)

這裡 start 最後是 2:從 2 出發確實能開到 0(4 − 3 = 1),接著 0 → 1 要 3、手上 1 + 2 = 3 剛好夠;但 1 → 2 要 4、手上只有 0 + 3 = 3,就停了。所以「cur 沒變負」只代表 start..n−1 走得完,還要靠 total 確認繞回來那一段也夠。
