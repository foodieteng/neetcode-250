Gas Station

PAGE 1 / 3 · CONCEPT
1

題目簡介// THE QUESTION

QUESTION

n 個加油站圍成一圈。到第 i 站可以加 gas[i],從 i 開到 i+1 要花 cost[i]。油箱一開始是空的,問從哪一站出發可以順時針繞完一整圈;做不到回傳 −1。題目保證:如果有答案,答案只有一個。
1 ≤ n ≤ 105,0 ≤ gas[i], cost[i] ≤ 104。

範例:gas=[1,2,3,4,5], cost=[3,4,5,1,2] → 3(從 3 出發:4−1、+5−2、+1−3、+2−4、+3−5,油箱一路 3, 6, 4, 2, 0);gas=[2,3,4], cost=[3,4,3] → −1(油總共 9,路費總共 10)。

每一站只看 diff = gas[i] − cost[i]。這題其實是兩個問題:「有沒有答案」和「答案是哪一站」。 有沒有:全部 diff 加起來(total)≥ 0 就有。是哪一站:從候選起點一路累加(cur),cur 一變負,候選起點到這裡的每一站全部淘汰,下一站當新候選。
2

為什麼一次掃完就夠// WHY ONE PASS

A 每一站都試著繞一圈 O(n²)
每個起點模擬一圈,油箱變負就換下一個起點。正確(驗證時拿它當參考解),但 n = 105 時最多 1010 步。
× REJECT · TLE
B 直覺挑「最賺」的那站 O(n)
從 diff 最大的那站出發,或從 gas 最多的那站出發。聽起來合理,但前面賺很多不代表後面撐得住。實測(612,240 組合法輸入):挑最大 diff 錯 27,179 組,挑最大 gas 錯 51,101 組。
× REJECT · WRONG ANSWER
SKIP WHOLE SEGMENT · ADOPT
C total 判有無 · cur 變負整段跳過 O(n) / O(1)
A 的問題是失敗之後只往前挪一站。其實從 start 開到 i 失敗,start..i 每一站都不可能是答案,可以直接跳到 i+1。每一站只被經過一次。和 A 窮舉比對 n ≤ 5、值 0..3 的全部 1,118,480 組,0 錯。
● ADOPT · 失敗一次淘汰一整段
3

核心策略 · 三步驟// THE LOOP

  1. 算 diff —— diff = gas[i] − cost[i],同時加進 total(整圈)和 cur(從候選起點開始)。
  2. cur < 0 就換人 —— 從 start 開不到 i+1:start = i + 1,cur = 0 重新累加。
  3. 看 total —— 掃完 total < 0 回傳 −1,否則回傳最後的 start。

cur 的處理和 53 Maximum Subarray(Kadane)一樣:累加到負的,前面那一段只會拖累後面,整段丟掉、從下一格重新開始。差別是這裡丟掉的那一段也代表「這些站都不能當起點」。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 從 start 到不了 i+1,start..i 都到不了

從 start 出發,經過中間任一站 k(start < k ≤ i)的時候,油箱裡是 start..k−1 的 diff 總和,而這個值 ≥ 0(否則早就在 k 之前重設了)。改從 k 出發,等於空著油箱到 k,只會比原本更少油 —— 原本帶著 ≥ 0 的油都在 i 撐不住,空油箱更不可能。 所以 cur 一變負,start 到 i 整段一起淘汰,直接把候選跳到 i+1。每一站最多被淘汰一次,一趟就掃完。

LEMMA 2 · total ≥ 0,最後的 start 就是答案

total < 0:油總量比路費少,從哪裡出發都不可能,回傳 −1。total ≥ 0:從最後的 start 開到 n−1,cur 一路沒變負;接著要繞回 0..start−1,那是前面被淘汰的幾段,每一段都只在最後一站才變負。而 total = cur + 前面各段的總和 ≥ 0,代表手上的 cur 剛好夠補前面所有段的虧損。 實測:有答案時 start 從來沒有等於 n(0 次)—— start 要變成 n,代表最後一站也讓 cur 變負,那每一段都是虧的,total 一定 < 0。另外就算答案不唯一(題目保證唯一,但窮舉時有 506,240 組不唯一),回傳的 start 也一定是可行的。

6

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

total < 0 一定無解;total ≥ 0 時,最後留下的 start 一定開得完一圈。

PROOF · 手法:淘汰 + 最低點
  1. total < 0 無解。繞一圈加的油比花的少,不管從哪裡出發都撐不完。
  2. 淘汰不會漏掉答案。從 start 開到 i 油箱變負,start..i 之間任一站 k 出發也不行:原本進到 k 時油箱 ≥ 0,改成空油箱從 k 出發只會更少,而原本都在 i 撐不住了。所以候選直接跳到 i + 1(LEMMA 1)。
  3. start − 1 是累積油量的最低點。把 diff 從 0 累加成曲線 P。每次重設都發生在 P 跌破上一次重設的高度,所以最後一次重設的位置 start − 1 是整條曲線的最低點。從最低點之後出發,油箱 = 目前的 P − 最低點 ≥ 0;繞回 0..start − 1 時,油箱 = total +(那一點的 P − 最低點)≥ total ≥ 0。一路都不會變負。(沒有重設時 start − 1 = −1,P(−1) = 0;最後一次重設不可能在 n − 1,否則 P(n − 1) < 0 = P(−1),total < 0,早就回傳 −1 了。)
面試這樣說 · 30 秒

總油量不夠一定無解。開到一半變負,這一段每一站當起點都不行:中途進站時油箱本來 ≥ 0,空著出發只會更慘,所以整段跳過。最後的 start 前一站是累積油量的最低點,從最低點的下一站出發,之後的油量永遠不會低於起點,總量又 ≥ 0,所以一定繞得完。

複雜度// COMPLEXITY

T = O(n)　　S = O(1)

一次迴圈,每站常數個加法和比較;只用了 total、cur、start 三個 int。重設最多 n 次(每一站都虧的時候,實測 n = 105 重設 100,000 次),但重設本身也是 O(1)。

total 回答「有沒有」,cur 和 start 回答「是哪一站」。 cur 一變負,從 start 到 i 每一站都不可能(它們只會帶更少油到 i),直接跳到 i+1。掃完 total ≥ 0 就回傳 start。
