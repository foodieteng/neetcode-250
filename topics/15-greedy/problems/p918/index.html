題目簡介// THE QUESTION

QUESTION

給環狀整數陣列 nums(最後一格後面接回第一格),找出和最大的非空子陣列,回傳那個和。每個元素最多用一次(不能繞超過一圈)。
1 ≤ n ≤ 3 × 104,−3 × 104 ≤ nums[i] ≤ 3 × 104。

範例:[1,-2,3,-2] → 3(只拿 3); [5,-3,5] → 10(跨尾巴:最後的 5 接回開頭的 5); [-3,-2,-3] → −2(全負,拿最大的那個)。

就是 53 Maximum Subarray 加上「可以跨過尾巴」。不跨尾巴的段,53 的 Kadane 已經會算;新的只有跨尾巴那一種。 跨尾巴的段把陣列頭尾都拿走、中間留一段沒拿 —— 想讓拿走的最大,就讓沒拿的那段最小。
2

為什麼用兩個 Kadane// WHY MAX + MIN KADANE

A 暴力:每個起點 × 每個長度 O(n²)
索引用 (i + k) % n 繞圈累加。答案對(驗證時拿它當參考解),但 n = 3 × 104 時是 9 × 108 次加法,太慢。
× REJECT · TLE
B 陣列接成兩倍 + 前綴和 + 單調佇列 O(n) / O(n)
把環攤平成 nums + nums,問題變成「長度 ≤ n 的段的最大和」= 前綴和 P[j] − P[i],j − n ≤ i < j,用單調佇列維護視窗內最小的 P[i]。也是線性,但要 2n 的前綴陣列和一個 deque,邊界條件多。
△ 能用 · 但要 O(n) 空間
ADOPT THE SIMPLEST
C 一趟跑兩個 Kadane:最大段 + 最小段 O(n) / O(1)
最大段 subMx 管「不跨尾巴」;總和減最小段 total − subMi 管「跨尾巴」。兩者取大。唯一的特例是全負:subMx < 0 就直接回傳它。五個 int,n = 3 × 104 實測約 40 µs,和暴力解對拍 239,530 組 0 錯。
● ADOPT · 53 寫兩遍
3

核心策略 · 三步驟// THE LOOP

  1. 每一格 x —— total += x;最大段的 Kadane curMx = max(curMx + x, x),最小段的 Kadane curMi = min(curMi + x, x)。
  2. 刷新兩個紀錄 —— subMx = max(subMx, curMx)、subMi = min(subMi, curMi)。初值 INT_MIN / INT_MAX。
  3. 收尾 —— subMx < 0(全負)回傳 subMx;否則回傳 max(subMx, total − subMi)。

最小段的 Kadane 就是 53 把 max 全部換成 min:前面那段是正的就丟掉重開(帶著它只會更大)。

4

動畫演示// [2,-3,4,-6,1,5]

不跨尾巴最好只有 [4..5] = 6;最小段是 [3] = −6,總和 3,所以跨尾巴 = 3 − (−6) = 9,就是 [4,5,0,1,2] 繞回開頭那一段。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 跨尾巴的最大段 = total − 最小段

環上的段只有兩種:不跨尾巴(普通的 [i..j],53 的 Kadane 會算到),或跨尾巴([j..n−1] + [0..i])。後者沒拿到的正好是中間一段連續的 [i+1..j−1],所以 跨尾巴的和 = total − 中間那段。 要前者最大,就讓中間那段最小 —— 也就是 subMi。反過來,任何「最小段」被拿掉後剩下的,不是跨尾巴的段,就是貼著頭或尾的普通段,都是合法答案;唯一的例外是最小段 = 整圈。

LEMMA 2 · 最小段 = 整圈時,total − subMi = 0 是「一個都不拿」

全負陣列的最小段一定是整個陣列(每多拿一格都更小),total − subMi = 0 代表空段,不合法。[-3,-2,-3]:total = subMi = −8,若直接取 max(0, −2) 會回傳 0,正解 −2。 實測窮舉 19,607 組裡有 2,955 組「最小段 = 整圈」,其中 2,592 組 subMx ≥ 0,被 max(…, subMx) 救回;剩下 363 組全負會出事 —— 所以判斷看 subMx < 0,不看 total。

一句洞察// INSIGHT

環狀的最大段,不是不跨尾巴的最大段,就是整圈減掉最小段。 兩個 Kadane 一趟跑完;全負時 total − subMi 會變成空段的 0,所以 subMx < 0 先回傳。
