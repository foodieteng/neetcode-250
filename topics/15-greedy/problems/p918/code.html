完整實作// MAX KADANE + MIN KADANE · ONE PASS

p918.cpp C++17 
class Solution {
public:
    int maxSubarraySumCircular(vector<int>& nums) {
        int total = 0, curMx = 0, curMi = 0;
        int subMx = INT_MIN, subMi = INT_MAX;

        for (int &x : nums) {
            total += x;

            curMx = max(curMx + x, x);
            curMi = min(curMi + x, x);
            subMx = max(subMx, curMx);
            subMi = min(subMi, curMi);
        }

        if (subMx < 0) return subMx;
        return max(total - subMi, subMx);
    }
};

三個官方範例 → 3、10、−2,都正確。 和 O(n²) 暴力解(每個起點 × 每個長度,索引取 % n)對拍 239,530 組:窮舉值 −2..2、長度 1–6 全部 19,530 組 + 隨機 200,000 組(長度 ≤ 8、值 ±5)+ 隨機 20,000 組(長度 ≤ 60、值 ±30,000),0 筆不一致。

迴圈裡其實是兩份 53 的 Kadane 疊在一起:

  • curMx / subMx:和 53 的 curL / maxL 一模一樣 —— 不跨尾巴的最大段。
  • curMi / subMi:把 max 換成 min,求最小段。跨尾巴的段 = 整圈拿掉中間一段,要它最大,就拿掉最小的那段:total − subMi。
  • if (subMx < 0) return subMx;:全負時最小段 = 整個陣列,total − subMi = 0 代表「一個都不拿」,不合法,直接回傳最大的那個負數。
