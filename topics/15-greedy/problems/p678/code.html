完整實作// UPDATE RANGE · r < 0 · CLAMP l

p678.cpp C++17 
class Solution {
public:
    bool checkValidString(string s) {
        int l = 0, r = 0;

        for (char &c : s) {
            if (c == '(') {
                l++; r++;
            } else if (c == ')') {
                l--; r--;
            } else {
                l--; r++;
            }

            if (r < 0) return false;
            l = max(l, 0);
        }

        return l == 0;
    }
};

三個官方範例 → true、true、true,都正確。 和「每個 * 三種都試」的暴力解比對長度 1–10 全部 88,572 組(24,349 組是 true)、和「記所有可能 open 的集合」的 DP 比對長度 11–13 全部 2,302,911 組,0 筆不一致;隨機 50,000 組(長度 ≤ 100)0 筆不一致。每一步都檢查 l ≤ r,0 次違反。

每一行各自的意思:

  • l / r:到目前為止,未配對的 '(' 最少 / 最多可能有幾個。
  • '*' 的 l--; r++;:l 走「當 ')'」的路、r 走「當 '('」的路;「當空字串」在中間,範圍連續,不用另外記。
  • r < 0:連最多的那種選法都不夠配右括號,之後不可能變好 → 立刻 false。
  • l = max(l, 0):open 不能是負的;把那些選法丟掉,範圍下界回到 0。
  • l == 0:0 在 [l, r] 裡,有一種選法剛好全部配完。因為 l 每步都夾過,這裡寫 l <= 0 也一樣。

細節走讀// WALKTHROUGH · "(*()" · "(((*)"

概念頁動畫走的是 "(*))"、"*)("、"(*)))"。這裡走一個 true、一個在結尾才失敗的 false。每一行都是實際印出來的。

// "(*()":* 當空字串 1 '(' l = 1 r = 1 [1, 1] 2 '*' l = 0 r = 2 [0, 2] 3 '(' l = 1 r = 3 [1, 3] 4 ')' l = 0 r = 2 [0, 2] // OUTPUT: l = 0 → true
// "(((*)":左括號太多,一個 * 救不完 1 '(' l = 1 r = 1 [1, 1] 2 '(' l = 2 r = 2 [2, 2] 3 '(' l = 3 r = 3 [3, 3] 4 '*' l = 2 r = 4 [2, 4] 5 ')' l = 1 r = 3 [1, 3] // OUTPUT: l = 1 ≠ 0 → false(r 一直 ≥ 0,沒有提早結束)

第二個例子一次都沒夾、也沒觸發 r < 0,失敗完全是在結尾的 l 判斷出來的:3 個 '(' 只有一個 * 和一個 ')' 可以配,最少還剩 1 個沒配到。
