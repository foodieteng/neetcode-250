題目簡介// THE QUESTION

QUESTION

字串只有 '('、')'、'*'。每個 * 可以當成 '('、')' 或空字串。問有沒有一種選法,讓整串變成合法的括號字串。
1 ≤ s.length ≤ 100。

範例:"()" → true;"(*)" → true(* 當空字串);"(*))" → true(* 當 '(')。

沒有 * 的時候,只要記一個數:目前還沒配對的左括號有幾個(open)。有了 *,open 不再是一個數,而是一個範圍。 l = open 最少可能是多少,r = open 最多可能是多少。* 讓範圍往兩邊各撐開一格;最後只要 0 在範圍裡就成立。

A 每個 * 三種都試 O(3k · n)
k 個 * 就有 3k 種字串,每種都檢查一次。正確(驗證時拿它當參考解),但 100 個 * 是 3100。

B 記「所有可能的 open」集合 O(n²)
每一步把集合裡每個 open 分別加 1、減 1、不變(負的丟掉)。正確(長度 11–13 全部 2,302,911 組拿它當參考解),但集合最大到 n 個元素。

核心策略 · 三步驟// THE LOOP

  1. 更新範圍 —— '(':l+1、r+1;')':l−1、r−1;'*':l−1(當 ')')、r+1(當 '(')。
  2. 兩道關卡 —— r < 0:就算把每個 * 都當 '(' 還是太多 ')',直接 false。l = max(l, 0):open 不可能是負的,把不合理的選法剪掉。
  3. 看結尾 —— l == 0:0 在範圍裡,存在一種選法剛好全部配完。

和 134 Gas Station 一樣,都是「一路累加的餘額不能變負」:那裡油箱變負就淘汰一段起點,這裡 r 變負就整串不合法、l 變負就把不可能的選法剪掉。

動畫演示// "(*))" · "*)(" · "(*)))"

三個例子各代表一種結局:"(*))" 範圍被夾了兩次,最後停在 [0, 0] → true;"*)(" 一路沒出事,但結尾 l = 1,0 不在範圍裡 → false;"(*)))" 第 5 個字 r 變成 −1,當場 false。虛線是更新後、夾之前的範圍,實線是夾完的範圍。

兩個關鍵// TWO LEMMAS

LEMMA 1 · 可能的 open 永遠是一段連續的數

一開始只有 {0}。'(' 和 ')' 把整段平移一格,還是連續的;'*' 把每個值變成「−1、不變、+1」三個,連續的一段 [l, r] 變成 [l−1, r+1],中間沒有洞;把負的剪掉,剩下的也還是連續的。 所以集合可以用兩端 [l, r] 完整描述,不需要記中間每一個。驗證時每一步都檢查了 l ≤ r,所有測資 0 次違反。

LEMMA 2 · 兩種失敗、一個夾

中途 r < 0:open 最多的選法都已經是負的,代表 ')' 太多,後面再怎麼補都救不回來 → 立刻 false。結尾 l > 0:open 最少的選法也還有左括號沒配完 → false。 l = max(l, 0) 不是失敗:l 變負只代表「有些選法把太多 * 當成 ')'」,那些選法不合法、丟掉就好,剩下的範圍從 0 開始。少了這一行,單獨一個 "*" 就會答錯(l 停在 −1 ≠ 0)。

6

最佳解證明// PROOF OF OPTIMALITY

要證明什麼 · CLAIM

[l, r] 正好是「所有還活著的選法」下,未配對左括號數的全部可能值 —— 所以回傳值一定對。

PROOF · 手法:追蹤所有可能(不變量)
  1. 把三種選法全部展開。每個 * 可以當 '('、')' 或空字串。追蹤一個集合 S = 所有選法下,目前還沒配對的 '(' 有幾個;負的代表 ')' 太多、那種選法已經死了,丟掉。字串合法 ⇔ 掃完時 0 ∈ S。
  2. S 永遠是一段連續的數 [l, r]。'(' 讓整段 +1,')' 讓整段 −1;'*' 把每個 v 變成 v − 1、v、v + 1,連續的一段變成 [l − 1, r + 1],中間沒有洞。丟掉負的,就是 l = max(l, 0)(LEMMA 1)。
  3. 兩個回傳都對。r < 0:連最大的可能都是負的,所有選法都死了,後面救不回來 → false。掃完時 l ≥ 0,所以 0 ∈ [l, r] ⇔ l == 0,回傳 l == 0 正確。
面試這樣說 · 30 秒

我不猜每個 * 是什麼,而是同時追蹤所有選法下「還沒配對的左括號」可能有幾個。這些可能值永遠是一段連續的數,所以只記兩端 l、r。r 變負代表所有選法都死了;最後 l 是 0,代表有一種選法剛好配完。

一句洞察// INSIGHT

不要猜每個 * 是什麼,記「未配對左括號可能有幾個」的範圍 [l, r] 就好 —— 這個範圍永遠是連續的。 r < 0 → 右括號太多,false;l 夾回 0 → 丟掉不可能的選法;結尾 l == 0 → 0 在範圍裡,true。
