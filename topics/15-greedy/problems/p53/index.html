題目簡介// THE QUESTION

QUESTION

給整數陣列 nums,找出和最大的連續子陣列(至少一個元素),回傳那個和。
1 ≤ nums.length ≤ 105,−104 ≤ nums[i] ≤ 104。進階:試試分治法。

範例:[-2,1,-3,4,-1,2,1,-5,4] → 6([4,-1,2,1]); [1] → 1;[5,4,-1,7,8] → 23(整段都拿)。

和 860 Lemonade Change 一樣,每一步只做一個局部決定:這一格要接在前面那段後面,還是丟掉前面、從這格重開。 判斷只看一個數字:前面那段的和 curL 是不是在拖後腿。

題目的進階要求。窮舉 5,380,839 組 0 錯,同一組 n = 105 實測 1.6 ms,完全夠快。只是要寫遞迴、處理跨中點的兩段,比 Kadane 長很多,還多 O(log n) 的遞迴深度。

curL = 「結尾一定在這格」的最大和;maxL = 到目前為止看過的最好答案。每格 curL = max(curL + num, num),再拿 curL 刷新 maxL。一趟掃完,兩個 int。實測每次約 0.28 ms,和暴力解對拍 0 錯。

3

核心策略 · 三步驟// THE LOOP

  1. 初值 —— maxL = INT_MIN(還沒看過任何段),curL = 0。
  2. 每一格 num —— 比「接上」curL + num 和「重開」num,大的那個當新的 curL。
  3. 刷新答案 —— maxL = max(maxL, curL)。掃完回傳 maxL。

「接上」輸給「重開」的條件是 curL + num < num,也就是 curL < 0:前面那段是負的,帶著它只會更小。

兩個關鍵// TWO LEMMAS

LEMMA 1 · curL 是「結尾在這格」的最佳解

任何結尾在 i 的子陣列,只有兩種:只有 nums[i] 自己,或是某段結尾在 i − 1 的子陣列再接上 nums[i]。後者最好的就是 curL(i−1) + nums[i]。所以 max(curL + num, num) 已經把所有結尾在 i 的段都比過了。 答案一定結尾在某一格,maxL 把每一格的 curL 都看過一次 —— 不會漏。

LEMMA 2 · maxL 要從 INT_MIN 開始,不能從 0

題目規定至少拿一個元素。全部都是負數時答案是最大的那個負數([-3,-1,-2] → −1),從 0 開始的 maxL 永遠不會被刷新,回傳 0 —— 等於「一個都不拿」。 實測:maxL = 0、「先歸零再更新」、curL = max(curL + x, 0) 三種寫法都錯 21,844 組,剛好是窮舉裡全負陣列的總數,一組不差;而且三個官方範例都過。

一句洞察// INSIGHT

前面那段是負的就丟掉,不是負的就帶著走。 curL 記「結尾在這格」的最好,maxL 記「全程看過」的最好;maxL 從 INT_MIN 開始,因為至少要拿一個。
