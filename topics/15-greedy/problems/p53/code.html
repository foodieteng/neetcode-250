完整實作// EXTEND OR RESTART · THEN RECORD

p53.cpp C++17 
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int maxL = INT_MIN, curL = 0;

        for (int& num : nums) {
            curL = max(curL + num, num);
            maxL = max(maxL, curL);
        }

        return maxL;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

三個官方範例 → 6、1、23,都正確。 和 O(n²) 暴力解對拍:窮舉值 −4..4、長度 1–7 全部 5,380,839 組 + 隨機 20,000 組(長度 ≤ 300、值 ±104),0 筆不一致。

兩行各自的意思:

  • curL = max(curL + num, num):curL 是「結尾一定在這格」的最大和。接上前面那段,或從這格重開,取大的。
  • maxL = max(maxL, curL):答案可能結尾在任何一格,所以每格都拿 curL 來比一次。順序不能反:先更新 maxL 再算 curL,會拿到「上一格」的值,第一次比的還是初值 0。

另一種常見寫法 curL += num; maxL = max(maxL, curL); if (curL < 0) curL = 0; 也對(窮舉 0 錯),關鍵是先刷新 maxL、再歸零。
