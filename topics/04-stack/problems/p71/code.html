完整實作 · 目錄堆疊// split by '/'

p71.cpp C++17 
class Solution {
public:
    string simplifyPath(string path) {
        stringstream ss(path);              // 把字串當成輸入串流
        string component;
        stack<string> st;

        while (getline(ss, component, '/')) {  // 以 '/' 為分隔逐段讀
            if (component == "..") {
                if (!st.empty()) st.pop();      // 上層(空則忽略)
            } else if (component == "." || component.empty()) {
                continue;                       // '.' 或空段 → 跳過
            } else {
                st.push(component);              // 一般名稱(含 "...")
            }
        }

        if (st.empty()) return "/";          // 根目錄

        string ans = "";
        while (!st.empty()) {
            ans = '/' + st.top() + ans;       // 由頂到底往前接
            st.pop();
        }
        return ans;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

堆疊存目錄名。收尾時因為 stack 只能取 top(從最後 push 的往回),用 ans = '/' + top + ans 往前接,順序才對。 若改用 vector 當堆疊,直接由前往後 '/'+join 更直覺。

stringstream 切段用法// getline + delimiter

STRINGSTREAM · 用串流把字串依分隔字元切段

stringstream ss(path)(需 #include <sstream>)把一個 string 包成可讀的輸入串流。 getline(ss, token, '/') 從串流讀到下一個 '/'為止,把中間內容放進 token,並吃掉那個分隔符(token 不含 /)。讀到結尾回傳的串流轉為 false → while 結束。

關鍵行為:兩個分隔符相鄰會切出「空字串」。所以 "a//b" 會得到 a、""、b;開頭的 / 也會先給一個 ""。這正好讓我們用「空段就跳過」統一處理連續斜線與首尾斜線,不必特別數斜線。注意:預設分隔是換行 '\n';要切別的字元一定要傳第三個參數。

// getline(ss, token, '/') 對 "/a//b/../c" 逐次的 token path = "/a//b/../c" 第1次: token = "" (開頭 '/' 前的空段) 第2次: token = "a" 第3次: token = "" (連續 "//" 之間的空段) 第4次: token = "b" 第5次: token = ".." 第6次: token = "c" getline 回傳 false → 結束 // 空段自然出現 → 用 component.empty() 一律跳過
// 常見等價寫法(不想用 stringstream 時) // (1) 手動掃:遇 '/' 就切一段 string cur; vector<string> segs; for (char c : path) { if (c == '/') { segs.push_back(cur); cur.clear(); } else cur += c; } segs.push_back(cur); // 別忘最後一段 // (2) 之後同樣用「空/./.. /名稱」四類處理 segs // stringstream 版更短;手動版少一個標頭、邏輯全看得到
