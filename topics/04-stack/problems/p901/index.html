題目簡介// THE QUESTION

QUESTION

設計 StockSpanner,每次 next(price) 回傳今天的跨度(span):從今天往回數,連續股價 ≤ 今天的最大天數(含今天)。 例如過去 [7,2,1,2]、今天 2 → span = 4;過去 [7,34,1,2]、今天 8 → span = 3。

這是「往回找第一個更大的價格」——span 就等於「今天」到「上一個嚴格更大價」之間的距離。暴力每次往回掃是 O(n)/次、總 O(n²)。 用單調堆疊存 (price, span):把被今天蓋過的那些天,整段 span 直接累加,不必重數。

2

為什麼「存 span 累加」// WHY THIS

A 每次往回線性掃 O(n)/次
要存全部歷史,每次 next 從今天往回走,最壞走到頭 → 總 O(n²)。重複數已知區塊。
× REJECT · 慢
B 只存 price(不存 span) 仍要重數
pop 掉較小的價後,還是得知道「它代表幾天」——沒存 span 就只能再數一次。
△ REJECT · 沒省到
ADOPT
C 單調堆疊存 (price, span);頂端 ≤ 今天就吃掉它的 span 攤還 O(1)
span = 1;當頂端 price ≤ 今天,span += 頂端.span 並 pop,連環直到頂端更大。 被吃掉那格的 span 早已算好它那一段有幾天,所以累加即可、不必重數。最後 push (今天, span)。
● ADOPT · O(1) 攤還
3

核心策略// STRATEGY

  1. 堆疊存 pair:(price, span),價格由底到頂遞減。
  2. next(price):span=1;當 top.price ≤ price,span += top.span、pop —— 反覆直到頂端更大或空。
  3. push (price, span),回傳 span。

為什麼「累加 span」不會重數也不會漏// THE INVARIANT

INVARIANT · 堆疊裡每格的 span = 「它自己那一段」已壓縮的天數

堆疊裡的價格由底到頂嚴格遞減,每格 (p, s) 代表「以 p 為區塊最大值、往回 s 天都 ≤ p」的一整段。當今天的價 ≥ 頂端 p,表示今天也 ≥ 那整段(因為 p 是那段的最大)——所以能安全地把 s 天整批算進今天,不必逐天重數。連環 pop 就是把一段段這樣吞併。

停在「頂端 p > 今天」是對的:那格的價比今天大,今天的連續 ≤ 區塊到此為止。用 ≤(含等於)是因為題目要「≤ 今天」都算,等價的天也要吃掉;停下的條件因此是嚴格更大。這也讓 span 恰好 = 今天到上一個嚴格更大價的距離。

複雜度// COMPLEXITY

next() = O(1) 攤還　　n 次 = O(n)　　S = O(n)

每個價格一生最多 push 一次、pop 一次。while 內每轉一圈都 pop 掉一格(永久)→ 總 pop ≤ n。

一句洞察// INSIGHT

單調堆疊 + 把答案(span)存在元素身上:被蓋過的區塊整段累加,而非逐天重數。 這是「previous greater element」的距離版,把 O(n²) 壓到攤還 O(1)。
