// st = the record; top = "previous score"
for each op:
  "C" → pop
  "D" → push 2 × top
  "+" → pop b, read a, push b, push a + b
  else → push stoi(op)  // negatives included
return sum of st

One: C pops.
Two: D pushes double the top, and + pushes the top two added together.
Three: anything else is an integer, so I push stoi(op).

One thing worth flagging — to detect an integer I rule out the three operator strings. Checking isdigit on the first character would miss a leading minus sign.

Alright, let me code this up. It's one loop over the operations with a stack of ints, then a loop that pops everything into the sum.

class Solution {
public:
    int calPoints(vector<string>& operations) {
        stack<int> st;

        for (string op : operations) {
            if (op == "C") {
                st.pop();                         // cancel the previous score
            } else if (op == "+") {
                int b = st.top(); st.pop();       // take the top, b
                int a = st.top();                 // peek the second, a
                st.push(b);                       // put b back
                st.push(a + b);                   // push the sum of the last two
            } else if (op == "D") {
                st.push(2 * st.top());            // double the previous score
            } else {
                st.push(stoi(op));                // integer → push
            }
        }

        int ans = 0;
        while (!st.empty()) { ans += st.top(); st.pop(); }  // sum up
        return ans;
    }
};

The line to get right is the "+" branch: I pop b, peek a, push b back, and only then push a + b. If I forget to push b back, the record loses a score. The final else catches every integer, negative ones included, since stoi parses the minus sign.
