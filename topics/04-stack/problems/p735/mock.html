Hmm, let me think about this for a second.

A naive approach would be to scan the array, resolve the first adjacent (right, left) pair, then restart. But each explosion forces a rescan, so that's O(n²).

This problem reminds me of stack-based cancellation, like matching brackets: each new item resolves against the most recent unresolved ones. I push survivors left to right. A new negative asteroid settles its collisions against the stack's top — which is exactly the asteroid immediately to its left — before it either dies or gets pushed.

Here's the plan.

// collide only when top > 0 and ast < 0
for each ast:
  while top>0 and ast<0:
    equal      → pop, ast dies, break
    top bigger → ast dies, break
    top smaller → pop, ast keeps going
  if survived: push ast

One: walk the asteroids left to right with a stack of survivors.
Two: while the top moves right and the new one moves left, they collide: equal, pop and the new one dies; top bigger, the new one dies; top smaller, pop and keep going.
Three: if the new one survived, push it.

One thing worth flagging — only the "top smaller" branch does not break. That's the chain: the top explodes but the new asteroid is still alive and flies on to the next one. The other two branches end its journey, so they break.

Alright, let me code this up. One stack and one loop.

class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        stack<int> st;

        for (int ast : asteroids) {
            if (st.empty()) { st.push(ast); continue; }

            bool survived = true;

            while (!st.empty() && st.top() > 0 && ast < 0) {   // collide only if left > 0 and right < 0
                if (st.top() == abs(ast)) {            // ① equal → both explode
                    st.pop();
                    survived = false;
                    break;
                }

                if (st.top() > abs(ast)) {            // ② top bigger → ast explodes
                    survived = false;
                    break;
                } else {                              // ③ top smaller → top explodes, ast keeps going
                    st.pop();
                }
            }

            if (survived) st.push(ast);            // not destroyed → survives, push
        }

        vector<int> ans;
        while (!st.empty()) { ans.push_back(st.top()); st.pop(); }
        reverse(ans.begin(), ans.end());       // stack pops reversed → flip back to original order
        return ans;
    }
};

The while loop runs only while the top is positive and the new asteroid is negative, and the three branches compare the top against abs(ast). After the loop, I empty the stack into the answer.

One thing worth flagging — survived guards the final push: once ast has exploded, I must not push it back. And the stack pops out in reverse, so I reverse the answer at the end.
