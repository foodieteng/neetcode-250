題目簡介// THE QUESTION

QUESTION

一排小行星,每個是非零整數:正數向右飛、負數向左飛,絕對值是大小。 當一顆向右的追上一顆向左的就會相撞:小的爆炸、相等兩顆都爆。求所有碰撞結束後剩下的狀態。

關鍵觀察:只有「左邊的正數」遇上「右邊的負數」才會相遇。用一個堆疊存「目前存活、還可能被後面撞到」的小行星 —— 新來一顆負數時,就跟堆疊頂端的正數逐一結算,直到它爆炸、或存活入堆疊。

核心策略// STRATEGY

  1. 逐顆處理:維護堆疊存目前存活的小行星。
  2. 會撞才進迴圈:當且僅當 top > 0 && ast < 0(左正遇右負)。比 |ast| 與 top:相等 → pop、兩爆;top > |ast| → ast 爆;否則 pop top、ast 續撞。
  3. 存活才入堆疊:迴圈沒把 ast 判爆(survived)→ push。

為什麼只結算「頂端正 + 進來負」// THE INVARIANT

KEY · 方向決定相遇 + while 的三種結果

兩顆會相撞 ⟺ 左邊那顆向右(+)、右邊那顆向左(−),它們相向而行才會遇上。其餘組合(兩正、兩負、或「負在左正在右」)永遠拉開距離,不相遇。 在「由左到右逐顆入堆疊」的框架下,這恰好就是 堆疊頂端是正數、而新來的是負數 的情形 —— 所以 while 的守門是 top > 0 && ast < 0。

進了 while,比 |ast| 與 top 有三種結果:① 相等 → 兩顆都炸(pop top、ast 也沒了,break);② top 較大 → 只有 ast 炸(break,top 留著);③ top 較小 → top 炸(pop),ast 繼續往下撞(不 break)。只有第 ③ 種會讓 ast 連環撞掉多顆。

複雜度// COMPLEXITY

T = O(n) 攤還　　S = O(n)

每顆小行星最多被 push 一次、pop 一次。while 內每轉一圈都會 pop 掉一顆(永久移除)→ 總 pop 次數 ≤ n。

一句洞察// INSIGHT

把「碰撞」化約成只有一種相遇方向(頂端正 + 進來負),再用堆疊讓「連環撞」自然發生。 三種結果對應 while 內三個分支:相等兩爆、top 大 ast 爆、top 小則 top 爆續撞。
