題目簡介// THE QUESTION

QUESTION

設計 FreqStack:push(val) 加入一個值;pop() 移除並回傳目前出現最頻繁的值。 若有多個並列最頻繁,回傳最接近堆疊頂端(最近 push)的那個。

兩條規則:先比頻率,頻率相同再比新近。若每次 pop 都掃全部找最頻繁 → O(n)/次。 巧妙做法:用頻率分層——bucket[f] 是「曾達到頻率 f 的值」的堆疊。pop 只要取最高層的頂端,兩條規則一次滿足。

3

核心策略// STRATEGY

  1. 兩個容器:freq[val] = 目前次數;bucket[f] = 達到頻率 f 的值堆疊。
  2. push(v):freq[v]++,再 bucket[freq[v]].push(v)(疊到「它現在的頻率層」)。
  3. pop():取最高層 bucket[maxF] 的 top(),pop 掉;freq[該值]--;若該層空了移除。

為什麼「最高層頂端」剛好對// THE INVARIANT

INVARIANT · bucket[f] 由底到頂 = 「達到頻率 f 的先後順序」

一個值每被 push 一次,頻率 +1,就被疊進「新的那一層」bucket。所以一個出現 3 次的值,會同時躺在 bucket[1]、bucket[2]、bucket[3] 各一份。最高層 bucket[maxF] 裡的值,就是目前頻率最高的那些——取它就滿足「最頻繁」。

而 bucket[f] 是堆疊:值是「照達到頻率 f 的先後」由底往頂疊,所以頂端 = 最後(最近)達到頻率 f 的值。當多個值並列最高頻率,它們都在 bucket[maxF],頂端正是最近 push 的那個 → 滿足「同頻率取最近」。一個頂端,兩條規則同時成立。pop 後 freq[v]--,下次它就只在較低層被看到,一切自洽。

6

複雜度// COMPLEXITY

push / pop = O(1) 攤還　　S = O(n)

本解用 map 取最高層(rbegin),多一個 O(log D)(D=不同頻率層數)。換成 unordered_map + 一個 maxFreq 整數可做到嚴格 O(1)。

維度量級
push / pop(本解, map)O(log D)
push / pop(maxFreq 變體)O(1) 攤還
SpaceO(n)

一句洞察// INSIGHT

把「頻率」變成分層,再讓每層是堆疊:高度處理「最頻繁」、堆疊順序處理「最近」。 一個值同時存在於多層,pop 一次就退一層 —— 兩條規則被同一個 bucket[maxF].top() 一次收乾淨。
