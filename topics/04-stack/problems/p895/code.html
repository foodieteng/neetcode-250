完整實作 · freq + 頻率分層堆疊// map by frequency

p895.cpp C++17 
class FreqStack {
public:
    unordered_map<int, int> freq;            // 值 → 目前次數
    map<int, stack<int>> st;            // 頻率 f → 達到 f 的值堆疊(map 有序)

    FreqStack() {}

    void push(int val) {
        freq[val]++;                          // 先加次數
        st[freq[val]].push(val);              // 疊進「它現在的頻率層」
    }

    int pop() {
        int k = st.rbegin()->first;            // 最高頻率層(map 最大 key)
        int v = st[k].top(); st[k].pop();       // 該層頂端 = 最近達到 k 的值
        if (st[k].empty()) st.erase(k);        // 空層移除,維持 rbegin 正確
        freq[v]--;                            // 它退回較低頻率
        return v;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

push 兩行:先 freq++、再疊進 st[freq[val]] —— 疊到的是「它現在的頻率層」。pop 用 st.rbegin() 取最高層。 收尾把空層 erase,rbegin() 才會指到真正的最高層。(原碼 return v; 後有個多餘的 ;,無害。)
2

複雜度 · O(1) 變體// maxFreq trick

本解 push/pop = O(log D)　　O(1) 變體 = O(1) 攤還

D = 不同頻率層數。map 的 []/rbegin/erase 帶 O(log D)。

// 嚴格 O(1) 變體:unordered_map + 一個 maxFreq 整數 unordered_map<int,int> freq; unordered_map<int, stack<int>> group; // 頻率層 → 堆疊 int maxFreq = 0; void push(int v){ int f = ++freq[v]; maxFreq = max(maxFreq, f); group[f].push(v); } int pop(){ int v = group[maxFreq].top(); group[maxFreq].pop(); if (group[maxFreq].empty()) maxFreq--; // 關鍵:空了就降一層 freq[v]--; return v; } // 不用有序 map;maxFreq 只會 ±1,故 O(1)
為什麼 maxFreq-- 對:pop 掉 maxFreq 層唯一(或最後一個)元素後,一定還有某值處於 maxFreq−1(它 push 到 maxFreq 前必先經過 maxFreq−1)→ 新的最高層剛好是 maxFreq−1。

邊界與陷阱// PITFALLS

陷阱後果正解
push 疊到 freq[val] 之前的層 層次錯位,pop 取錯 先 freq[val]++,再疊進新頻率層
pop 忘了 freq[v]-- 該值頻率虛高,之後亂序 取出後把它的頻率退回
用 < / 掃描找最頻繁 O(n)/次,且同頻率取序麻煩 分層 → 直接取最高層頂端
空層沒 erase(map 版) rbegin 指到空層 → 取值崩 層空即 erase(k)(或用 maxFreq--)
以為要另存插入時間 其實不用 bucket 是堆疊,頂端天然是最近
