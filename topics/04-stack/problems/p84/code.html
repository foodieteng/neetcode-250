完整實作 · 遞增索引堆疊// one pass + sentinel

p84.cpp C++17 
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        heights.push_back(-1);              // 末尾哨兵:比誰都矮,收尾清空堆疊
        int n = heights.size();
        int maxArea = 0;
        stack<int> st;                      // 存索引,高度由底到頂遞增

        for (int i = 0; i < n; i++) {
            while (!st.empty() && heights[st.top()] >= heights[i]) {  // 新柱較矮 → 結算頂端
                int h = heights[st.top()]; st.pop();       // 被結算的柱高
                int w = st.empty() ? i : i - st.top() - 1;  // 右界 i、左界=新頂端
                maxArea = max(maxArea, h * w);
            }
            st.push(i);                        // 尚無右邊界,入堆疊等待
        }
        return maxArea;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

三個關鍵:遞增(找兩側更矮 → 遞增堆疊)、寬 = i − st.top() − 1(堆疊空則寬 = i)、末尾哨兵 -1 一次清空。 被 pop 的柱,右界就是觸發它的 i、左界是 pop 後的新頂端。
2

遞增 vs 遞減 · 判斷依據// DECISION

要找的邊界堆疊方向pop 條件(新元素 x)被 pop 者的答案
下一個更大遞減x > topx = 它右邊第一個更大
下一個更小遞增x < topx = 它右邊第一個更小
// 一句話推導方向 堆疊放「還沒找到邊界」的元素;某元素被 pop 時,新進來的 x 就是它的邊界。 → pop 條件 = 「x 恰好是被 pop 者要找的那種邊界」 找更小 → pop 掉 ≥ x 的頂端 → 堆疊遞增 找更大 → pop 掉 ≤ x 的頂端 → 堆疊遞減 // 口訣:方向與你找的「大/小」相反。本題找更矮 → 遞增
3

複雜度分析// COMPLEXITY

觀察成本說明
每柱 push ≤ 1O(n)外層一趟
每柱 pop ≤ 1O(n)結算即離場
面積 h×w≤ 10⁹落在 int 範圍
T = O(n)　　S = O(n)

while 巢狀但總 pop ≤ n,攤還線性。

4

邊界與陷阱// PITFALLS

陷阱後果正解
寬度寫成 i − st.top() 多算一格(含了左邊界柱) 開區間 → i − st.top() − 1
pop 後堆疊空沒特判 取 st.top() 越界 空 → 寬 = i(延伸到最左)
沒放末尾哨兵 遞增殘留的柱沒被結算 append -1,或迴圈後另清空
用了遞減堆疊 找的是更大,方向反了 找更矮 → 遞增堆疊
擔心 h*w 溢位 10⁴×10⁵=10⁹ < INT_MAX int 足夠(更保險用 long long)
