完整實作 · 位置排序 + 時間堆疊// O(n log n)

p853.cpp C++17 
class Solution {
public:
    int carFleet(int target, vector<int>& position, vector<int>& speed) {
        int n = position.size();
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](const auto& a, const auto& b) {
            return position[a] < position[b];       // 依位置由小到大
        });

        stack<pair<int, double>> st;       // (車index, 抵達時間 t)

        for (auto i : idx) {
            double t = (double)(target - position[i]) / speed[i];  // 浮點!
            while (!st.empty() && st.top().second <= t) {  // 後車 t ≤ 前車 → 併入
                st.pop();
            }
            st.push({i, t});
        }

        return st.size();                     // 倖存的堆疊元素數 = 車隊數
    }
};

兩個關鍵:t 一定用 (double) 算(整數除法會把不同車算成同時到、答案錯);<= 讓「同時抵達」也算同隊。 排序只動 idx、不動原陣列。st 存的 i 這裡沒用到,只為對稱可省(存 double 即可)。

複雜度分析// COMPLEXITY

步驟成本說明
排序 idxO(n log n)主導項
堆疊掃一趟O(n)每車最多 push/pop 一次
idx + stackO(n)額外空間
T = O(n log n)　　S = O(n)

排序決定整體;堆疊部分攤還線性。

3

邊界與陷阱// PITFALLS

陷阱後果正解
t 用整數除法 不同車被算成同時到 → 答案錯 轉 (double) 再除
比「速度」而非「抵達時間」 起點不同,快車未必先到 用 t=(target−pos)/speed
比較用 < 同時抵達的車被當兩隊 <=:在 target 相遇也算同隊
沒依位置排序就掃 前後關係亂,併隊判斷失效 先按 position 排序
直接排序 position(丟了 speed 對應) position 與 speed 錯位 排 idx,或排 (pos,speed) pair
