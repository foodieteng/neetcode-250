class Solution {
public:
    string decodeString(string s) {
        string curr = "";
        int repeat = 0;
        stack<pair<string, int>> st;       // (外層前綴, 重複次數)

        for (char c : s) {
            if (c == '[') {
                st.push({curr, repeat});          // 保存外層狀態
                repeat = 0; curr = "";        // 內層從乾淨開始
            } else if (c == ']') {
                auto [prev, k] = st.top(); st.pop();  // 取回外層
                string res = "";
                for (int i = 0; i < k; i++) res += curr;  // 內層 × k
                curr = prev + res;                 // 前綴 + 展開,接回外層
            } else if (isalpha(c)) {
                curr += c;                        // 字母接到目前這層
            } else {
                repeat = repeat * 10 + (c - '0'); // 多位數
            }
        }

        return curr;
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗

] 這行是核心:curr = prev + curr×k —— 先接外層前綴、再重複內層,順序不能反。 數字要 *10+ 處理多位數(如 100[..])。(原碼在 ] 裡用結構化綁定 auto [prev, repeat] 遮蔽了外層變數,這裡改名 k 更清楚、也少一個沒用到的外層 prev。)

複雜度分析// COMPLEXITY

步驟成本說明
掃字元O(len s)每字元一次分派
展開 ×k 複製O(N)總複製量 = 輸出長度
堆疊 + currO(N)不超過輸出規模
T = O(N)　　S = O(N)　　(N = 輸出長度)

題目保證輸出 ≤ 10⁵,故整體線性於輸出。

邊界與陷阱// PITFALLS

陷阱後果正解
數字只讀一位 100[x] 讀成 1、0、0 repeat = repeat*10 + (c−'0')
[ 只存 curr 或只存 repeat 接不回外層 / 次數丟失 兩個都要壓入,再一起清空
] 寫成 curr = res + prev 前綴接在後面 → 順序錯 curr = prev + res(前綴在前)
[ 後忘了清空 內層混入外層殘留 push 後 curr="" ; repeat=0
結構化綁定遮蔽外層變數 邏輯仍對,但易讀性差 綁定改名(如 [prev, k])避免混淆
