題目簡介// THE QUESTION

QUESTION

解碼字串:規則 k[encoded] 表示 encoded 重複 k 次,可巢狀。 例 3[a2[c]] = accaccacc、2[abc]3[cd]ef = abcabccdcdcdef。輸入保證合法。

巢狀是難點:2[c] 在 a… 裡面,展開內層後要接回外層。用堆疊記住「進入 [ 之前累積的字串與次數」—— 遇 ] 時彈出、把內層展開結果接回去。每個 [ 存一層外層狀態。

2

為什麼用堆疊// WHY THIS

A 用一個變數邊掃邊展開 巢狀就崩
遇到內層 [ 時,外層「已累積的字串 + 還沒用的次數」會被覆蓋、救不回來。
× REJECT · 無法巢狀
B 只存次數、不存前綴 接不回外層
] 展開後要接在「外層 [ 前面那段字串」後面 —— 沒存前綴就接錯位置。
△ REJECT · 少資訊
ADOPT
C 堆疊存 (前綴 curr, 次數 repeat);] 時展開接回 O(輸出)
[ 把 (curr, repeat) 壓入、清空重來;] 彈出 (prev, k),curr = prev + curr×k。 巢狀自然由堆疊層數處理,每層都記得自己的外層前綴與次數。
● ADOPT · O(輸出)
3

核心策略 · 四種字元// STRATEGY

  1. 數字:repeat = repeat*10 + (c−'0')(可能多位數)。
  2. [:壓入 (curr, repeat),再把 curr=""、repeat=0,進入新一層。
  3. 字母:curr += c。
  4. ]:彈出 (prev, k),curr = prev + curr×k(把這層展開、接回外層)。

為什麼壓「前綴 + 次數」// THE INVARIANT

INVARIANT · 每個堆疊格 = 「外層在此 [ 之前的狀態」

進入 [ 代表要開始蒐集「要被重複的內層字串」。此時 curr 是外層已累積、但還沒接內層的前綴,repeat 是這個內層要重複幾次。兩者之後才用得到(等 ]),所以先壓進堆疊保存,再把 curr/repeat 清空,讓內層從乾淨狀態開始蒐集。堆疊層數 = 巢狀深度。

遇 ],內層字串已存在 curr。彈出的 (prev, k) 就是「外層前綴」與「這層次數」,於是 curr = prev + curr×k:先接外層前綴,再把內層重複 k 次——順序不能反。展開後 curr 變成外層的新前綴,若外面還有 ] 就繼續往上展開。這就是巢狀能正確層層收合的原因。

複雜度// COMPLEXITY

T = O(N)　　S = O(N)　　(N = 輸出長度)

每個輸出字元被產生 O(1) 次(展開時複製);堆疊與 curr 加起來不超過輸出規模。題目保證輸出 ≤ 10⁵。

維度量級
TimeO(N)(輸出長度)
SpaceO(N)

一句洞察// INSIGHT

巢狀 = 需要「回到外層」的記憶 → 堆疊。每進一層 [ 就存起外層的前綴與次數,每出一層 ] 就展開接回。 這與遞迴同構:堆疊格 = 遞迴呼叫的區域狀態。
