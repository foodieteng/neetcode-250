class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n, 0);          // default 0: stays 0 if no warmer day comes
        stack<int> st;                    // waiting indices, temps decreasing

        for (int i = 0; i < n; i++) {
            while (!st.empty() && temperatures[i] > temperatures[st.top()]) {
                ans[st.top()] = i - st.top();   // distance = index gap
                st.pop();                          // settled, remove it; may chain
            }
            st.push(i);                          // i starts waiting
        }

        return ans;
    }
};

ans starts at all zeros, and the stack holds indices. For each day, a while loop settles every waiting day that is cooler, then I push today's index. That matches the plan.

One thing worth flagging — I read st.top() to set the answer before popping, or I'd lose the index I need for the distance.
