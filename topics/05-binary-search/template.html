二分搜尋通用模板

[ L , R )  ·  FIND FIRST TRUE  ·  LOWER / UPPER BOUND
語言 C++17　·　區間 [l, r)　·　全部程式已編譯驗證並與 <algorithm> 逐筆對拍　·　核心 答案永遠是 l 或 l−1
一切的起點:把問題畫成 TF 帶· THE F/T STRIP

二分搜尋不是「找那個數」,而是找一條分界線。做法:先把問題寫成一個對索引的是非判斷 pred(i), 只要 pred 沿著索引單調(一旦為 T 就不再變回 F),整條陣列就長成 F F F T T T —— 模板要找的永遠是「第一個 T」。所有題型的差別,只在你把 pred 寫成什麼。

模板收斂後,l 停在第一個 T、l−1 就是最後一個 F。 這條帶子上只有兩個有意義的位置,所以 —— 不管題目怎麼問,答案不是 l 就是 l−1。 整張速查表其實只在回答一件事:這題的 pred 該怎麼寫、要拿 l 還是 l−1。
通用模板· THE ONE SKELETON
CORE左閉右開 [l, r) · 找第一個 TO(log n) · O(1)
WHEN 任何能寫成單調是非題的搜尋 · 這一副骨架就夠
// 回傳「第一個讓 pred 成立的索引」;若全都不成立,回傳 n(尾後位置)
int l = 0, r = n;                    // ← 右開:r 初值是 n,不是 n-1

while (l < r) {                        // ← 右開就配 <,不是 <=
    int m = l + (r - l) / 2;          // 防溢位(值域二分時是必須,不是講究)

    if (pred(m)) r = m;                // T:m 可能就是答案 → 保留(不減 1)
    else         l = m + 1;            // F:m 已出局 → 跨過(一定加 1)
}
return l;                              // l == r,且 [0,l) 全 F、[l,n) 全 T

// 不變量:[0, l) 全是 F,[r, n) 全是 T
// 終止  :l <= m < r 恆成立 → 兩個分支都讓區間嚴格變短
// 三處成套:r = n / l < r / r = m —— 只要混到閉區間寫法就會壞

只要記這一副。閉區間 [l, r] 那套(r = n−1、l <= r、r = m−1)也對,但你必須三處同時對齊; 兩套混用是二分最常見的 bug 來源。本章所有題目都用右開版,唯一例外是 374 猜數字 —— 它的候選是 1…n 而非索引,所以寫成 l = 1, r = n 收斂到單格,骨架仍然一模一樣。

看出來了嗎 —— 右邊三欄只有兩種值:l 或 l−1。 「找第一個滿足的」就拿 l,「找最後一個不滿足的」就拿 l−1。 你要做的判斷永遠只有兩步:① pred 怎麼寫 ② 要 l 還是 l−1。

l 與 l−1 · 兩個位置各代表什麼· THE ONLY TWO ANSWERS
回傳 l第一個 T · 分界線本身
語意:第一個滿足條件的位置。
範圍:0 … n —— 注意含 n:若整條帶子全是 F(沒有任何元素滿足),l 會停在 n。

要不要擋 l == n?看你回傳的是「縫」還是「格」 —— 35 回傳插入位置(縫),n 是合法答案,不能擋; 704 回傳索引(格),n 是越界,必須先擋再讀 nums[l]。

驗證命中的順序不可反:
l != n && nums[l] == target
回傳 l − 1最後一個 F · 分界線前一格
語意:最後一個不滿足條件的位置。因為 [0, l) 全是 F,最後一個 F 自然就是 l−1。
範圍:−1 … n−1 —— 注意含 −1:若第一格就是 T(沒有任何 F),l = 0、l−1 = −1。

所以拿 l−1 一定要先擋:
if (l == 0) 沒有這樣的元素;
忘了擋就會讀到 nums[-1] —— 這是 l−1 家族唯一的坑。

典型用途:找前驅 / 找「不超過 target 的最大值」/ 取 target 的末位置(upper_bound − 1)。

int lowerBound(vector<int>& a, int target) {
    int l = 0, r = a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] >= target) r = m;    // ≥ 這側是 T
        else                l = m + 1;
    }
    return l;                         // 0 … n
}

int upperBound(vector<int>& a, int target) {
    int l = 0, r = a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] > target) r = m;     // 只差這個 > 
        else               l = m + 1;
    }
    return l;
}
// 出現次數 = upperBound - lowerBound
// 末位置   = upperBound - 1(先確認次數 > 0)

背誦口訣
  • 先畫 TF 帶:把題目寫成單調的是非題 pred(i),整條陣列必成 F F F T T T,模板只找第一個 T。
  • 一副骨架:r = n / l < r / r = m / l = m + 1 —— 四者成套,少改一處就無窮迴圈或漏解。
  • 不對稱是刻意的:T 保留 mid(r = m,不減 1),F 跨過 mid(l = m + 1,一定加 1)。
  • 答案只有兩個:第一個滿足的 → l;最後一個不滿足的 → l − 1。
  • 兩端各有一個坑:l 可能是 n(讀 nums[l] 前先擋),l − 1 可能是 −1(用之前先擋 l == 0)。
  • ≥ 換成 > 就從 lower_bound 變 upper_bound;兩者相減 = 出現次數,upper − 1 = 末位置。
  • 值域二分:骨架不動,a[m] 比大小換成 check(m),區間換成 [lo, hi + 1)。
  • mid 一律寫 l + (r − l) / 2:小題目是好習慣,值域到 1e9 / 2³¹−1 時是正確性。
  • STL:lower_bound / upper_bound / equal_range / binary_search / partition_point; 記得減 begin() 才是索引,set/map 用成員版。
