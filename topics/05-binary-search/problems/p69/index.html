題目簡介// THE QUESTION

QUESTION

給非負整數 x,回傳 √x 向下取整的結果。 不准用任何內建的次方函式(pow(x, 0.5) 之類一律禁止)。

標成 EASY,但它其實是整章「答案二分」的最小樣本: 沒有陣列、沒有貪心 check,只有一個最乾淨的述詞 —— m² > x。 如果 410 或 1011 卡住了,回來看這題的骨架最快。

這題真正會扣分的地方不在演算法,在型別:x 可以到 2³¹−1, 而 m² 實測會衝到 1.15×10¹⁸ —— 是 INT_MAX 的 5.4 億倍。 沒有 long long 這題直接爆。

為什麼是二分// WHY THIS

A 從 0 一路試上去 O(√x)
√(2³¹−1) ≈ 46341,其實跑得動。但它沒有回答「這題在教什麼」 —— 而且同樣的骨架換到值域更大的題目就死了。
× REJECT · 不是重點
B (int)sqrt(x) O(1)
題目明文禁止。而且就算沒禁,double 只有 53 bit 尾數, 在 x 接近 2³¹ 時可能差一 —— 正式寫法還是得補一輪 while (g*g > x) --g; 校正。
× REJECT · 被禁 + 有精度風險
BOTH FAIL · ADOPT
C 二分述詞 P(m) = (m·m > x) O(log x)
m 越大 m² 越大 ⇒ P 一旦為真就永遠為真 ⇒ 真值表必定是 F F F T T T。 二分找第一個 T,答案就是它的前一格(最後一個 F)。 全程只用整數乘法,沒有浮點、沒有精度問題。
● ADOPT · 31 輪
3

核心策略 · 三步驟// STRATEGY

  1. 定值域:left = 0、right = (long long)x + 1。右界取 x+1 是為了保證真值表裡至少有一個 T(因為 (x+1)² > x 恆成立)。
  2. 寫述詞:P(m) = (m·m > x)。真 → right = mid(保留,它可能就是第一個 T);假 → left = mid + 1(跨過)。
  3. 退一格:收斂後 left 是第一個 T,return left − 1 才是最後一個 F,也就是 floor(√x)。
這就是 lower_bound 的骨架。35、981 用的是同一副 —— 差別只在述詞是什麼、以及要不要退一格。「找第一個 T」和「找最後一個 F」是同一次二分的兩個讀法。

這題真正的考點:型別// THE OVERFLOW

演算法三行就講完了,但型別可以錯三個地方,而且都會在 x 很大時才發作:

位置危險在哪實測
m · m m 最大會到 2³⁰,平方就是 2⁶⁰ 實測峰值 1152921504606846976
= INT_MAX 的 5.4 億倍
(long long)x + 1 少了轉型 ⇒ x + 1 在 int 裡算 ⇒ x = 2³¹−1 時溢位 UBSan 實錘:
2147483647 + 1 overflow
l / r / m 宣告成 int ⇒ 上面兩個問題一起發生 220 萬個測試點
答錯 1987086 個
// m² 的峰值是怎麼來的(實測,非手算) 第一輪 l = 0, r = x + 1 = 2147483648 m = 0 + (2147483648 - 0)/2 = 1073741824 = 2^30 m * m = 1152921504606846976 = 2^60 LLONG_MAX = 9223372036854775807 峰值佔 LLONG_MAX 的 12.5 % ← long long 夠用,但只剩 8 倍餘裕 峰值是 INT_MAX 的 536870912 倍 ← int 差了 9 個數量級 // 峰值出現在「第一輪」,不是最後 —— 二分還沒收斂時 m 最大
注意峰值出現在第一輪。很多人以為「答案才 46340,平方也才 21 億」就放心用 int —— 但二分是從值域中點開始探的,中途的 m 遠比答案大。

複雜度// COMPLEXITY

T = O(log x)　　S = O(1)

值域寬度 x + 1 ≤ 2³¹ ⇒ 約 31 輪,每輪一次乘法。實測 x = 2³¹−1 時正好 31 輪。

維度量級說明
TimeO(log x)實測最多 31 輪
SpaceO(1)三個 long long
浮點完全不用只有整數乘法與比較 ⇒ 沒有精度問題
正確性0 錯213 萬個測試點(見複習頁)
對照 O(√x) 的逐一試:46341 次 vs 31 次,差 1500 倍。 而且 O(log x) 的寫法換到 long long 值域也只多幾輪,逐一試則直接死掉。

一句洞察// INSIGHT

這是整章最小的一顆種子:把「求一個值」換成「二分一個單調的是非題」。 410 的 check 是貪心分段、1011 的是裝箱, 這裡的只是 m·m > x —— 骨架一模一樣,只是述詞換了。
