完整實作 · 兩段二分// pick row, then search it

p74.cpp C++17 
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        // ── 第一段:對「每列首元素」二分,找第一列首元素 > target ──
        int left = 0, right = matrix.size();

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (matrix[mid][0] > target) {
                right = mid;              // 這列太大 → 保留 mid 當右界
            } else {
                left = mid + 1;          // 這列首元素 ≤ target → 跨過
            }
        }

        if (left - 1 < 0) return false;   // 所有列首元素都 > target → 不可能存在

        int rowIdx = left - 1;          // 最後一列「首元素 ≤ target」= 唯一可能的列

        // ── 第二段:對該列二分,收斂到單格 ──
        left = 0, right = matrix[rowIdx].size() - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;

            if (matrix[rowIdx][mid] >= target) {
                right = mid;              // 可能就是答案 → 保留
            } else {
                left = mid + 1;          // 太小 → 跨過
            }
        }

        return matrix[rowIdx][left] == target;   // 唯一候選,仍要驗一次
    }
};

兩段用的是同一副骨架,只有三處不同:pred 寫什麼(> target vs ≥ target)、 right 的初值(m vs n − 1)、取 l 還是 l − 1。 對照模板頁就會發現:第一段是「最後一個不滿足」,第二段是「收斂到單格」。

兩段各自是模板的哪一種// TWO FLAVORS

面向第一段(選列)第二段(列內)
搜尋對象每列的首元素選定那列的所有元素
right 初值m(右開)n − 1(閉,收斂單格)
predmatrix[m][0] > targetmatrix[row][m] >= target
收斂後 l 的意義第一列「首元素 > target」唯一候選格
要的答案l − 1l
必要的檢查l == 0 → false== target 驗命中
// 為什麼第一段用 > 而不是 >= 若寫 matrix[m][0] >= target,收斂後 l = 第一列「首元素 >= target」。 當 target 剛好等於某列的首元素時,兩者會差一列: 用 > → l 指向下一列,l-1 正好是含 target 的那列 ✔ 用 >= → l 指向含 target 的那列,l-1 變成前一列,漏解 ✘ 實測反例 matrix = [[1,3],[10,11]], target = 10 用 > : 首元素欄 [1,10] 的 >10 帶 = [F,F] → l=2 → rowIdx=1 → 列 [10,11] 找到 → true 用 >= : >=10 帶 = [F,T] → l=1 → rowIdx=0 → 列 [1,3] 找不到 → false (窮舉 m,n=1..4 共 40 筆不一致) // 「取 l-1」的寫法,pred 必須用嚴格 >,才能把「等於」留在 l-1 那側

複雜度分析// COMPLEXITY

步驟成本說明
第一段選列O(log m)m ≤ 100 → 7 輪
第二段列內O(log n)n ≤ 100 → 7 輪
兩次收尾檢查O(1)擋 l==0、驗命中
合計O(log m + log n)= O(log(m·n))
T = O(log(m·n))　　S = O(1)

關鍵等式:log m + log n = log(m·n)。所以「兩段二分」和「攤平成一維一次二分」同級。
