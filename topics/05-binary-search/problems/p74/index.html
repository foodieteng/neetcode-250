題目簡介// THE QUESTION

QUESTION

m × n 矩陣,滿足兩個性質:每列遞增,且下一列的首元素 > 上一列的末元素。 判斷 target 在不在裡面,回傳 true/false。要求 O(log(m·n))。

這兩個性質合在一起,說的其實是一件事:把矩陣一列一列接起來,就是一條完整的遞增序列。 所以這題骨子裡不是「二維搜尋」,而是一維二分被摺成了兩層。而且它正好是 模板頁裡 l − 1「最後一個不滿足」 那一條的實戰題。

2

為什麼兩段二分// WHY THIS

A 逐格掃過整個矩陣 O(m·n)
完全沒用到兩個排序性質,不符題目要求的 O(log(m·n))。
× REJECT · 不符要求
B 先線性找列,再對該列二分 O(m + log n)
找列那一步仍是線性掃描,只用掉了一半的性質。m 最大 100 雖然能過,但沒答到題目要的量級。
△ REJECT · 只做一半
BOTH FAIL · ADOPT
C 兩段都二分:先用首元素欄選列,再列內二分 O(log m + log n)
「每列首元素」構成的那一欄本身就是遞增的,可以二分 → O(log m) 鎖定唯一可能的列; 該列又是遞增序列 → 再 O(log n)。合起來 log m + log n = log(m·n),剛好命中要求。
● ADOPT · O(log mn)
3

核心策略 · 三步驟// STRATEGY

  1. 第一段(選列):對「每列首元素」跑模板,pred = matrix[m][0] > target。收斂後 l = 第一列首元素 > target。
  2. 取前一列:target 若存在,只可能在 l 前面那列 → rowIdx = l − 1。若 l == 0(所有列都太大)→ 直接 false。
  3. 第二段(列內):對該列二分收斂到單格,最後驗 matrix[rowIdx][l] == target。

為什麼是 l − 1 而不是 l// THE l−1 FAMILY

RULE · 第一個滿足拿 l,最後一個不滿足拿 l − 1

第一段的 pred 是「matrix[m][0] > target」,TF 帶長這樣(以 target = 3 為例):

列      0   1   2
首元素  1  10  23
> 3 ?   F   T   T　　→ 模板收斂到 l = 1(第一個 T)

但 l = 1 那列的首元素已經超過 target,而列內遞增 ⇒ 該列整列都比 target 大,不可能。 我們要的是最後一個「首元素 ≤ target」的列 —— 也就是最後一個 F —— 正是 l − 1。

而 l − 1 家族永遠附帶一個坑:它可能是 −1。 當 target 比所有列的首元素都小(例如 target = 0),整條帶子全是 T,l = 0 → l − 1 = −1。 所以 if (l - 1 < 0) return false; 不是防禦性程式碼,是必要的正確性檢查,少了它就會讀到 matrix[-1]。

情形第一段收斂的 lrowIdx = l − 1結果
target = 3(在第 0 列)10往第 0 列找 → true
target = 13(落在第 1 列的區間但不存在)21第 1 列找不到 → false
target = 0(比全部都小)0−1直接 return false
target = 100(比全部都大)3 = m2最後一列找不到 → false
注意第四列:l 收斂到 m(尾後位置)時,l − 1 = m − 1 仍是合法的列,不需要特判 —— 因為 target 真的有可能落在最後一列。只有左邊界 l == 0 要擋。

複雜度// COMPLEXITY

T = O(log m + log n) = O(log(m·n))　　S = O(1)

因為 log m + log n = log(m·n) —— 兩段二分相加,剛好等於「攤平成一維後一次二分」的量級。m,n ≤ 100 → 約 7 + 7 = 14 輪。

維度量級說明
TimeO(log m + log n)兩段各自折半
SpaceO(1)只有幾個 int
等價形式O(log(m·n))對數相加 = 乘積取對數
另解(攤平)O(log(m·n))同級,一次迴圈(見複習頁)

一句洞察// INSIGHT

「每列遞增 + 下一列首元素 > 上一列末元素」= 攤平就是一條遞增序列。 所以先對首元素那一欄二分選列(要的是最後一個不滿足 → l − 1,並記得擋 l == 0), 再對那一列二分。log m + log n = log(m·n)。
