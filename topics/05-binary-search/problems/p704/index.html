題目簡介// THE QUESTION

QUESTION

給升冪排序、元素相異的整數陣列 nums 與 target,回傳 target 的索引;不存在則回傳 -1。 要求 O(log n)。例 nums=[-1,0,3,5,9,12]、target=9 → 4;target=2 → -1。

這是二分搜尋的原型題。與其背「找到就 return」的三分支寫法,不如一開始就學邊界二分(lower_bound): 迴圈只做一件事 —— 把區間壓到第一個 ≥ target 的位置;是否真的命中,留到迴圈外檢查一次。 這個骨架之後在 35 / 34 / 33 / 875 等題可以原封不動地重用。

2

為什麼用邊界二分// WHY THIS

A 從頭線性掃描 O(n)
答案正確,但完全沒用到「已排序」這個條件,不符題目要求的 O(log n)。
× REJECT · 不符要求
B 閉區間三分支 l<=r + == 提早 return O(log n)
複雜度對,但 r=n−1、r=mid−1、l<=r 三處要同時對齊,少改一處就無窮迴圈或漏解;且只會「隨便找到一個」,無法推廣到有重複值的「找最左/最右」。
△ REJECT · 易錯難推廣
BOTH FAIL · ADOPT
C 左閉右開 [left, right) 邊界二分,迴圈外驗一次 O(log n)
迴圈裡只有兩個分支:nums[mid] ≥ target 就 right = mid(保留 mid)、否則 left = mid + 1(丟掉 mid)。 結束時 left 必等於「第一個 ≥ target 的位置」,再檢查 left != n && nums[left] == target 即可。同一副骨架直接支援「插入位置 / 最左出現 / 答案二分」。
● ADOPT · STABLE
3

核心策略 · 三步驟// STRATEGY

  1. 定義區間:left = 0、right = n(不是 n−1),候選集合是左閉右開的 [left, right)。
  2. 收縮:mid = left + (right−left)/2。nums[mid] ≥ target → right = mid(mid 可能是答案,保留);否則 left = mid + 1(mid 已出局,丟掉)。
  3. 迴圈外驗證:left < right 不成立時區間空,left = 第一個 ≥ target 的位置。若 left == n 或 nums[left] != target → 回傳 -1,否則回傳 left。

迴圈不變量 · 為什麼一定停、一定對// INVARIANT

INVARIANT · 答案永遠在 [left, right] 這條界線上

把陣列想成一條由 F(nums[i] < target)接到 T(nums[i] ≥ target)的布林帶:因為已排序,它必定長成 F F F T T T 的形狀 —— 單調。我們要找的是第一個 T 的位置。

不變量:[0, left) 全是 F、[right, n) 全是 T。初始 left=0, right=n 時兩段都空,成立。 每輪測 mid:是 T 就令 right=mid(把 mid 併進「全 T」段);是 F 就令 left=mid+1(把 mid 併進「全 F」段)。兩種寫法都維持不變量。

終止:區間長度每輪至少少 1(mid 一定落在 [left, right) 內,兩個分支都會真的移動指標),所以必定收斂到 left == right。 此時 [0,left) 全 F、[left,n) 全 T ⇒ left 就是第一個 T,也就是第一個 ≥ target 的位置。

二分搜尋的本質不是「找那個數」,而是「找 F/T 的分界」。 只要你能把問題寫成一個單調的是非判斷,同一副骨架就能用 —— 這也是「答案二分」(875、1011、410)能成立的理由。

左閉右開 vs 閉區間// TWO STYLES

寫法right 初值迴圈條件右分支結束時
左閉右開 [l, r)(本題) n l < r r = mid l == r,即第一個 ≥ target
閉區間 [l, r] n − 1 l <= r r = mid − 1 l == r + 1
// 三處必須成套,不能混搭 right 初值 ─┐ 迴圈條件 ─┼─ 這三個要嘛全用「右開」,要嘛全用「閉區間」 右分支寫法 ─┘ 混搭的典型後果: r = n 卻寫 l <= r → 讀到 nums[n],越界 r = mid 卻寫閉區間 → mid 沒被排除,l==r 時原地打轉 → 無窮迴圈 // 建議只記熟一套。本題全書統一用左閉右開 [l, r)

一句洞察// INSIGHT

別在迴圈裡找「等於」,而是把區間壓到 F/T 的分界 —— ≥ target 就 right = mid(保留)、否則 left = mid + 1(丟棄), 收斂後 left 就是第一個 ≥ target 的位置,命中與否迴圈外驗一次就好。
