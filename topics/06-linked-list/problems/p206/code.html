解法 B · 迭代(建議預設)// O(1) SPACE

p206_iterative.cpp C++17 
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode *curr = head, *prev = nullptr, *next;

        while (curr) {
            next = curr->next;   // ① 先存後路 —— 下一行就要覆蓋它了
            curr->next = prev;   // ② 反向這一根
            prev = curr;         // ③ prev 前進
            curr = next;         // ④ curr 前進
        }

        return prev;              // 不是 curr —— curr 此刻是 nullptr
    }
};
四行的順序是唯一的:①必須在②之前(否則失去後路),③必須在②之後(否則 prev == curr 造成自環)。 實測把①拿掉或把③提前,8 種結構分別錯 6 種和 7 種。

解法 A · 遞迴// O(n) STACK

p206_recursive.cpp C++17 
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // 兩個條件缺一不可:!head 擋空串列,!head->next 擋最後一個節點
        if (!head || !head->next) {
            return head;
        }

        // 先把後面那一整段翻好;node 全程都是「最後一個節點」
        ListNode* node = reverseList(head->next);

        head->next->next = head;   // 讓後一個指回自己
        head->next = nullptr;      // 自己斷尾,否則兩節點互指成環

        return node;                  // 原封不動往上傳,不是 head
    }
};

🎤 面試模擬 · UMPIRE mock interview transcript ↗(兩種寫法都涵蓋)

node 這個回傳值從頭到尾都是同一個節點(原串列的最後一個)—— 每一層只是把它接著往上傳,誰都沒有改過它。 寫成 return head 是最常見的錯:實測 8 種結構錯 6 種,[1,2] 直接回 [1]。

細節走讀// LINE BY LINE

// [迭代] 四行為什麼是這個順序 next = curr->next; ① 必須最先 —— curr->next 是通往後半段的唯一出路,②會覆蓋它 curr->next = prev; ② 反向。此時 prev 還是「上一個」,所以接得對 prev = curr; ③ 必須在②之後 —— 若提前,②就變成 curr->next = curr(自環) curr = next; ④ 靠①存下來的值才走得動 // 四行兩兩之間都有依賴,任兩行對調都會壞
// [迭代] 空串列為什麼不必特判 head == nullptr ⇒ curr = nullptr ⇒ while (curr) 一次都不進 ⇒ 直接 return prev,而 prev 的初值正是 nullptr // 空串列翻轉後還是空串列,初值恰好就是答案
// [迭代] 迴圈結束時 prev 為什麼正好是新的 head 不變量:每圈開始時 prev 指著「已翻好那段」的頭 curr 指著「還沒動那段」的頭 迴圈因 curr == nullptr 結束 ⇒「還沒動那段」是空的 ⇒ 整條都翻好了 ⇒ prev 指著整條翻好之後的頭 = 原串列的最後一個節點 // 這就是 return prev 而非 return curr 的理由
// [遞迴] head->next->next = head 到底在動誰 設此刻 head 是節點 4,head->next 是節點 5(此時 5 已經是翻好那段的尾巴) head->next->next = head ⇒ 節點 5 的 next 改成指向節點 4 head->next = nullptr ⇒ 節點 4 的 next 清掉,4 成為新的尾巴 若少了第二行:4->next 還是 5、5->next 是 4 ⇒ 4 ⇄ 5 成環 // 第一行「接上」,第二行「斷開」,兩件事必須成對
// [遞迴] base case 的兩個條件各擋什麼 !head 擋「一開始就傳進空串列」的情形(n = 0) !head->next 擋「遞迴到最後一個節點」的情形 —— 少了它,下面 head->next->next 會對 nullptr 解參考 → SEGV(已用 ASan 驗證) // 兩個都是必要的,而且擋的是不同的東西
// EDGE: 退化輸入(皆已實測) n = 0 [] → A: !head 命中,回 nullptr B: 迴圈不進,回 prev = nullptr n = 1 [7] → A: !head->next 命中,回自己 B: 一圈,7->next = nullptr,回 7 n = 2 [1,2] → 兩者皆 [2,1] n = 5000 → 兩者皆正確;A 的堆疊深度 5000(234 KB) // 兩份實作都不需要為 n=0 或 n=1 寫任何特判
PREV概念與動畫 NEXT複習與練習
// ONE-LINE TAKEAWAY
迭代四行的順序唯一:先存 next、再反向、再推 prev、最後推 curr;回傳 prev 不是 curr。遞迴要「接上 + 斷開」成對,回傳 node 不是 head,base case 兩個條件各擋一件事。七種改法裡三種成環 —— 症狀是吊死不是答錯。
