題目簡介// THE QUESTION

QUESTION

給單向鏈結串列的 head,把它翻轉,回傳新的頭。 節點數 0 ~ 5000,值域 ±5000。

這是整個 06 章的地基。後面的 兩兩交換、K 個一組翻轉、回文判斷、重排串列 全部都會在某一步呼叫「翻轉一段」——把這題的指標順序刻進肌肉記憶,後面會省很多力氣。

題目本身不難,難的是手不能亂:鏈結串列每個節點只有一條出路, 一旦把 next 覆蓋掉就再也回不去。所以這題真正在考的是 「改一根指標之前,先想清楚有沒有東西會因此失聯」。
2

為什麼是原地改指標// WHY THIS

A 把值倒進 vector,再造一條新串列 O(n) 額外空間
會過,但配置了 n 個新節點,而且舊的那條要嘛外洩、要嘛還要多寫一段釋放。面試官問「能不能原地做」你就得重寫。
× REJECT · 白花空間
B 只把值倒過來,不動指標 O(n) 額外空間
對這題「碰巧」可行,但它沒有真的翻轉串列 —— 節點的相對位置一個都沒變。 換成「K 個一組翻轉」或節點帶有其他欄位時,這條路直接死掉。
△ REJECT · 學不到東西
BOTH FAIL · ADOPT
C 原地把每根 next 反過來接 O(n) 時間
一條 n 個節點的串列有 n 根 next 指標,翻轉就是把每一根反向。 節點本身一個都不動。實測 20 萬組隨機測資,翻轉前後節點位址集合完全相同 —— 零配置、零釋放。
● ADOPT · 原地翻轉
剩下的問題只有一個:用什麼順序去反向這 n 根指標。 從後往前就是遞迴版,從前往後就是迭代版 —— 這正是你給的兩份程式碼。
3

兩種寫法的骨架// TWO SHAPES

解法 A · 遞迴(從後往前)

  1. 下潛:一路呼叫到最後一個節點,途中什麼都不改。base case 回傳的那個節點就是最終的新 head,之後每層原封不動往上傳。
  2. 回程接線:head->next->next = head —— 讓後面那個節點指回自己。
  3. 斷尾:head->next = nullptr —— 自己不能再指著後面,否則兩節點互指成環。

解法 B · 迭代(從前往後)

  1. 先存後路:next = curr->next —— 下一行就要覆蓋它了,不先存住後半段就永遠失聯。
  2. 反向:curr->next = prev。
  3. 兩指標前進:prev = curr; curr = next;。迴圈結束時 curr 是 nullptr,prev 正好停在最後一個節點 = 新的 head。
兩者做的事完全一樣 —— 都是把那 n 根指標一根根反向,只是走的方向相反。 實測 20 萬組隨機測資,兩份程式碼的輸出逐位元相同。

兩個一定會被問到的「為什麼」// TWO LEMMAS

LEMMA 1 · 迭代版為什麼一定要先存 next

單向串列裡,curr->next 是通往後半段的唯一一條路。 curr->next = prev 這一行會把它覆蓋掉 —— 執行完之後,後面那 n−k 個節點沒有任何指標指得到,永遠失聯。

所以 next = curr->next; 必須在它之前。 實測把這一行拿掉(直接寫 curr = curr->next 在改完之後), [1,2] 就只回 [1] —— 丟了一半的串列,8 種結構錯 6 種。

LEMMA 2 · 遞迴版為什麼一定要斷尾

head->next->next = head 讓後面那個節點指回自己, 但自己本來也還指著它 —— 這一瞬間兩個節點互相指,形成一個長度 2 的環。

head->next = nullptr 就是把自己那一根斷掉。實測拿掉這行, [1,2] 會走成 2 → 1 → 2 → 1 → … 永遠走不完。 成環是鏈結串列題最典型的死法 —— 它不會答錯,它會直接把你的程式吊死。

// 三種改法都會成環(實測,n = 0..7 共 8 種結構) [迭代] prev 初值寫成 head 而非 nullptr → 錯 7/8,[1] 就自己指自己 [迭代] prev = curr 寫在接線之前 → 錯 7/8,同樣自環 [遞迴] 忘了 head->next = nullptr → 錯 6/8,[1,2] → 2 ⇄ 1 // 都不是「答錯」,是「永遠跑不完」

一句洞察// INSIGHT

鏈結串列題的通則:每個節點只有一條出路,所以覆蓋任何一根 next 之前, 先問「有沒有東西會因此失聯」。 迭代版用 next 暫存來回答它,遞迴版用還沒返回的堆疊框來回答它 —— 兩者都是在買一份後路,只是一個用變數、一個用堆疊。

// ONE-LINE TAKEAWAY
翻轉 = 把 n 根 next 全部反向,節點一個都不動(實測位址集合守恆)。從後往前是遞迴、從前往後是迭代。迭代要先存 next(否則丟半條),遞迴要斷尾(否則成環)。時間都是 O(n),但遞迴吃 O(n) 堆疊 —— n=5000 實測 234 KB,17 萬層就崩。
