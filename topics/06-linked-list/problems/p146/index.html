題目簡介// THE QUESTION

QUESTION

實作一個 LRU(Least Recently Used)快取,支援 get(key) 與 put(key, value)。 容量滿了要插入新 key 時,淘汰最久沒被使用的那個。

get 與 put 都算一次使用。查不到的 get 回傳 -1。

1 ≤ capacity ≤ 3000、0 ≤ key ≤ 10⁴、0 ≤ value ≤ 10⁵、最多 2×10⁵ 次呼叫。

兩個操作都要 O(1) 平均時間複雜度。

這題要同時做到兩件事,而單一資料結構都只能做到其中一件:

需求誰做得到誰做不到
用 key 找到資料,O(1)雜湊表串列(要走過去,O(n))
維持「誰最久沒用」的順序串列雜湊表(根本沒有順序)
把某一項搬到最新端,O(1)雙向串列陣列 / vector(搬移要 O(n))
所以答案是「兩個一起用」:雙向串列負責順序,雜湊表負責速度, 而雜湊表的值存的是「節點的指標」 —— 一次查表就直接握住那個節點,不必走串列。 這樣「找到它」與「搬動它」兩步都是 O(1)。

為什麼非要「雙向」串列不可// WHY THIS

A 只用雜湊表 + 每筆存一個時間戳 O(n) / 淘汰
正確,而且好寫 —— 本頁所有實測數字的參考解就是它。 但淘汰時要掃過所有項目找最小時間戳,O(capacity)。
△ 正確 · 但不是 O(1)
B 雜湊表 + vector 記順序 O(n) / 使用
順序有了,但「把中間某一項搬到最後」要搬動後面全部元素。 而且搬完之後所有索引都變了 —— 雜湊表裡存的位置全部失效。
× REJECT · 搬移成本 O(n)
C 雜湊表 + 單向串列 O(n) / 刪除
這是最容易踩的坑。就算雜湊表直接給你節點指標, 單向串列要把一個節點拆下來,還是得先找到「它前面那個」 —— 而唯一的辦法是從頭走過去。O(1) 的查表被 O(n) 的拆除抵銷掉了。
× REJECT · 拆不下來
D 雜湊表 + 雙向串列 + 兩個哨兵 O(1) 平均
節點自己知道前後是誰,所以拆下來只要改四根指標,不必找前驅。 再加兩個哨兵,連 nullptr 判斷都省了。
● ADOPT · 這就是本題答案
C 值得特別記住:「雙向」不是為了「可以往回走」,是為了「可以就地把自己拆下來」。 這也是 460 LFU 用 std::list 而不是 vector 的同一個理由 —— list 從中間刪除不會讓其他指標/迭代器失效。

兩個哨兵買到了什麼// THE SENTINELS

left 與 right 是兩個不存任何資料的節點,建構時就先接起來。 有了它們,串列永遠非空,於是:

// remove:把 node 從串列上拆下來 Node *prev = node->prev, *next = node->next; prev->next = next; next->prev = prev; // 四行,零個 if —— 因為 node 的前後「保證存在」(最差就是哨兵) // insert:把 node 接到 right 之前(= 最新端) Node *back = right->prev; back->next = node; node->prev = back; node->next = right; right->prev = node; // 一樣零個 if
沒有哨兵的話,這兩個函式各要處理「拆的是頭」「拆的是尾」「串列空了」三種特例。 哨兵不是省了幾行,是把「特例」整類消滅掉 —— 和 19、92 的 dummy 是同一招, 只是這裡頭尾各放一個。
哪一端是什麼誰會用到
left->next最久沒用的淘汰時直接取它
right->prev剛剛用過的insert 永遠接在這後面

三種情形,兩個動作拼出來// THE THREE CASES

情形做什麼要動幾張表
get 命中remove(node) → insert(node)只動串列
get miss直接 return -1兩張都不動
put 命中改值 → remove → insert只動串列
put 未命中 + 已滿淘汰 left->next → 新增兩張都要動
put 未命中 + 未滿直接新增兩張都要動
唯一需要小心的是最後兩列 —— 只要有節點進出,兩張表就必須同步。 淘汰時如果只 remove 而忘了 cache.erase,雜湊表就留下一個指向已下架節點的幽靈項目; 反過來只 erase 沒 remove,串列上就留下一個永遠淘汰不掉的孤兒。

一句洞察// INSIGHT

當一個需求裡有兩件事,而每種資料結構只擅長其中一件 —— 那就兩個一起用,並讓其中一個指向另一個。 這題的關鍵不是「用雜湊表」也不是「用串列」,而是「雜湊表的值存的是串列節點的位址」 —— 那根指標就是兩個世界之間的橋。
