題目簡介// THE QUESTION

QUESTION

刪除串列中倒數第 n 個節點,回傳新的頭。 1 ≤ sz ≤ 30、1 ≤ n ≤ sz。

Follow up:能不能只走一趟?

單向串列沒有「倒數第 n 個」這種存取方式 —— 最直覺的做法是走兩趟: 第一趟數長度 sz,第二趟走到第 sz − n 個。 而 follow-up 問的就是:能不能一趟就好?

答案是雙指標拉開固定間距:先讓一個指標領先 n+1 格, 然後兩個一起走。前面那個走到 null 時,後面那個剛好停在「要刪的節點的前一個」。 「數長度」這件事被間距本身取代了。
2

為什麼一趟就夠// WHY THIS

A 走兩趟:先數長度,再走到第 sz−n 個 O(n) · 兩趟
完全正確,而且好懂。複雜度也是 O(n) —— 兩趟不會讓它變 O(n²)。 但題目明文問了 follow-up,所以這只是起點。
△ 正確 · 但沒回答 follow-up
B 把節點指標全塞進 vector,用索引刪 O(n) 空間
一趟就好、也對,但花了 O(n) 空間去換一個本來 O(1) 就能解決的問題。 而且它沒有用到串列的任何性質 —— 換成陣列題也是同一份程式碼。
× REJECT · 空間浪費
ADOPT
C 雙指標拉開 n+1 格,再同步前進 O(n) 一趟 · O(1) 空間
間距一旦拉開就鎖住不變。前指標走到 null 的那一刻, 後指標與尾巴的距離必定等於間距 —— 也就是「倒數第 n+1 個」, 正好是要刪的那個的前驅。
● ADOPT · one pass
這是「固定間距雙指標」的標準用法: 凡是「倒數第 k 個」「距離尾巴 k 格」這種需求,都可以用間距把它換算成 「前指標走到底」這個看得見的終止條件。
3

核心策略 · 三步驟// STRATEGY

  1. 掛 dummy:dummy->next = head,兩個指標都從 dummy 出發。 dummy 在這題是必要的 —— 見第 5 節。
  2. 拉開間距:curr 先走 n + 1 步。 多的那一格是為了讓 tail 停在「前一個」。
  3. 同步前進:while (curr) { tail = tail->next; curr = curr->next; }, 結束後 tail->next 就是要刪的節點,tail->next = tail->next->next; 繞過去。

n+1 與 dummy,各自在解決什麼// TWO LEMMAS

LEMMA 1 · 為什麼是 n+1 而不是 n

同步前進結束時,curr 在 null(可以想成「尾巴後面那一格」), 而間距不變 ⇒ tail 距離那一格剛好是間距那麼多。

間距取 n ⇒ tail 落在倒數第 n 個,也就是要刪的那個節點本身。 但單向串列刪不掉自己 —— 刪一個節點需要拿到它的前驅。

間距取 n+1 ⇒ tail 落在倒數第 n+1 個 = 前驅。 實測少了那個 +1,全部 465 組合法輸入統統錯。

LEMMA 2 · dummy 解決的是「要刪的就是頭」

n == sz 時,要刪的是第一個節點 —— 而頭沒有前驅, LEMMA 1 的推論就沒有落腳點了。

dummy 就是補上那個不存在的前驅。有了它, 「刪頭」和「刪中間任何一個」變成完全同一段程式碼,而且最後回傳 dummy->next 自動處理了「頭被換掉」的情形。 實測:拿掉 dummy 從 head 出發,465 組錯 30 組 —— 剛好就是每個 sz 的 n == sz 那一組。

// curr 走 n+1 步會不會越界? dummy + sz 個節點 = 共 sz+1 個位置(索引 0 .. sz),再往後就是 nullptr curr 從 dummy(索引 0)出發走 n+1 步 → 停在索引 n+1 題目保證 1 ≤ n ≤ sz ⇒ n+1 ≤ sz+1 n = sz 時剛好走到 nullptr(索引 sz+1 那一格),不會再對它取 ->next // 實測 sz = 1..30 的 n = sz 情形,curr 最後正好是 nullptr —— 30 種全部如此

複雜度// COMPLEXITY

T = O(sz)　　S = O(1)　　一趟

curr 總共走 sz + 1 步(n+1 步拉開 + 剩下的同步前進), tail 走 sz − n 步。每個節點最多被經過一次。

維度量級說明
TimeO(sz)一趟,curr 走 sz+1 步
SpaceO(1)兩個指標 + dummy
正確性0 錯窮舉全部 465 組合法輸入
記憶體每次呼叫漏 2 個dummy + 被移除的節點,見程式碼頁
對比走兩趟的版本:複雜度完全一樣,都是 O(sz)。 「一趟」買到的不是漸進上的改進,而是常數與寫法上的簡潔 —— 面試時值得先說「兩趟也是 O(n),但既然你問了 follow-up,我寫一趟的」。

一句洞察// INSIGHT

「距離尾巴 k 格」這種相對位置,可以用兩個指標之間的固定間距來表達 —— 於是「要走到哪裡」這個難題,就換成了「前面那個走到底沒」這個看得見的終止條件。 而 +1 與 dummy 各補一格:一個是為了拿到前驅,一個是為了讓頭也有前驅。
